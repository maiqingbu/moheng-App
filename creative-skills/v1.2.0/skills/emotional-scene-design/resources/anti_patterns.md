# 情绪场景设计：反模式

## AP-S01 错误2:铺垫不足
- 类型：`source`
- 来源：`WWC-12-020`
- 识别信号：表现: 突然就哭了突然就爆发了读者:???为什么? 解决: 情感需要积累前面要有铺垫例:前面多次提到父子情深后面父亲死时才有冲击力没有铺垫=没有情感

## AP-S02 问题一：铺垫不足
- 类型：`source`
- 来源：`WWC-20-031`
- 识别信号：表现：突然就高潮了，读者没感觉 解决：提前铺垫，积累情绪

## AP-S03 问题二：高潮太短
- 类型：`source`
- 来源：`WWC-20-032`
- 识别信号：表现：期待很久，一下就过了 解决：延长高潮时间，充分展现

## Project policy guardrails
- 不得强制“展示不要讲述”绝对化
- 不得无因情绪跳变
- 关键情绪变化要有触发与后效
- 任何 HARD/Canon/Knowledge 冲突优先于文学质量建议。
- 不得读取未来不该暴露给当前 POV/Renderer 的信息。
- 不得把 Skill 自身知识当成项目事实。
- 不得读取或泄露当前 POV/Renderer 不可见的未来信息。
- 不得以文学质量评分覆盖 HARD 失败。
