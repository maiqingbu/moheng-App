## P01 问题2:视角切换过频
- 类型：`source`
- 来源：`WWC-06-015`（多视角叙事技巧）
- 证据短摘：表现: 几乎每段都换一个视角读者眼花缭乱无法投入任何一个角色 解决方法: 原则:一个完整场景用一个主视角如果确实需要切换:- 用明确的分隔- 每个视角至少维持一个场景- 不要每段都换
- 在本 Skill 中：仅用于“控制视角、可知信息、心理距离和感知选择，避免越界和无意跳视角。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P02 误区3:为切换而切换
- 类型：`source`
- 来源：`WWC-06-032`（多视角叙事技巧）
- 证据短摘：错误做法: 强行切换视角,但没必要 正确做法: 切换视角前问自己:1. 必须切换吗?2. 切换后能提供新信息吗?3. 对剧情有帮助吗?如果答案都是否就不要切换

## P04 2. 第三人称视角
- 类型：`source`
- 来源：`WWC-06-004`（多视角叙事技巧）
- 证据短摘：特点: 使用"他/她":- 更灵活- 可以描写角色不知道的事- 容易切换视角- 保持一定距离感示例:"林风推开门,看到桌上放着一封信。他不知道的是,这封信的内容将改变他的一生。而在千里之外,那个写信的女孩正流着泪..." 全知视角 vs 限制视角: 全知视角:- 知晓一切(所有角色想法、未来)- 可以评论和解释- 上帝视角- 适合宏大叙事限制视角:- 跟随特定角色- 只知道该角色所知- 切换角色时切换视角- 适合悬念和反转
- 在本 Skill 中：仅用于“控制视角、可知信息、心理距离和感知选择，避免越界和无意跳视角。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P06 1. 第一人称视角
- 类型：`source`
- 来源：`WWC-06-003`（多视角叙事技巧）
- 证据短摘：特点: 使用"我":- 最强代入感- 局限于"我"的所见所闻- 无法描写"我"不在场的情节- 适合心理描写示例:"我推开门,看到桌上放着一封信。这封信...是她留下的吗?我的手在颤抖。" 优点: 代入感极强 心理描写自然 容易建立读者与角色的情感连接 缺点: 视野受限 难以描写"我"不知道的事 切换其他角色需要明确标识 适用场景: 现代都市情感文 悬疑推理(有限信息) 主角心路历程重要的作品
- 在本 Skill 中：仅用于“控制视角、可知信息、心理距离和感知选择，避免越界和无意跳视角。”的候选判断，应用前必须与输入事实和 HARD 边界核对。
