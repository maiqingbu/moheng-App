# POV 与心理距离设计：示例

## 来源案例 E-S01
- 来源：`WWC-06-019` / 多视角叙事技巧 / 案例二:情感误会
- 短摘：第60章:男主视角"她今天又躲着我...果然,她根本不喜欢我。算了,放弃吧。"第61章:女主视角"啊啊啊!他今天又看着我!我肯定脸红了!他会不会觉得我很奇怪?我好喜欢他,但不敢说..."效果:读者看清误会恨不得把两人推到一起期待误会解开
- 使用方式：只借用方法结构；人物、事件和项目事实必须来自当前任务输入。

## 合成边界案例 E-I01
- 类型：`inference`（用于评测，不归因于原始材料）。
- 情境：用户要求执行“Renderer 前”，但缺少 `POV policy`。
- 期望：返回 `NEEDS_INPUT`，指出最小缺口，不生成权威事实。
