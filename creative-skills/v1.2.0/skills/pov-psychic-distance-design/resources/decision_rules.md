# POV 与心理距离设计：来源候选规则（非绑定）

> v1.1 审查说明：v1.0 的本文件由检索结果机械映射到 payload 字段，存在语义错配风险。运行时不得直接按“第 N 段→第 N 字段”执行；默认方法见 `operating_method.md`。以下内容仅保留来源可追溯性。

## DR-01
- 当：Renderer 前
- 证据：`WWC-06-015` / 问题2:视角切换过频
- 则：将“表现: 几乎每段都换一个视角读者眼花缭乱无法投入任何一个角色 解决方法: 原则:一个完整场景用一个主视角如果确实需要切换:- 用明确的分隔- 每个视角至少维持一个场景- 不要每段都换”作为候选规则，结合项目事实形成 `pov_holder`；不得直接照搬为权威结论。
- 否则：证据与任务不匹配时忽略该规则，并降低 `confidence`。

## DR-02
- 当：POV finding 修复
- 证据：`WWC-06-032` / 误区3:为切换而切换

- 否则：证据与任务不匹配时忽略该规则，并降低 `confidence`。

## Fail-closed rules
- 缺少 `POV policy`：返回 `NEEDS_INPUT`，不得编造。
- 缺少 `KnowledgeState`：返回 `NEEDS_INPUT`，不得编造。
- 缺少 `SceneContract`：返回 `NEEDS_INPUT`，不得编造。
- 来源规则与 HARD/Canon/Knowledge 冲突：返回 `BLOCK` 并报告冲突引用。
