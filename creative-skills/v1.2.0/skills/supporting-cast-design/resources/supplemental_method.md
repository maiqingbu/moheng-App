# 配角群像设计：缺口补强方法

> 来源类型：`project_method`。原始 67,818 字资料对此 Skill 覆盖不足；以下内容为项目方法补强，不进入 `WWC-*` provenance。

## 补强框架
群像按“独立欲望 + 戏剧功能 + 与主角的交换/冲突 + 与其他配角的横向关系 + 独特声线/方法 + 阶段性去留”设计，避免所有人物围绕主角待机。

## 强制诊断测试
- 删除某配角后剧情与关系网无变化，则功能不足。
- 两个配角可互换台词和行动，考虑合并。
- 所有配角都无条件帮助/反对主角，关系动力不足。
- 一次引入过多新名字且无即时功能，延迟登场。
