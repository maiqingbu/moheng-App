## P01 2. 多视角多线
- 类型：`source`
- 来源：`WWC-05-008`（多线叙事技巧）
- 证据短摘：特点： 不同角色视角 切换展现不同线索 上帝视角 示例： 第一章：主角视角 - 主角修炼第二章：反派视角 - 反派阴谋第三章：女主视角 - 女主危机第四章：回到主角视角 - 主角救女主 优点： 信息全面 制造悬念 视野开阔 缺点： 容易乱跳 代入感弱化 需要标注视角 技巧： 章节标题标注视角 固定人物用第三人称 主角视角用第一人称

## P04 多视角叙事技巧
- 类型：`source`
- 来源：`WWC-06-001`（多视角叙事技巧）
- 证据短摘：多个视角,多重精彩！网文俱乐部教你运用多视角叙事,让故事层次丰富、悬念迭起,展现不同角色的内心世界。 多视角叙事是提升小说深度和张力的重要技巧。通过切换不同角色的视角,让读者全面了解故事,增加悬念和冲突,丰富情节层次。掌握这一技巧能让你的作品更有吸引力。

## P05 什么是多视角叙事
- 类型：`source`
- 来源：`WWC-06-002`（多视角叙事技巧）
- 证据短摘：定义:从多个角色的视角讲述故事,每个视角呈现不同的信息、感受和认知。 与单一视角的区别: 单一视角:只从主角视角叙述读者与主角同步获知信息神秘感强但信息有限多视角:从多个角色视角叙述读者可能比某些角色知道得更多全景式呈现,层次丰富
- 在本 Skill 中：仅用于“围绕主角和故事发动机设计功能不同、欲望独立、可产生摩擦的配角。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P06 2. 第三人称视角
- 类型：`source`
- 来源：`WWC-06-004`（多视角叙事技巧）
- 证据短摘：特点: 使用"他/她":- 更灵活- 可以描写角色不知道的事- 容易切换视角- 保持一定距离感示例:"林风推开门,看到桌上放着一封信。他不知道的是,这封信的内容将改变他的一生。而在千里之外,那个写信的女孩正流着泪..." 全知视角 vs 限制视角: 全知视角:- 知晓一切(所有角色想法、未来)- 可以评论和解释- 上帝视角- 适合宏大叙事限制视角:- 跟随特定角色- 只知道该角色所知- 切换角色时切换视角- 适合悬念和反转
- 在本 Skill 中：仅用于“围绕主角和故事发动机设计功能不同、欲望独立、可产生摩擦的配角。”的候选判断，应用前必须与输入事实和 HARD 边界核对。
