## P07 什么是冲突
- 类型：`source`
- 来源：`WWC-03-002`（冲突升级技巧）
- 证据短摘：定义:角色目标与阻碍之间的对抗 冲突公式: 角色想要X + 有人/事阻止 = 冲突示例:主角想变强(目标)+ 资源匮乏/敌人打压(阻碍)= 冲突产生 为什么需要冲突? 没有冲突:主角想要什么就有什么→ 没有挑战→ 没有悬念→ 没有看点→ 读者无聊有冲突:主角要努力争取→ 有困难要克服→ 有敌人要打败→ 有挑战要面对→ 读者期待!
- 在本 Skill 中：仅用于“在 SceneContract 内形成 Want/Opposition/Stakes/Tactic/Countermove/ForcedChoice/Cost/Turn/AgencyChain 等可执行戏剧设计。”的候选判断，应用前必须与输入事实和 HARD 边界核对。
