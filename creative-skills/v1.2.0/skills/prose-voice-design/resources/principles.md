## P01 第三层:语言修改(小改)
- 类型：`source`
- 来源：`WWC-02-005`（修改润色技巧）
- 证据短摘：精简语言: 去掉废话:冗余:"他慢慢地、缓缓地、一步一步地走过去"精简:"他缓步走过去"原则:能用一个词别用三个能用短句别用长句 增强表现力: 平淡:"他很生气"生动:"他双拳紧握,眼中似有火焰跳动"把"告诉"改成"展示"! 统一风格: 检查全文:- 是严肃还是轻松?- 是幽默还是庄重?- 前后风格是否一致?风格混乱会很出戏!
- 在本 Skill 中：仅用于“根据题材、POV、人物和 TasteProfile 形成可执行的语言密度、句法、意象、幽默/克制等风格目标。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P02 问题3:次要视角喧宾夺主

- 来源：`WWC-06-016`（多视角叙事技巧）
- 证据短摘：表现: 本来主角是A结果写着写着B角色的视角内容更多更精彩A反而像配角 解决方法: 1. 统计视角比例 主角视角:60-70% 其他重要角色:20-30% 次要角色:5-10%2. 主线永远跟随主角 其他视角是辅助线3. 如果B更精彩 考虑是不是选错主角了?

## P05 什么是多视角叙事
- 类型：`source`
- 来源：`WWC-06-002`（多视角叙事技巧）
- 证据短摘：定义:从多个角色的视角讲述故事,每个视角呈现不同的信息、感受和认知。 与单一视角的区别: 单一视角:只从主角视角叙述读者与主角同步获知信息神秘感强但信息有限多视角:从多个角色视角叙述读者可能比某些角色知道得更多全景式呈现,层次丰富
- 在本 Skill 中：仅用于“根据题材、POV、人物和 TasteProfile 形成可执行的语言密度、句法、意象、幽默/克制等风格目标。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P06 2. 第三人称视角
- 类型：`source`
- 来源：`WWC-06-004`（多视角叙事技巧）
- 证据短摘：特点: 使用"他/她":- 更灵活- 可以描写角色不知道的事- 容易切换视角- 保持一定距离感示例:"林风推开门,看到桌上放着一封信。他不知道的是,这封信的内容将改变他的一生。而在千里之外,那个写信的女孩正流着泪..." 全知视角 vs 限制视角: 全知视角:- 知晓一切(所有角色想法、未来)- 可以评论和解释- 上帝视角- 适合宏大叙事限制视角:- 跟随特定角色- 只知道该角色所知- 切换角色时切换视角- 适合悬念和反转
- 在本 Skill 中：仅用于“根据题材、POV、人物和 TasteProfile 形成可执行的语言密度、句法、意象、幽默/克制等风格目标。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P07 问题2:视角切换过频
- 类型：`source`
- 来源：`WWC-06-015`（多视角叙事技巧）
- 证据短摘：表现: 几乎每段都换一个视角读者眼花缭乱无法投入任何一个角色 解决方法: 原则:一个完整场景用一个主视角如果确实需要切换:- 用明确的分隔- 每个视角至少维持一个场景- 不要每段都换
