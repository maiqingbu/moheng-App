# 对话设计：反模式

## AP-S01 问题3:对话不自然
- 类型：`source`
- 来源：`WWC-02-018`
- 识别信号：症状: 说明文式对话角色说话都一个样信息堆砌 修改方案: 口语化:"我认为这个方案不太妥当"→"这样不行吧?"加入语气词:"你要小心"→"你可要小心啊!"区分角色语气:老人:沉稳年轻人:活泼文人:文雅武夫:粗犷

## AP-S02 误区1:过度修改
- 类型：`source`
- 来源：`WWC-02-028`
- 识别信号：症状: 改来改去永远不满意一直改下去结果:影响更新读者流失 解决: 设定修改次数上限:连载文最多改2-3遍够用就行完美主义要不得!及格就可以发布边写边进步

## Project policy guardrails
- 不得让角色说出其不知道的信息
- 不得所有角色同一语气
- 信息说明必须服务当下行动
- 任何 HARD/Canon/Knowledge 冲突优先于文学质量建议。
- 不得读取未来不该暴露给当前 POV/Renderer 的信息。
- 不得把 Skill 自身知识当成项目事实。
- 不得读取或泄露当前 POV/Renderer 不可见的未来信息。
- 不得以文学质量评分覆盖 HARD 失败。
