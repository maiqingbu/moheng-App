## P01 时间线处理技巧
- 类型：`source`
- 来源：`WWC-15-001`（时间线处理技巧）
- 证据短摘：玩转时间,精彩加倍！网文俱乐部教你处理时间线,从线性叙事到时空穿越,让故事悬念迭起、层次丰富。 时间线是小说叙事的骨架。巧妙处理时间线能增加悬念、丰富层次、制造反转。从线性叙事到倒叙插叙,从双时间线到时空穿越,掌握时间线技巧让你的故事更精彩。
- 在本 Skill 中：仅用于“建立问题、线索、误导、揭示和角色知识边界，使谜团可追踪且公平。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P03 信息平衡
- 类型：`source`
- 来源：`WWC-05-015`（多线叙事技巧）
- 证据短摘：信息差制造悬念： 主角知道的：读者知道主角不知道的：- 方案A：读者也不知道（一起发现）- 方案B：读者知道（通过其他视角） 方案B示例： 主角视角：主角在修炼，不知危险来临反派视角：读者看到反派在布置阴谋效果：读者知道但主角不知，产生紧张感 注意： 信息不能长期不平衡 该让主角知道时要让他知道 不能为了悬念强行压制信息
- 在本 Skill 中：仅用于“建立问题、线索、误导、揭示和角色知识边界，使谜团可追踪且公平。”的候选判断，应用前必须与输入事实和 HARD 边界核对。
