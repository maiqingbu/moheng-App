# 人物弧设计：反模式

## AP-S01 错误4:为冲突而冲突
- 类型：`source`
- 来源：`WWC-03-035`
- 识别信号：表现: 强行制造冲突角色行为不合理只为了有冲突很假! 解决: 冲突要自然产生:- 利益冲突- 理念不合- 误会- 阵营对立符合逻辑!

## AP-S02 错误4:脱离角色
- 类型：`source`
- 来源：`WWC-12-022`
- 识别信号：表现: 一个冷酷角色突然哭得稀里哗啦读者:人设崩了 解决: 情感表达要符合人设冷酷角色:即使伤心也不会嚎啕大哭可能是:- 沉默不语- 眼眶微红- 一个人找地方发泄符合人设的情感才真实!

## AP-S03 错误1:冲突单一
- 类型：`source`
- 来源：`WWC-03-032`
- 识别信号：表现: 从头到尾只有一个冲突主角vs反派没有其他太单调! 解决: 多条冲突线:主线冲突+支线冲突外部冲突+内部冲突人与人+人与环境

## AP-S04 错误3:冲突解决太容易
- 类型：`source`
- 来源：`WWC-03-034`
- 识别信号：表现: 看起来很严重的危机一章就解决了轻轻松松没有压迫感! 解决: 重要冲突要有过程:- 多次交锋- 策略调整- 实力提升- 最终解决不要太轻易解决!

## AP-S05 错误2:冲突不升级
- 类型：`source`
- 来源：`WWC-03-033`
- 识别信号：表现: 开局打小怪中间打小怪后期还是打小怪没有进步感! 解决: 敌人要越来越强格局要越来越大困难要越来越大

## Project policy guardrails
- 不得把“心理变化”无证据写成 Canon
- 必须指定可观察行为证据
- 任何 HARD/Canon/Knowledge 冲突优先于文学质量建议。
- 不得读取未来不该暴露给当前 POV/Renderer 的信息。
- 不得把 Skill 自身知识当成项目事实。
- 不得读取或泄露当前 POV/Renderer 不可见的未来信息。
- 不得以文学质量评分覆盖 HARD 失败。
