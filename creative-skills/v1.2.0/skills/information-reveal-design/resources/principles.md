# 信息释放与秘密控制：来源原则

> 覆盖等级：`HIGH`。以下仅列原始材料可追溯证据；短摘不是运行时项目事实。

## P01 误区3:为切换而切换
- 类型：`source`
- 来源：`WWC-06-032`（多视角叙事技巧）
- 证据短摘：错误做法: 强行切换视角,但没必要 正确做法: 切换视角前问自己:1. 必须切换吗?2. 切换后能提供新信息吗?3. 对剧情有帮助吗?如果答案都是否就不要切换
- 在本 Skill 中：仅用于“决定何时告诉读者什么、何时只给信号，控制解释、谜团与 forbidden reveal。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P02 问题二：信息量过大

## P03 问题2:视角切换过频
- 类型：`source`
- 来源：`WWC-06-015`（多视角叙事技巧）
- 证据短摘：表现: 几乎每段都换一个视角读者眼花缭乱无法投入任何一个角色 解决方法: 原则:一个完整场景用一个主视角如果确实需要切换:- 用明确的分隔- 每个视角至少维持一个场景- 不要每段都换
- 在本 Skill 中：仅用于“决定何时告诉读者什么、何时只给信号，控制解释、谜团与 forbidden reveal。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P04 3. 镜头切换法
- 类型：`source`
- 来源：`WWC-04-006`（场景转换艺术）
- 证据短摘：电影式转换: 镜头一:主角在A地镜头二:切换到B地的配角示例:"林风走进房间,关上了门。与此同时,千里之外的雪山之巅,一个白衣人缓缓睁眼..."(场景切换)标识词:- 与此同时- 另一边- 同一时刻- 此时此刻 分隔符法: 使用分隔符明确区分:林风这边的剧情...***苏婉那边的剧情...***反派那边的剧情...清晰明确不会混乱
- 在本 Skill 中：仅用于“决定何时告诉读者什么、何时只给信号，控制解释、谜团与 forbidden reveal。”的候选判断，应用前必须与输入事实和 HARD 边界核对。

## P05 2. 场景切换法

## P06 3. 段落切换法(高级)
- 类型：`source`
- 来源：`WWC-06-008`（多视角叙事技巧）
- 证据短摘：方法: 在同一场景内切换不同角色感受示例:林风看着苏婉,心想:"她怎么了?"苏婉低下头,心中默念:"千万别发现我在撒谎。"林风察觉到不对劲,但他选择不追问。苏婉松了口气,但随即更加内疚。 注意: 切换要自然 不要过于频繁(会晕) 最好用明确标识(心想、暗道等) 新人慎用

## P07 问题4:信息不对称把握不当
- 类型：`source`
- 来源：`WWC-06-017`（多视角叙事技巧）
- 证据短摘：表现: 类型一:读者和所有角色都不知道(没有多视角的意义)类型二:读者全知道,没悬念(失去神秘感) 解决方法: 最佳状态:读者 > 部分角色 > 其他角色示例:读者知道:反派的阴谋主角不知:正往陷阱里走反派知道:主角要来了这样:- 读者紧张(他要上当了!)- 主角无知(增加风险感)- 反派得意(增加期待他被打脸)
- 在本 Skill 中：仅用于“决定何时告诉读者什么、何时只给信号，控制解释、谜团与 forbidden reveal。”的候选判断，应用前必须与输入事实和 HARD 边界核对。
