# 情绪场景

## 用途

让情绪峰值场景（离别、牺牲、愤怒爆发、恐惧、真相揭开、温情）真正打动读者：靠铺垫积累，靠细节和动作展示，靠递进推高，靠留白收尾。避免把情绪直接告诉读者。

## 何时使用 / 不适用

- **使用：**
  - 规划阶段，有场景标注为"情绪峰值"时，需要提前安排铺垫；
  - 写作阶段写这类场景；
  - 审核发现情绪苍白、突兀、煽情过度、不符合人设时。
- **不适用：** 普通推进场景（不要每章都煽情）；对话的具体写法（由对话 Skill 负责）。

## 方法

1. **情绪要先挣来。** 峰值之前必须有积累：同一份感情在前文出现过，或者承诺、期待、关系已经被读者看见。没有铺垫的爆发，读者只会问"为什么"。（来源：常见错误 2，铺垫不足）
2. **选一种铺垫手段。**（来源：情感铺垫技巧）
   - 对比：今与昔、期待与现实、人物前后的变化。
   - 关键物品：前文出现一个承载感情的物件，到峰值时让它出现变化（破损、遗失、被交还）。
   - 反复强化：同一句誓言或愿望出现三次，第四次兑现或落空。
3. **层层递进，不要一步到位。** 把峰值拆成 4～6 个小步骤，每一步情绪更进一层。例如离别：知道要走 → 准备 → 告别 → 转身 → 回头。原文附有离别、复仇、守护三种场景的分阶段模板，可以参考它的递进思路，但不要照搬台词。
4. **展示，不要告诉。** 写手、眼睛、呼吸、声音的变化，未完成的动作，说不出口的话。不写"他很伤心"。（来源：常见错误 1；修改润色，"把'告诉'改成'展示'"）
5. **用回忆对照放大当下。** 在峰值时刻插入一个短回忆，让过去的同一个动作或同一句话和现在形成对照。
6. **留白收尾。** 峰值最高的地方少写：一个动作、一段沉默，不加解释，也不总结人物的感受。（来源：留白艺术）
7. **情绪的表达方式要符合人设。** 冷硬的人物不会嚎啕大哭，会沉默、走开，或者做一件反常的小事。（来源：常见错误 4，脱离角色）
8. **控制频率。** 重要时刻才写峰值，前后要有放松的段落。（来源：常见错误 3，过度煽情）
9. **不同情绪的侧重点：**
   - 愤怒：先压抑，再写身体反应，然后爆发，最后写后续行动。
   - 恐惧：用暗示代替直接展示，营造氛围，用感官（尤其是听觉）一步步逼近，最后突然落点。
   - 反转：先给出假象，再埋下事后能回看出来的线索，在最恰当的时机揭开。

## 参考区间（来自原文，仅供参考）

- 一个情绪峰值场景通常拆成 4～6 个递进步骤。
- 原文的改写练习要求"把一句话的情绪改写到至少 500 字"。由此可以作为参考：峰值场景一般占 500～900 字，这个篇幅来自递进和细节，不是来自形容词堆叠。
- 节奏上：轻松 → 紧张 → 情绪峰值 → 放松，循环往复。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| "他很伤心，伤心得无法呼吸。" | 写他做了什么、没做成什么，比如手停在半空、话说到一半。删掉形容词。 |
| 角色突然崩溃大哭，前文从没写过两人感情深 | 在前面的章节或本章前段补一处共同经历，或者一个物件 |
| 每章都有人死、有人哭 | 一卷只保留几个真正的峰值，其余场景用克制的方式表达 |
| 峰值之后接一大段内心总结："他终于明白……" | 删掉总结，停在动作或画面上 |
| 冷酷的反派当众痛哭 | 改成符合人设的反常小动作 |

## 示例（自写，演示手法）

情境：王府兄长得知被逐出府的弟弟病死在外，消息传到书房。

**弱版：**

> 消息传来，兄长非常悲痛，他后悔当初把弟弟赶走，伤心得说不出话来。他想起两人小时候的事情，泪流满面。

问题：全是告诉；没有递进；"后悔"把潜台词直接说穿了。

**改写版：**

> 来报信的小厮跪在门口，话没说完就开始磕头。
>
> 兄长"嗯"了一声，提笔把那页账目的最后一行写完，搁下笔，又拿起来，墨已经干了。
>
> "冬衣，"他问，"送到了吗？"
>
> 小厮愣了愣："送到了。说是……一直穿着。"
>
> 兄长点点头，起身去关窗。窗外那棵海棠是他们小时候一起种的，今年开得晚。他关到一半，手停在窗棂上，停了很久。
>
> 那年弟弟八岁，踮着脚够不到窗栓，回头喊他："哥，你来。"
>
> 风把半扇窗吹开了。他没有再去关。

手法对照：

- 递进：报信 → 照常写完账 → 问冬衣 → 关窗 → 停住 → 回忆 → 不再关窗。
- 物件：冬衣（承接前文）、海棠、窗栓。
- 未完成的动作：窗关到一半。
- 回忆对照：小时候是"你来"，现在再也没有人叫他。
- 留白：结尾不写他的感受。
- 符合人设：克制的兄长不哭，他的反常是"没有再去关窗"。

## 自检清单（审核环节使用）

- [ ] 这个峰值在前文有铺垫吗（共同经历、物件、反复出现的承诺）？
- [ ] 是否拆成了 4～6 个递进步骤，而不是一句话写完？
- [ ] 有没有"他很伤心／非常愤怒"这类直接告诉读者的句子？
- [ ] 峰值处是否留白，有没有在后面附加总结？
- [ ] 情绪的表达方式是否符合人物的性格？
- [ ] 本章和前后章节的峰值密度是否过高？

## 注入要点·规划

> 选择器在规划环节注入，不超过 500 字。

本章有情绪峰值场景时，规划中要写明：

- 这份情绪来自前文的哪一处铺垫（共同经历、物件或承诺）；如果没有，在本章前段补一个。
- 峰值场景拆成 4～6 个递进节拍。
- 峰值前后安排节奏较缓的场景。

## 注入要点·写作

> 选择器在写作环节、遇到标注为"情绪峰值"的场景时注入，不超过 1100 字。

写本场景时：

1. 不直接写"他很伤心／愤怒／害怕"。改写身体和动作的变化：手、眼睛、呼吸、声音、未完成的动作、说不出口的话。
2. 按节拍层层递进，每一步情绪都比上一步更进一层，不要一步到位。
3. 让前文铺垫过的物件或话语在这里再出现，并发生变化（破损、交还、落空）。
4. 在最高点插入一个很短的回忆，形成今昔对照。
5. 峰值最高的地方少写，停在动作或画面上，不加"他终于明白了……"这类总结。
6. 情绪的表达方式要符合人物性格：克制的人用反常的小事表达。
7. 愤怒：先压抑，再写身体反应，然后爆发，最后写行动。恐惧：用暗示和感官逐步逼近，最后突然落点。反转：先给出假象，再在细节里埋线索，最后揭开。
