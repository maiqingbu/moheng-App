# 开篇策略比较

## 用途

在写之前比较几种不同的开篇思路，选出最适合这本书的一种。比较的不是文笔，而是：从哪里切入、读者凭什么留下来、和同类作品有什么不同。

## 何时使用 / 不适用

- **使用：** 生成故事方向时；开篇三章规划之前；审核发现几个方向大同小异，或者开局模式和题材不搭时。
- **不适用：** 已经确定方向之后的逐章规划（由黄金三章、章节规划负责）。

## 方法

1. **几个候选方向必须真的不同。** 至少在下面一项上有明显差异：开局模式、切入时间点、主角初始处境、核心卖点。只换名字和背景的不算不同。
2. **从经典开局模式出发，再加变化**（来源：开头技巧，经典开头模式；套路与爽点，"在套路上创新"）。常见模式和它们的长处：
   - 困境开局：对比强，容易引起同情，逆袭的期待明确。
   - 巅峰开局：实力对比强，主角的优势明确，回报来得快。
   - 日常突变：符合常规叙事，便于展开世界，读者容易接受。
   - 身份隐藏：反差大，打脸的期待明确，可持续性强。
   - 机缘或系统降临：成长路线清晰，回报密集。

   每个方向都要写明：在经典模式的基础上，新在哪里。
3. **对每个方向回答四个问题：**
   - 第一章的切入点：正在发生的冲突或异常是什么？
   - 读者留下来的理由：悬念、冲突、成长还是复仇期待？
   - 主角的特殊之处在第几章出现？
   - 三章内的第一个明显回报是什么？
4. **按题材检查是否合适**（来源：开头技巧，不同类型的开头）：
   - 玄幻：要快；
   - 都市：要接地气，特殊能力一开始不要太夸张；
   - 历史：要交代时代背景和主角的优势；
   - 科幻：要尽快展现世界的独特之处。
5. **给出推荐和理由。** 推荐要针对目标读者的口味和作品的核心卖点，不能只说"这个更有趣"。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 三个方向只是主角名字和地名不同 | 换开局模式、切入时间点或主角的初始处境 |
| 只说"开局有悬念"，没有具体的切入点 | 写出第一章正在发生的那件事 |
| 方向的卖点和题材读者的期待不符 | 按题材检查节奏和回报方式 |
| 照搬经典套路，没有任何变化 | 写明在套路之上新在哪里 |

## 示例（自写，演示：同一创意的三个不同开篇）

创意：修复城市记忆的调查员，每修复一次就会失去一段自己的真实记忆。

```
方向A 日常突变：从一次普通的委托写起，结尾发现代价。
      留人理由：悬念——代价会拿走什么？
      新意：能力本身就是诅咒；回报和代价同时出现。
方向B 巅峰开局：主角已经是档案局最好的修复师，却突然发现自己不记得妹妹。
      留人理由：悬念加情感——他亲手修掉了什么？
      新意：从最强的人失去最重要的东西切入。
方向C 身份隐藏：主角是被开除的前调查员，在黑市私下修复记忆。
      留人理由：冲突——档案局在追捕他。
      新意：主角站在制度的对立面。
推荐：B。核心卖点是"代价"的情感冲击，B 在第一章就让代价落在最痛的地方；
      A 的节奏偏慢，C 的冲突偏向追逃，会冲淡主题。
```

## 自检清单

- [ ] 候选方向在开局模式、切入点、主角处境或卖点上是否真的不同？
- [ ] 每个方向是否写明了第一章的切入点、留人理由、特殊之处出现的时间、第一个回报？
- [ ] 是否符合题材读者的期待？
- [ ] 推荐理由是否基于目标读者和核心卖点？

## 注入要点·方向生成

> 生成故事方向时注入，不超过 900 字。

生成几个故事方向时：

- 方向之间必须在开局模式（困境、巅峰、日常突变、身份隐藏、机缘降临）、切入时间点、主角初始处境或核心卖点上有明显差异，不能只换名字。
- 每个方向写明：第一章正在发生的冲突或异常；读者留下来的理由（悬念、冲突、成长或复仇期待）；主角的特殊之处在第几章出现；三章内的第一个回报；在经典模式之上新在哪里。
- 按题材检查节奏：玄幻要快，都市要接地气，历史要交代时代背景和主角优势，科幻要尽快展现世界的独特之处。

## 注入要点·开篇规划

> 规划开篇三章前注入，不超过 600 字。

先写明本书采用的开局模式、第一章的切入点、读者留下来的理由，以及三章内的第一个回报。之后的三章规划都要服务这几点。
