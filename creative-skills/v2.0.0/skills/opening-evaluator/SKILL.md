# 开篇评估

## 用途

对开篇三章做一次整体评估：读者会不会留下来？如果不会，具体卡在哪里、怎么改。输出的是可以执行的修改建议，不只是一个分数。

## 何时使用 / 不适用

- **使用：** 开篇三章完成后的评估；开篇章节的审核。
- **不适用：** 第四章以后的单章评估（由章节叙事评估负责）。

## 评估维度与判断标准

| 维度 | 合格 | 不合格的信号 |
|---|---|---|
| 第一段 | 有抓手（冲突、异常或有趣），信息清楚，能进入情境 | 自我介绍、天气、大段环境描写 |
| 切入速度 | 第一章进入冲突或异常 | 前半章都在铺垫和介绍 |
| 主角 | 通过选择展现性格；读者对他有同情、认同或喜欢 | 被动、不讨喜、行为动机不合理 |
| 特殊之处 | 第一章出现或露出端倪，第二章开始使用 | 三章还没出现 |
| 设定交代 | 通过剧情分散交代 | 大段说明；一次讲太多读者记不住 |
| 悬念与期待 | 能说出具体的"想知道什么" | 没有问题，或者问题很空泛 |
| 回报 | 三章内至少有一个明显的回报（反击、认可、得到某样东西） | 只有铺垫没有回报，或者一直在压抑 |
| 三章推进 | 每章都有新的东西 | 三章重复同一种冲突 |
| 方向 | 第三章确立了短期目标，暗示了长期目标 | 读完三章不知道故事要去哪里 |

来源：开头技巧，开头检查清单和常见问题；读者粘性，前三章的要求。

## 修改建议的写法

每条问题都要写成"位置、问题、改法"三部分。改法从原文给的几种方式里选（来源：修改润色，开头不够吸引人）：

- 倒叙：从最精彩的片段开始，再回到起点；
- 冲突开局：直接从冲突开始；
- 悬念开局：先抛出一个问题。

另外几类问题的改法：

- 信息量过大：把设定分散到剧情里，只说必要的部分。
- 主角不讨喜：给一个正面特质、一个合理的动机。
- 缺少回报：第三章安排一次反击或被认可。

## 示例（自写，演示一条合格的评估意见）

> **位置：** 第1章前 600 字
> **问题：** 开头是主角起床、天气、档案局的介绍，第 600 字后委托人才出现。前 600 字没有抓手。
> **改法：** 从委托人推门进来、说出那个不可能的请求开始（冲突开局）。档案局的规则改到第二场修复前、主角犹豫时，用一句争执带出来。

## 注入要点·评估

> 评估开篇三章时注入，不超过 1200 字。

逐项评估开篇三章：

- 第一段有没有抓手、信息是否清楚。
- 是否在第一章就进入冲突或异常。
- 主角是否通过选择展现性格，读者是否会站在他这边。
- 特殊之处是否在第一章出现或露出端倪、第二章开始使用。
- 设定是否通过剧情分散交代。
- 是否有具体的悬念。
- 三章内是否有明显的回报。
- 三章是否各有新的推进。
- 第三章是否确立了方向。

每个问题都按"位置、问题、改法"写出。改法从倒叙、冲突开局、悬念开局、分散设定、补主角动机、安排反击或认可中选择。最后给出最需要优先处理的 1～3 条。
