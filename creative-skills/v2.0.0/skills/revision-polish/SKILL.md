# 修改润色

## 用途

针对审核发现的具体问题，对已经写好的正文做有方向的修改：该删的删，该补的补，把概述改成演出来，把告诉改成展示。这个 Skill 也是"篇幅不足或超出时改写"的方法：篇幅的变化必须来自展开没写透的节拍，或者删掉无用段落，**不能靠注水**。

## 何时使用 / 不适用

- **使用：** 改写环节（篇幅不在区间内、审核发现概述化、对话生硬、描写平淡、冗余、风格不统一）；审核环节的语言和情节检查。
- **不适用：** 本章规划本身就缺内容的情况。节拍不够时应该回到规划补情节，不能在改写里硬撑。改动已经提交的事实，走变更流程，不在改写里处理。

## 方法

1. **先定位再动手，一次只看一个层面。**（来源：分遍修改、标记法）
   - 结构：本章推进是否成立。
   - 情节：每段有没有用、有没有跳跃。
   - 语言：是否流畅、是否在展示。
   - 细节：用词、标点、前后数字。

   改写时只针对审核列出的问题，不要整章推倒重写成另一篇。
2. **篇幅不足：展开没写透的节拍，而不是加新的形容词。** 对照规划中的节拍，找出只用一两句概述带过的那些。把它们演出来：谁做了什么动作，对方怎么反应，环境里有什么细节，人物当时的心理活动。展开后整体结构不变，信息和动作更多。（来源：情节修改"补充缺失"；语言修改"增强表现力"）
3. **篇幅超出：先删没有作用的段落，再压缩重复的部分。** 一段文字如果不推动剧情、不塑造人物、不营造氛围，就删掉；重复的说明压缩成一句。（来源：删除冗余、删减法、压缩法）
4. **不注水。** 下面这些都算注水，一律不允许：
   - 堆叠同义的形容词（"慢慢地、缓缓地、一步一步地"）；
   - 重复讲已经交代过的信息；
   - 加入和本章推进无关的闲笔和景物；
   - 在段末反复总结人物感受。

   （来源："网文不需要废话"；"不要为了凑字数水文"）
5. **把告诉改成展示。** "他很生气""景色很美""战斗很激烈"这类句子，改成具体的动作、感官和细节。（来源：常见问题 4，描写平淡）
6. **跳跃处补过渡。** 突然出现的能力、突然的情绪变化、突然的实力提升，都要补上铺垫或过渡的一两笔。（来源：补充缺失）
7. **对话：** 说明式的台词改成口语，并区分不同人物的语气。具体方法见对话 Skill。（来源：常见问题 3）
8. **风格统一，用词准确。** 全章基调前后一致；模糊的动词换成准确的动词；连续重复的词换掉。（来源：统一风格、替换法）
9. **改完自查。** 读一遍，拗口的地方再改。站在读者的位置问自己：这里会不会无聊、会不会看不懂。（来源：朗读法、换位法）
10. **知道什么时候停。** 同一章最多改 2～3 轮。如果还是不达标，说明问题出在规划上，应该回到规划环节，而不是一直改下去。（来源：误区 1，过度修改，"连载文最多改 2～3 遍"）

## 参考区间（来自原文，仅供参考）

- 修改轮数：连载章节最多 2～3 轮。
- 节奏检查：可以给每章标一个 1～10 的紧张度，正常的走势应该有起有伏（原文示例：3、5、8、4、6、10……）。

## 失败写法与改法

| 改写时的失败做法 | 正确做法 |
|---|---|
| 篇幅不够就加形容词和景物描写 | 找出被概述的节拍，把它们演出来 |
| 把整章推倒重写，情节和上一版完全不同 | 保留情节和结构，只处理列出的问题 |
| 每一轮改写的结果都一样（无效改写） | 明确告诉改写环节具体问题和位置：哪几个场景、缺多少字、哪几个节拍只是概述 |
| 篇幅超了就砍掉关键节拍 | 先删没有作用的段落和重复说明，关键节拍保留 |
| 改了三轮还不达标，继续改 | 回到规划，补充或调整节拍 |

## 示例（自写，演示手法：展开被概述的节拍）

规划中的节拍：老仆在侧门送弟弟离府，往行李里塞了一件冬衣。

**初稿（概述，约 40 字）：**

> 第二天清晨，老仆在侧门送他离开，还给他塞了一件冬衣。他上了车，王府越来越远。

**改写（展开同一个节拍，约 260 字，没有加新情节）：**

> 天刚擦亮，侧门外只停了一辆青篷车。
>
> 老仆提着包袱出来，脚步比平时慢，像是在数门槛上的砖。他把包袱递上车，又伸手要了回去，解开结，从怀里掏出一件叠得方方正正的冬衣塞进去，重新系紧。
>
> "北边冷，"他说，"府里的规矩，出门的人都要带。"
>
> 弟弟在府里住了二十年，从没听过这条规矩。他看了老仆一眼，老仆低着头，在给车夫塞铜钱。
>
> 车动了。弟弟没有回头。等车拐过街角，他才掀开帘子一角。侧门已经关了，门楣上那盏灯还亮着。这个时辰，本该早就熄了。

手法对照：

- 篇幅是靠动作（解开包袱又重新系上）、对白（"府里的规矩"）、细节（灯还亮着）展开的。
- 没有新增情节，也没有堆叠形容词。
- 展开后，兄长的隐情透过老仆的反常和那盏没熄的灯露了出来。

## 自检清单

- [ ] 有没有只用一两句概述带过的规划节拍？
- [ ] 有没有不推动剧情、不塑造人物、不营造氛围的段落？
- [ ] 有没有"他很生气／景色很美"这类直接告诉读者的句子？
- [ ] 有没有突然的能力、情绪或实力变化，前面没有铺垫？
- [ ] 全章风格是否统一？有没有连续重复的用词？
- [ ] 有没有注水：同义形容词堆叠、重复交代、无关闲笔、段末总结感受？

## 注入要点·改写

> 选择器在改写环节注入，不超过 1200 字。同时附上审核给出的具体问题清单：哪个场景、缺多少字或超多少字、哪些节拍只是概述。

改写本章时：

1. 保留本章的情节和结构，只处理问题清单列出的问题，不要重写成另一篇。
2. 篇幅不足：把清单中只用一两句概述带过的节拍演出来，写清谁做了什么、对方如何反应、现场有什么细节、人物在想什么。不要加形容词，不要加无关景物，不要重复已有信息，不要在段末总结感受。
3. 篇幅超出：先删掉不推动剧情、不塑造人物、不营造氛围的段落，再把重复的说明压缩成一句，关键节拍保留。
4. 把"他很生气""景色很美"这类句子改成具体的动作、感官和细节。
5. 突然出现的变化，补一两笔铺垫或过渡。
6. 全章风格保持一致，换掉模糊或重复的用词。
