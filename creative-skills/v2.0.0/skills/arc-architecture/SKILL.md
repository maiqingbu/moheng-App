# 段落（剧情单元）架构

## 用途

卷是大阶段，卷里还要分成若干剧情单元（一个案件、一次试炼、一段逃亡）。每个单元有自己的小目标和小高潮。本技能负责把卷拆成单元，并为每个单元安排内部节奏。

## 何时使用 / 不适用

- **使用：** 卷规划时（常驻）；章节规划时确定本章处在单元的哪个位置；审核发现单元中段松垮、没有高潮、单元之间雷同时。
- **不适用：** 单章内部的场景安排（由章节规划负责）。

## 方法

1. **【补写】把卷拆成 3～6 个单元。** 每个单元写明：小目标、对手或障碍、小高潮、交给主线的东西（线索、能力、关系变化）。
2. **单元内部节奏**（来源：长篇连载管理，大节奏；高潮设计，高潮节奏）：
   - 铺垫约占四成：引出问题，建立期待；
   - 发展约占四成：交锋、受挫、调整；
   - 高潮和余韵约占两成：爆发，然后交代后果。
3. **快慢交替。** 一段冲突之后给几章日常或铺垫，再进入下一次冲突和高潮。（来源：节奏控制，中期节奏示例）
4. **单元之间要有变化。** 相邻单元换冲突类型（打斗、智斗、情感、生存）、换场景或换对手，避免重复。
5. **单元结尾交接。** 每个单元的余韵里，埋下下一个单元的引子。
6. **章节规划时标出位置。** 每章都写明它处在当前单元的铺垫、发展、高潮还是余韵，用来决定本章的节奏和篇幅分配。

## 参考区间（来源经验，按作品调整）

- 小高潮：约每 5～10 章一次；
- 单元长度：约 10～30 章；
- 内部比例：铺垫约 40%，发展约 40%，高潮与余韵约 20%。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 单元中段十章都在原地打转 | 每两三章加入一次受挫或新信息 |
| 单元只有铺垫，没有高潮就转到下一件事 | 补一场高潮并交代后果 |
| 连续三个单元都是"被挑衅—打脸" | 换冲突类型和对手 |
| 高潮后立刻切新单元，没有余韵 | 给一两章处理后果、整理收获 |

## 示例（自写）

```
单元：《失忆的证人》（第 66–82 章，共 17 章）
小目标：修复一名证人的记忆，证明一桩冤案
对手：抹去证人记忆的中间人
交给主线：中间人的雇主编号，与姐姐档案的编号同一格式
铺垫（66–72）：接案，证人的记忆每天都在被二次覆盖
发展（73–78）：两次修复失败，主角代价加重；发现证人家里有人在配合
高潮（79–81）：在覆盖发生的那一夜潜入，正面阻断
余韵（82）：证人想起了真相，主角却忘了母亲的生日；引出下一单元的委托人
```

## 自检清单

- [ ] 本卷是否拆成了几个单元，并各有小目标和小高潮？
- [ ] 单元内部比例是否合理，中段是否有受挫和新信息？
- [ ] 相邻单元的冲突类型是否有变化？
- [ ] 本章是否标明了它在单元中的位置？

## 注入要点·规划

> 卷规划时注入，不超过 600 字。

把本卷拆成 3～6 个剧情单元，每个写明小目标、对手或障碍、小高潮、交给主线的东西。单元内部按铺垫约 40%、发展约 40%、高潮与余韵约 20% 安排，中段每两三章要有受挫或新信息。相邻单元换冲突类型、场景或对手。每个单元的余韵里埋下下一个单元的引子。

## 注入要点·章节

> 章节规划时注入，不超过 400 字。

写明本章处在当前单元的铺垫、发展、高潮还是余韵。铺垫章要建立期待；发展章要有受挫或新信息；高潮章要集中爆发；余韵章交代后果并引出下一个问题。
