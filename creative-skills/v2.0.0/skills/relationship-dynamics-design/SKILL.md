# 人物关系动态

## 用途

把人物关系当作一条会变化的线来设计：关系从哪里开始、经过哪些转折、最后走到哪里。每次转折都要有触发事件，不能突然跳变。

## 何时使用 / 不适用

- **使用：** 确定人物群和卷规划时；本章包含关系转折、对峙、和解或告别的场景时；审核发现关系停滞、跳变或缺少动机时。
- **不适用：** 单个人物的设定（由主角设计、配角设计负责）。

## 方法

1. **【补写】写出关系的起点和终点。** 起点：两人现在是什么关系，彼此欠着什么、瞒着什么。终点：全书结束时他们会变成什么样。
2. **找到关系里的冲突来源。** 利益冲突、理念不合、误会、阵营对立，至少选一种。关系里没有张力，就没有戏。（来源：冲突升级，冲突要自然产生）
3. **【补写】列出关系的转折点。** 每个转折点写明：触发事件、谁做了什么选择、关系从什么变成什么。相邻两次转折之间要有足够的章节铺垫。
4. **关系线和主线互相影响。** 处理主线冲突时，关系线随之变化；关系出了问题，又反过来影响主线。（来源：冲突升级，多线交织）
5. **先建立，再冲击。** 想让关系破裂有分量，先要用具体的共同经历让读者相信这段关系。（来源：情感冲击，情感铺垫）
6. **【补写】关系用行为表现。** 关系的变化体现在称呼、距离、是否分享秘密、是否在关键时刻站出来，而不是靠旁白宣布"他们的关系变了"。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 两人从相识到生死之交只用了一章 | 补上共同经历和转折点 |
| 多年的挚友毫无原因地反目 | 写出触发事件和积累的裂痕 |
| 关系线和主线各写各的 | 让主线事件迫使关系做出选择 |
| 旁白说"他们和好了" | 用一个具体行为表现和好，比如重新喊回旧称呼 |

## 示例（自写）

```
关系：王府兄弟 萧承（兄）与萧衍（弟）
起点：兄长替弟弟挡过一次家法，弟弟敬他如父；兄长瞒着弟弟一桩与生母有关的旧事
冲突来源：误会＋阵营（弟弟被太子拉拢，兄长暗中站在另一边）
转折1（第3卷）：弟弟发现兄长截下了自己的奏折　→ 敬重变成怀疑
转折2（第5卷）：兄长为保弟弟，当众与他划清界限　→ 怀疑变成怨恨
转折3（终卷）：真相揭开时兄长已死　→ 怨恨变成无法弥补的悔
行为表现：弟弟从喊"大哥"改口称"世子"；结尾在灵前重新喊出"大哥"
```

## 自检清单

- [ ] 关系的起点、终点和冲突来源是否明确？
- [ ] 本章的关系变化是否有触发事件和人物选择？
- [ ] 关系变化是否用行为表现，而不是旁白宣布？
- [ ] 关系线是否和主线互相影响？

## 注入要点·规划

> 卷规划或本章含关系转折场景时注入，不超过 500 字。

写明关键关系的起点、终点和冲突来源（利益、理念、误会或阵营）。列出关系转折点，每个写明触发事件、谁做了什么选择、关系从什么变成什么。转折之间要有铺垫，不能跳变。关系的变化用行为表现：称呼、距离、是否分享秘密、关键时刻是否站出来。让主线事件迫使关系做出选择。
