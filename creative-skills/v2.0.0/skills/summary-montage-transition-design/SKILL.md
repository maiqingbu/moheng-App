# 概述、蒙太奇与转场

## 用途

处理场景和场景之间的部分：什么时候一笔带过，什么时候跳过时间，怎样从一个地点、时间或视角自然转到另一个，让读者始终清楚身在何处。

## 何时使用 / 不适用

- **使用：** 本章包含时间跳跃、地点转换、回忆或视角切换时；审核发现转场突兀、混乱、无意义或时间线不清时。
- **不适用：** 场景内部的展开（由场景契约和戏剧化呈现负责）。

## 方法

1. **该跳就跳。** 与场景目标无关的过程（吃饭、赶路、等待）直接跳过，用一句时间标记接上下一个重要时刻。（来源：场景转换，省略法；时间线处理，时间跳跃）
2. **时间和地点要标清楚**（来源：场景转换、时间线处理，时间标记）：
   - 跨度大时明确写出（"三个月后"）；
   - 跨度小时可以通过环境、动作、对话暗示（天色、伤口结痂、一句"好久不见"）。
3. **选择转场方式**（来源：场景转换，高级技巧）：
   - 物品串联：一件东西连接两个场景；
   - 对话引导：上一场景提到的事，成为下一场景的画面；
   - 情绪延续：跨越时间，但情绪连贯；
   - 思绪引导：从眼前进入回忆，再回到眼前。
4. **快慢分开用。** 不重要的过程快转；重要的转折、需要氛围或情绪积累时慢转，写出移动的过程和心境的变化。（来源：场景转换，快转换与慢转换）
5. **转换要有目的。** 每次切换都要推动剧情、增加信息、制造悬念或形成对比。转过去写一点无关内容又转回来的，删掉。（来源：场景转换，无意义转换）
6. **频率适中。** 一个场景完整展开后再转，不要几乎每段都换；也不要一个场景拖得过长。（来源：场景转换，转换频率）
7. **用蒙太奇压缩或对照。** 一段时间内的多次重复（训练、调查、准备）可以用几个短镜头概述；两个场景并列可以形成对比、制造紧张或暗示心境。（来源：场景转换，蒙太奇）
8. **回忆的进出要清楚。** 由眼前的触发物进入，回到眼前时要有明确的回神动作。（来源：时间线处理，闪回的进入与退出）

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 上一段在家，下一段已在千里之外，没有任何交代 | 加一句时间或移动标记 |
| 三个场景交叉，读者分不清现在在哪 | 每次切换用分隔，并让每个场景有明显特征 |
| 三天的准备写成三千字流水账 | 用三四个短镜头概述 |
| 回忆结束后读者不知道已回到现在 | 加一个回神动作，回到眼前的画面 |

## 示例（自写）

**蒙太奇式概述（准备听证会的五天）：**

> 第一天，他把证人的档案读了四遍。第二天，他在背面写满了名字，又一一划掉。第三天，苏晴没有来上班。第四天，他发现自己想不起母亲做的那道汤叫什么。第五天早上，他穿上了唯一一件没有褶皱的衬衫。

五天压缩成五句，每一句都推进了准备进度、关系或代价。

**物品串联转场：**

> 他把那张授权卡放回桌上，卡面朝下。
> ——
> 两天后，同一张卡出现在稽查科的证物袋里。

## 注入要点·章节

> 本章包含时间跳跃、转场或回忆时注入，不超过 400 字。

写明本章哪些过程直接跳过、哪些需要慢转。每次转场标明时间或地点的变化和转场的目的。

## 注入要点·写作

> 写作时注入，不超过 500 字。

与场景目标无关的过程一笔带过，用时间标记接上下一个重要时刻。大跨度明确写时间，小跨度可以用环境、动作或对话暗示。转场优先用物品、对话、情绪或思绪连接。多次重复的过程用几个短镜头概述。每次切换都要让读者立刻知道现在在哪里、是什么时候、是谁的视角。回忆由眼前的东西触发，结束时写一个回神动作。
