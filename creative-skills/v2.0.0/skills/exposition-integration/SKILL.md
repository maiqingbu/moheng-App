# 信息交代融入

## 用途

把背景、设定、前情、人物来历等信息，融进正在发生的情节里交给读者，而不是停下故事做说明。

## 何时使用 / 不适用

- **使用：** 本章需要交代设定、回顾背景或介绍新人物时；审核发现大段说明、人物对彼此早已知道的事互相解释、回忆过长时。
- **不适用：** 世界规则本身的设计（由世界规则负责）。

## 方法

1. **少即是多。** 只交代当前情节需要的那部分，其余留到需要的时候。（来源：世界观深化，展现原则；开头技巧，只介绍必要信息）
2. **在需要时交代。** 人物到了某地，才介绍某地；遇到某个势力，才介绍这个势力。（来源：世界观深化，需要时再说）
3. **通过行动、对话和冲突交代。** 交易中带出货币，争执中带出身份差异，被欺负的过程中带出社会结构。（来源：世界观深化，通过行动对话、通过冲突）
4. **【补写】对话交代要有理由。** 一个人只会对不知道的人解释。让新人、外人或有误解的人成为解释的对象；避免两个都知道的人互相复述。
5. **分散，并在重要处重复。** 一大块信息拆成几次给，每次一点；关键设定在后文自然地再提一两次，帮助读者记住。（来源：开头技巧，信息量过大的解决方法）
6. **回忆要短，要有触发，要有用。** 回忆由眼前的物、话、气味或地点触发；只写揭示关键信息的片段；进入和退出都要让读者清楚。（来源：时间线处理，闪回技巧）
7. **【补写】先制造疑问，再给答案。** 读者想知道的时候给出的信息，比提前给出的更容易被记住。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 章首三段讲城市历史 | 只留一句与当前情节有关的，其余分散到后文 |
| "你也知道，我们档案局成立于三十年前……" | 改为向新人或外人解释，或者干脆删除 |
| 回忆连续写了两千字，主线停住 | 压缩为最关键的片段，几百字以内 |
| 新人物登场先列出年龄、身高、来历 | 用一个动作和一句话展现他，来历以后再说 |

## 示例（自写）

**说明式：**

> 记忆修复需要两级授权，未经授权的修复会被吊销执照。林默的执照已经被暂停过一次。

**融入式：**

> 窗口后的办事员看了一眼屏幕，抬头："您的执照上有一次暂停记录。"她把申请单推回来，"二级授权那栏，需要主管签字。"
> 林默看着那个空格。上一次，就是因为它是空的。

授权规则、处罚、主角前科，都在一次办事受阻的过程中交代完毕，并且制造了压力。

## 自检清单

- [ ] 本章交代的信息是否都是当前情节需要的？
- [ ] 是否通过行动、对话或冲突交代，而不是停下来说明？
- [ ] 对话中的解释是否有一个不知情的听者？
- [ ] 回忆是否有触发、够短、揭示了关键信息？

## 注入要点·写作

> 本章需要交代信息时注入，不超过 500 字。

只交代当前情节需要的信息，其余留到以后。把信息放进行动、对话和冲突中，不停下来写说明段。对话中的解释必须有一个不知情的听者，避免知情的人互相复述。大块信息拆开分几次给，关键设定后文自然再提。回忆由眼前的物或话触发，只写关键片段，进入和退出要清楚。
