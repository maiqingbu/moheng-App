# 重复与疲劳评估

## 用途

检查跨章的重复：章节目标、情节模式、回报类型、章末钩子方式、常用句式和词语。长篇最容易在不知不觉中重复，读者会因此感到疲劳。

## 何时使用 / 不适用

- **使用：** 章节规划时（常驻，对照最近几章）；审核时；出现重复信号时。
- **不适用：** 单章内的用词精简（由文字与语感负责）。

## 评估维度与判断标准

需要输入最近若干章的目标、主要事件、回报类型、结尾方式。

| 维度 | 合格 | 不合格的信号 |
|---|---|---|
| 章节目标 | 与最近几章不同 | 与上一章目标相同或只换了说法 |
| 情节模式 | 冲突类型有变化 | 连续多次同一种套路（如"被轻视—打脸"） |
| 回报类型 | 有变化 | 同一种回报连续出现 |
| 升级维度 | 换维度升级 | 每次都只是"对手更强" |
| 章末方式 | 钩子类型有变化，并且每章推进 | 连续几章停在同一时刻或同一种悬念 |
| 措辞 | 无高频重复的句式和比喻 | 同一个比喻、口头禅、描写套语反复出现 |

来源：套路与爽点，避免套路疲劳；冲突升级，冲突要有变化；读者粘性，断章技巧；长篇连载管理，重复套路。

## 修改建议的写法

每条问题写成"位置、与哪一章重复、改法"。改法参考（来源：套路与爽点，避免套路疲劳）：

- 换形式：同样的回报换一种场景或方式呈现；
- 加新元素：在熟悉的模式里加一个新的变量；
- 深化：不只写结果，写出心理和后续影响；
- 换类型：打斗换智斗，个人换团队，外部换内部。

## 示例（自写）

> **位置：** 第 23 章章纲
> **与哪一章重复：** 第 19 章、第 21 章（三章都是"委托人隐瞒—林默修复发现真相—当面揭穿"）
> **改法：** 第 23 章改为"林默自己的记忆被人动过"——由主角成为被修复的一方，类型从外部调查换成内部危机。

## 注入要点·评估

> 章节规划或审核时注入，不超过 600 字。

对照最近几章检查：本章目标是否与之前重复；冲突模式、回报类型、升级维度、章末钩子方式是否连续雷同；是否有反复出现的比喻、口头禅、描写套语。每个问题写出位置、与哪一章重复、改法。改法从换形式、加新元素、深化心理和后续影响、换冲突类型中选择。
