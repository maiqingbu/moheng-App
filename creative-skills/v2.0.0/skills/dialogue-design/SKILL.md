# 对话

## 用途

让每一句对话都在做事：推进情节、暴露性格、制造或升级冲突、顺带交代必要的信息。不写人物轮流念说明书，也不写把心里话直接说穿的台词。

## 何时使用 / 不适用

- **使用：** 写作阶段遇到标注为"对话为主""信息揭示"的场景；审核发现对话生硬、像说明书、人物口吻分不清、心里话直说时。
- **不适用：** 情绪峰值的整体递进（由情绪场景负责）；世界观本身的设计。

## 方法

1. **每句对话至少做一件事。** 推进情节、展现性格、制造冲突，三者至少占一样；什么都不做的寒暄删掉。（来源：开头技巧，对话的作用）
2. **设定信息通过对话里的交易、争执、闲谈带出来，不要让人物向读者解释。** 两个人物都已知道的事情，不能用"你也知道"的方式再讲一遍。（来源：世界观深化，"通过角色行动和对话自然展现"；"你也知道"一句为【补写】）
3. **【补写】说出来的话和心里想的话不一样。** 重要的对话要有潜台词：人物想要什么、为什么不能直说、于是绕着说或者说反话。读者从语气、停顿、答非所问中读出真实想法。
4. **【补写】对话里要有角力。** 双方想要的东西不一样：一方追问，一方回避；一方试探，一方装傻。每一轮交锋，局面都要有一点变化。
5. **人物口吻要分得开。** 身份、性格、出身决定措辞、句子长短和口头禅。遮住说话人的名字，也能猜出是谁在说。冷硬的人说短句，油滑的人绕弯子。（来源：修改润色，"对话符合性格"；幽默喜剧，口头禅与标志性动作）
6. **用动作代替对话标签。** 少用"他说""她说"，必要时写一个动作，让动作同时交代谁在说话、处于什么状态。不要连续三句都用"说"。（来源：修改润色，替换法；"用动作代替标签"为【补写】）
7. **【补写】打断、沉默和答非所问都算对话。** 比起完整的一问一答，被打断的半句、没回答的问题、转移的话题更有张力。
8. **写完读出来。** 读着拗口、不像人话的地方就改。（来源：修改润色，朗读法）
9. **风格要和作品一致。** 轻松作品可以吐槽、玩梗；严肃作品要克制。同一部作品的对话风格前后统一。（来源：幽默喜剧，吐槽改写；修改润色，统一风格）

## 参考区间（【补写】，仅供参考）

- 对话为主的场景里，对话约占 50%～70%，其余是动作和反应。连续超过 6～8 轮没有动作和反应，就会变成一段念台词。
- 单句台词一般不超过 3 个短句。需要长篇说明的地方，拆成追问和回答。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| "你也知道，我们青州有三大宗门，灵石是货币……" | 改成一次买卖或争执，让信息作为附带内容出现 |
| 人物把心里话说穿："我其实很在乎你，只是不敢说。" | 改成绕开、说反话或做一个动作，让读者自己读出来 |
| 一问一答像审讯笔录 | 加入回避、打断、反问，让双方各有所求 |
| 所有人说话一个腔调 | 按身份和性格给每个人定措辞、句子长短、口头禅 |
| "他说……她说……他说……" | 用动作承担说话人提示，删掉多余的标签 |

## 示例（自写，演示手法）

情境：被逐之前的深夜，弟弟闯进兄长书房，想要一个解释。兄长有苦衷，不能明说。

**弱版：**

> "哥，你为什么要赶我走？"弟弟说。
> "因为有人说你私通外藩，我必须保住王府。"兄长说。
> "你相信那些流言吗？"弟弟说。
> "我不信，但我没有办法。我其实是为了保护你。"兄长说。

问题：
- 兄长把苦衷直接说穿，悲剧的误会也就不存在了；
- 一问一答，没有角力；
- 句句用"说"。

**改写版：**

> 门被推开的时候，兄长正在研墨。
>
> "书信是假的。"弟弟站在门口，没进来，"你知道。"
>
> 墨条在砚台里转了一圈。"夜深了。"
>
> "你知道。"
>
> "明早侧门备了车。"
>
> 弟弟走过来，一把按住砚台，墨溅了几点在账册上。"小时候你教我写字，说字如其人。那些信上的字，你看不出不是我的？"
>
> 兄长把账册挪开，拿袖子去擦那几点墨，擦不掉，越擦越开。
>
> "府里，"他说，"容不下你。"
>
> 弟弟松了手，笑了一声："是容不下我，还是容不下你那顶冠？"
>
> 兄长没有答，把一封封好的信压回了镇纸底下。

手法对照：

- 角力：弟弟追问，兄长回避（"夜深了""备了车"）。
- 潜台词：兄长始终不正面回答，读者从"擦不掉的墨"和"压回镇纸的信"里读出隐情。
- 用动作代替标签：研墨、按住砚台、擦墨、压信，几乎不用"说"。
- 口吻区分：弟弟句子急、带锋芒，兄长句子短、避重就轻。
- 信息附带出现：书信是伪造的、字如其人、信的存在，都在争执中带出，没有专门解释。

## 自检清单（审核环节使用）

- [ ] 每一句对话是否都在推进情节、展现性格或制造冲突？
- [ ] 有没有"你也知道"式的说明，或者人物向读者讲解设定？
- [ ] 重要对话有没有潜台词，还是把心里话直接说穿了？
- [ ] 遮住名字，能不能分清是谁在说话？
- [ ] 是否连续多句使用"说"，或者超过 6～8 轮对话里没有动作和反应？

## 注入要点·写作

> 选择器在写作环节、遇到"对话为主"或"信息揭示"场景时注入，不超过 1000 字。

写本场景的对话时：

1. 每句对话都要做事：推进情节、展现性格或制造冲突，删掉无用的寒暄。
2. 双方想要的东西不一样：一方追问，一方回避；一方试探，一方装傻。每一轮交锋，局面都要有变化。
3. 重要的心里话不要直接说出口。用回避、反话、答非所问、沉默和动作让读者自己读出来。
4. 设定和背景信息放进争执或交易里顺带说出，不写"你也知道……"。
5. 每个人物的口吻按身份和性格区分：措辞、句子长短、习惯用语。
6. 少用"他说""她说"，用动作提示谁在说话，同时交代这个人的状态。每 3～5 轮对话插入一个动作或反应。
7. 风格和作品保持一致：轻松的作品可以吐槽，严肃的作品要克制。
