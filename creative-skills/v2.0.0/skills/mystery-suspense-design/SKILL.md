# 悬念与谜团设计

## 用途

设计跨越多章甚至全书的谜团：读者想知道答案，作者按计划一点点给出线索，揭开时既意外又合理。也包括"读者知道而人物不知道"的紧张感。

## 何时使用 / 不适用

- **使用：** 全书和卷规划谜团时；本章包含调查、揭示或反转场景时；审核发现谜团不公平、长期停滞、揭示缺少铺垫或缺少悬念时。
- **不适用：** 章末的单章钩子（由章末钩子负责）；单个伏笔的登记与回收（由伏笔与回收负责）。

## 方法

1. **【补写】分清三种悬念：**
   - 谜团：读者不知道答案（谁做的、为什么、是什么）；
   - 紧张：读者知道危险，人物不知道（来源：多线叙事，信息差）；
   - 期待：读者知道会发生，想看怎么发生。
2. **【补写】谜团写出"问题—答案—线索链"。** 先定答案，再倒推三到五条线索，按由远到近的顺序分布在多章里。每条线索都要能在揭示后被读者回头认出来。
3. **悬念要持续加深。** 抛出问题之后，下一次接触要么给出部分答案并带出新问题，要么提高问题的分量。不要原样重复。（来源：读者粘性，悬念加深）
4. **【补写】公平原则。** 揭示所依赖的关键信息，必须在之前出现过；不能靠揭示时才第一次出现的人或物。
5. **【补写】误导要有依据。** 可以引导读者往错误方向猜，但错误答案也要有合理的证据，揭示后两种解释都说得通，以真相更完整。
6. **揭示按"布局、交锋、破局、揭露"推进**，最后可以再加一次反转，但反转同样要有前文依据。（来源：高潮设计，智斗高潮）
7. **信息差不能长期失衡。** 读者知道而人物不知道的状态不能拖太久，该让人物知道时要让他知道。（来源：多线叙事，信息平衡）
8. **【补写】揭示的时机。** 一个谜团解开时，最好同时打开一个更大的谜团，让悬念接力。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 凶手在揭示那一章才第一次登场 | 提前让他出现，并留下至少两条线索 |
| 谜团提出后二十章没有任何进展 | 每隔几章给出一条部分答案或新线索 |
| 反转只是为了意外，前后矛盾 | 回头补上依据，或取消反转 |
| 人物一直蒙在鼓里，读者早已不耐烦 | 安排一次让人物得知的事件 |

## 示例（自写）

```
谜团：姐姐为什么被抹去？
答案：她是自愿的——她发现自己记忆里的证据会害死弟弟，于是主动申请删除
线索链：
  第12章 姐姐的旧书桌上，档案局的申请表回执（读者以为是被迫）
  第58章 黑市中介说"有人花钱买自己被忘记"（当作闲话带过）
  第97章 被修复的记忆中，姐姐穿着档案局制服（误导：以为她是加害者）
  第150章 姐姐留下的录音只剩半句："别来找我，是为了你……"
  揭示（第225章）：申请表上是她本人的签名
误导：读者被引导怀疑姐姐是组织成员；揭示后，制服的线索两种解释都成立
接力：揭示的同时，引出"她看到的证据是什么"这个更大的问题
```

## 自检清单

- [ ] 答案是否先定好，线索是否由远到近分布？
- [ ] 揭示依赖的关键信息是否在之前出现过？
- [ ] 悬念是否在持续加深，而不是原样重复？
- [ ] 误导是否也有合理依据？
- [ ] 信息差是否拖得太久？

## 注入要点·规划

> 全书或卷规划谜团时注入，不超过 600 字。

每个谜团先定答案，再倒推 3～5 条线索，按由远到近分布在多章里。揭示依赖的关键信息必须提前出现。误导读者时，错误答案也要有依据，揭示后真相解释得更完整。每隔几章给出部分答案或新线索，让悬念加深而不是重复。一个谜团解开时，打开一个更大的问题。

## 注入要点·章节

> 本章含调查、揭示或反转场景时注入，不超过 400 字。

写明本章推进的是哪个谜团、给出哪条线索或部分答案、带出什么新问题。揭示场景按布局、交锋、破局、揭露推进，所用的关键信息必须是前文出现过的。读者知道而人物不知道的状态如果已拖很久，本章要考虑让人物得知。
