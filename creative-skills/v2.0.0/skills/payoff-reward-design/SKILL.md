# 回报（爽点）设计

## 用途

安排读者得到满足的时刻：反击、证明、获得、真相、和解。回报要有铺垫、有反差、有后续，并且类型和密度都要符合读者承诺。

## 何时使用 / 不适用

- **使用：** 卷规划分配回报时；本章角色是"回报"或"高潮"时；审核发现缺少回报、回报太弱、类型重复或密度不当时。
- **不适用：** 全书的核心体验定位（由读者承诺负责）；高潮场面的写法细节（由动作冲突场景等负责）。

## 方法

1. **选择回报类型**（来源：套路与爽点；读者粘性，爽点类型）：
   - 反击或证明：被看轻之后用实力回应；
   - 升级：能力突破；
   - 获得：宝物、资源、地位、认可；
   - 逆转：绝境翻盘；
   - 复仇：旧账清算。

   【补写】严肃或悲剧向的作品，回报也可以是：真相落地、和解、牺牲被理解、遗憾成为定局。
2. **先压后放。** 回报之前要有足够的压抑和铺垫；压得越实，放的时候越痛快。（来源：套路与爽点，打脸的设置技巧）
3. **要有反差。** 对手的轻视或局面的绝望，与最终结果之间要有明显落差。
4. **要有反应。** 写出旁人、对手的反应，以及主角得到的好处。回报之后交代后续影响，不要匆匆收尾。（来源：套路与爽点；高潮设计，收尾草率）
5. **对手不能太弱。** 碾压无脑的对手没有快感；回报要有一定难度。（来源：套路与爽点，碾压的注意事项）
6. **按阶段控制密度**（来源：套路与爽点，爽点密度控制）：
   - 前期密，用来吸引和留住读者；
   - 中期稍疏，以升级、获得、击败强敌为主；
   - 后期跟着情节走，集中在大战和终局。
7. **可以组合。** 连环回报（一个接一个）或递进回报（小成就到大成就）。（来源：高潮设计，爆发方式；套路与爽点，组合）
8. **避免疲劳。** 同一种回报不要连续使用；换形式、换场景，或者加入心理和后续影响，让它有新意。（来源：套路与爽点，避免套路疲劳）

## 参考区间（来源经验，按作品调整）

| 阶段 | 爽文 | 正常节奏 | 严肃向 |
|---|---|---|---|
| 前期 | 每章约 1 个 | 约每 2 章 1 个 | 稀疏但必须有 |
| 中期 | 约每 2～3 章 1 个 | 约每 3 章 1 个 | 以情感兑现为主 |

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 刚被嘲讽，下一段就打脸 | 延长压抑，让反差更大 |
| 打完就切下一个场景 | 补上对手和旁人的反应、主角的收获 |
| 连续五章都是同一种打脸 | 换类型：获得、智斗、真相 |
| 对手愚蠢得毫无威胁 | 提高对手的能力，回报要有难度 |
| 悲剧向作品硬塞爽点 | 改用真相、理解或遗憾作为回报 |

## 示例（自写）

```
回报：听证会反击（第2卷高潮，第128章）
压：副局长当众出示主角越界修复的录像，搭档被要求作证指控他（第121–127章逐步加压）
放：主角当场修复证人的记忆，证人说出是副局长下令抹去证据
反差：从"被告"变成"揭发者"
反应：旁听席哗然；副局长第一次失态；搭档没有开口作证，而是默默撤回了证词
收获：执照恢复（获得）＋搭档关系出现裂缝中的转机（情感）
代价：主角当众忘记了自己的生日——回报中掺着代价，符合本书承诺
```

## 自检清单

- [ ] 回报类型是否符合读者承诺？
- [ ] 回报前是否有足够的压抑和铺垫？
- [ ] 是否写出了反差、反应和收获？
- [ ] 对手是否有足够难度？
- [ ] 与最近几次回报相比，类型或形式是否有变化？

## 注入要点·规划

> 卷规划时注入，不超过 600 字。

按读者承诺选择回报类型，按阶段控制密度：前期密，中期稍疏，后期集中在大战和终局。严肃或悲剧向作品用真相、和解、牺牲被理解、遗憾落地作为回报。回报分小、中、大逐级递进，同一种回报不要连续使用。

## 注入要点·章节

> 本章角色为回报或高潮时注入，不超过 500 字。

写明本章回报的类型、之前的压抑来自哪里、反差是什么、谁会有什么反应、主角得到什么、留下什么后续影响。对手要有一定难度。和最近几次回报相比要换类型或换形式。

## 注入要点·写作

> 写作回报章时注入，不超过 400 字。

回报前把压抑写实；回报时写清楚反差；回报后写出对手和旁人的反应、主角的收获和后续影响，不要匆匆收尾。
