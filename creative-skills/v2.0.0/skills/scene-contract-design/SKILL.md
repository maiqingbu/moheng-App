# 场景契约（场景卡）

## 用途

为每个场景写一张"契约卡"：谁想要什么、什么在阻止、场景中发生了什么转折、结束时局面变成了什么。规划阶段用它保证每个场景都有作用，写作阶段用它保证每个节拍都写够、写实。

## 何时使用 / 不适用

- **使用：** 章节规划时（常驻）；写作时作为场景结构的依据；审核发现场景没有目标、没有转折、重复，或者节拍展开不足时。
- **不适用：** 跨章的单元结构（由段落架构负责）。

## 方法

1. **【补写】每个场景写出五项：**
   - 视角人物：从谁的眼睛看；
   - 目标：他在这个场景里想得到什么；
   - 阻力：谁或什么在阻止（来源：冲突升级，冲突公式）；
   - 转折：场景中途发生的、改变局面的事情；
   - 结果：结束时局面变好还是变坏，以及新的问题。
2. **【补写】结果要和开始不同。** 场景开始和结束时，人物的处境、关系或认识至少有一项变化。没有变化的场景，要么合并，要么删除。（来源：修改润色，删除冗余；冲突升级，冲突要推动剧情）
3. **【补写】每个场景拆成 2～4 个节拍。** 节拍是场景里一次完整的"行动—反应"：试探、交锋、受挫、反击、发现、决定。每个节拍写明在这一步发生了什么、局面怎样推进。
4. **节拍的篇幅要撑得住。** 一个节拍需要有动作、对话、感受和细节的展开，通常需要几百字；一个场景需要完整展开后再转场。（来源：场景转换，一个场景的篇幅参考）
5. **按章节目标篇幅分配场景和节拍。** 先确定本章的篇幅区间，再决定场景数量和每个场景的节拍数，让总量自然落在区间里。不能规划太少的内容硬撑篇幅，也不能塞太多内容导致每个节拍都只有一句。
6. **【补写】场景之间要有因果。** 前一个场景的结果，引出后一个场景的目标。用"因此"或"但是"连接，不用"然后"。

## 参考区间（按章节篇幅换算，需负责人确认）

- 单个节拍：约 250～400 字；
- 单个场景：2～4 个节拍；
- 2000～3000 字的章节：通常 2～3 个场景、共 6～9 个节拍。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 场景里人物只是闲聊，结束时一切照旧 | 给他一个目标和阻力，让结果改变局面 |
| 一个场景只有一个动作，一句话写完 | 拆成 2～4 个节拍，逐个展开 |
| 场景之间用"然后"串起来，没有因果 | 让前一个结果引出后一个目标 |
| 为了凑篇幅，同一个节拍反复描写 | 增加真正的节拍（新的受挫、新的发现），或在规划阶段增加场景 |

## 示例（自写）

```
场景2：档案库潜入（视角：林默）
目标：在巡查换班的十分钟内，拿到姐姐的封存档案
阻力：电子锁需要两级授权；苏晴今晚值班
节拍1 试探：用委托人的旧工牌刷开外门，发现内门锁已更换（约 300 字）
节拍2 受挫：苏晴的脚步声出现，他躲进档案架之间，听见她在打电话替他请假（约 350 字）
节拍3 转折：苏晴离开前，故意把自己的授权卡留在了桌上（约 350 字）
节拍4 决定：他拿起卡，又放下——用了它，苏晴就会被追责（约 300 字）
结果：档案没拿到（局面变坏），但他第一次知道苏晴在暗中帮他（关系变化）；新问题：她为什么要帮他？
```

## 自检清单

- [ ] 每个场景是否写明视角、目标、阻力、转折、结果？
- [ ] 每个场景结束时是否有局面、关系或认识的变化？
- [ ] 每个场景是否有 2～4 个节拍，并且每个节拍都有推进？
- [ ] 场景和节拍的总量是否与本章篇幅区间匹配？
- [ ] 场景之间是否有因果连接？

## 注入要点·章节

> 章节规划时注入，不超过 700 字。

每个场景写明视角人物、目标、阻力、转折、结果，结束时处境、关系或认识至少一项变化。每个场景拆成 2～4 个节拍，每个节拍写明这一步发生了什么、局面怎样推进。按本章篇幅区间分配场景和节拍数量（每个节拍约 250～400 字），既不能内容太少硬撑篇幅，也不能塞太多导致节拍只剩一句。场景之间用"因此"或"但是"连接。

## 注入要点·写作

> 写作时注入，不超过 500 字。

按场景卡逐个节拍展开。每个节拍都要写出动作、对话、人物的感受和具体细节，不要用一句概述带过。篇幅不足时，展开规划中已有的节拍，不要添加与场景目标无关的描写或重复内容。
