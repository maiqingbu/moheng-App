# 作品核心设定（立项）

## 用途

把一个模糊的创意压缩成能写几十万字的核心设定：一句话就能说清楚的故事发动机。它要回答四个问题：主角想要什么、什么在阻止他、读者凭什么一直看下去、和同类作品有什么不同。

## 何时使用 / 不适用

- **使用：** 用户给出创意或选择市场方向之后；生成故事方向时；审核发现创意太空泛、只有氛围没有冲突、和同类作品没有区别时。
- **不适用：** 具体的世界规则（由世界规则负责）；分卷和主线（由主线设计负责）。

## 方法

1. **【补写】一句话核心设定**：谁、想要什么、因为什么无法轻易得到、如果失败会怎样。这四个要素缺任何一个，故事就没有发动机。
2. **找到核心冲突**：角色想要的东西，加上阻止他的人或事，就是冲突。阻力必须能持续、能升级，才撑得起长篇。（来源：冲突升级，冲突公式）
3. **从一个核心设定往外推演**：这个设定会带来什么社会结构、什么矛盾、主角为什么会卷进去。推演得越顺，世界和动机就越统一。（来源：世界观深化，推演法）
4. **说清楚新在哪里**：先承认它属于哪种成熟的模式，再写明在模式之上的变化，比如"代价机制""身份反转""换一个视角"。完全没有套路基础风险大，完全照搬没有吸引力。（来源：套路与爽点，套路与创新）
5. **【补写】检查能不能写长**：列出三个可以逐步升级的阶段。列不出来，说明设定只够写短篇，需要扩大冲突的范围或加深代价。（来源方向：长篇架构，主线不清晰会在中期卡文）
6. **【补写】主题和卖点一致**：如果作品要的是悲剧感，核心设定里就要有"人物出于善意却走向毁灭"的结构；如果要的是爽感，核心设定里就要有"被压制，然后反击"的空间。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| "一个关于成长和救赎的故事" | 写出谁、想要什么、被什么阻止、失败的后果 |
| 只有一个很酷的世界设定，没有人物欲望 | 让设定直接制造主角的欲望或困境 |
| 冲突在开篇就能解决 | 让阻力来自更大的结构，可以逐级升级 |
| 和热门作品只有名字不同 | 写明在套路之上的具体变化 |

## 示例（自写）

**弱版：** "一个关于记忆和失去的都市故事。"

**改写版：**

> 一个能修复他人被篡改记忆的年轻调查员（谁），想找回在公共档案中被"抹去"的姐姐（欲望）；但每修复一段记忆，他自己就会失去一段真实的过去（阻力，并且会持续加重）。如果停下来，姐姐就永远消失；如果继续，他会先忘记自己为什么出发（代价）。

**新意：** 能力本身就是代价，而且越接近真相，失去的越多。

**能写长的三个阶段：**
1. 第一次发现代价；
2. 发现篡改背后有组织；
3. 必须在找回姐姐和保住自己之间做最后的选择。

## 自检清单

- [ ] 一句话里是否有人物、欲望、阻力和失败的后果？
- [ ] 阻力能不能持续、能不能升级？
- [ ] 新意是否具体？
- [ ] 能不能列出三个逐步升级的阶段？

## 注入要点·立项

> 生成方向或确定核心设定时注入，不超过 700 字。

每个核心设定都要写出一句话：谁、想要什么、被什么阻止、失败会怎样。阻力要来自能持续升级的人或结构。从核心设定推演出它带来的社会矛盾，以及主角卷入的原因。写明它属于哪种成熟的模式，以及在模式之上新在哪里。列出三个可以逐步升级的阶段，证明它能写长。
