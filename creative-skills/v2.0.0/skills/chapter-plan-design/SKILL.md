# 章节规划（节拍级）

## 用途

把"这一章要发生什么"拆成场景，再把场景拆成节拍，让每个场景都有足够、具体的故事内容。字数由节拍自然撑起来，而不是让写作环节去注水。

## 何时使用 / 不适用

- **使用：** 每一章的规划环节；审核发现"场景只是概述""篇幅不足""与上一章目标重复"之后，重新规划时。
- **不适用：** 卷级、全书级规划（由卷规划、主线设计负责）；具体句子怎么写（由写作环节和场景类 Skill 负责）。

## 方法

1. **先确认本章推进了什么。** 对照上一章的目标和结尾写下本章的推进点：发生了什么不可逆的变化，比如关系、处境、信息或实力。如果和上一章只是同一件事换个说法，本章不成立，必须换推进点。
2. **一章写一个完整情节，按起承转合安排。** 起是本章要面对的问题，承是尝试或推进，转是意外、代价或反转，合是阶段结果加上留给下一章的问题。（来源：节奏控制，"标准章节：一个完整情节，起承转合"）
3. **拆场景。** 通常 3～5 个场景。每个场景写清四件事：
   - 目的：这个场景要改变什么；
   - 冲突：阻力来自谁或什么；
   - 转折：场景里发生了什么意外或代价；
   - 结果：场景结束时局面有什么不同。

   不满足这四项的场景要合并或删除。（来源：修改润色，"不推动剧情、不塑造人物、不营造氛围的情节——删"）
4. **拆节拍。** 每个场景写 2～4 个节拍。一个节拍是一次具体的"动作／对话／发现＋反应"，要能直接演出来，不能是概述。
   - 节拍数量和场景预计字数挂钩：大约 250～400 字一个节拍。预计 800 字的场景至少要 2 个、最好 3 个节拍。
   - 节拍不够，说明内容不够撑起这个篇幅：应该补情节（新的阻力、新的信息、人物的选择），而不是把预计字数调小去凑区间，也不是让写作环节注水。
5. **标注场景类型**（选择器要用）：情绪峰值、动作冲突、信息揭示、对话为主、过渡、日常。
6. **标注本章角色**（节奏用）：普通、重要、高潮、过渡。本章角色决定本章在用户字数区间里大致落在哪一段。
7. **章末留一个问题。** 章末问题要从本章实际发生的变化里自然长出来，不要硬加悬念。具体做法由章末钩子 Skill 负责。
8. **场景之间可以跳过无关的时间。** 吃饭、赶路、睡觉这类内容不单独成场景，用一句时间跳转带过就行。（来源：场景转换艺术，省略法）

## 参考区间（来自原文，仅供参考）

| 本章角色 | 原文经验字数 | 用法 |
|---|---|---|
| 普通章节 | 2000～2500 字 | 落在用户区间的中下段 |
| 重要情节 | 3000～4000 字 | 落在用户区间的上段 |
| 高潮章 | 4000～5000 字 | 落在用户区间的上限；如果用户区间放不下，就把高潮拆成两章 |
| 快节奏推进的短章 | 1500～2000 字 | 只在用户区间允许时使用 |

来源：节奏控制，"章节长度分配"。用户设定的区间优先，原文经验只用来决定落在区间的哪一段。

## 失败写法与改法

| 失败写法 | 问题 | 改法 |
|---|---|---|
| 场景只有一句描述，或者只有预计字数 | 写作时没有东西可写，只能概述，篇幅自然不够 | 每个场景补齐目的、冲突、转折、结果，再写 2～4 个节拍 |
| 本章目标和上一章几乎一样 | 故事原地打转，读者觉得在重复 | 先写清"本章发生了什么不可逆的变化"，换掉重复的推进点 |
| 四个场景全是"主角想／主角感到" | 内心独白撑不起篇幅，也没有戏 | 每个场景至少有一个外部阻力或另一个人物的行动 |
| 为了凑区间把每个场景的预计字数都写大 | 写作时只能注水 | 按节拍数量反推字数；节拍不够就补情节 |
| 结尾总是"真正的战争才刚刚开始"这类话 | 套话，没有具体的下一步问题 | 结尾问题要指向一个具体的人、物或决定 |

## 示例（自写，演示手法）

题材：王府兄弟，悲剧。本章是兄长逐弟出府的那一章，本章角色是"重要"，用户区间 2000～3000 字。

**弱版：**

```
场景1 预计600字：兄弟发生争执
场景2 预计800字：兄长做出决定
场景3 预计700字：弟弟离开王府
场景4 预计500字：兄长独自留下
```

问题：只有一个梗概，没有阻力、没有转折。写作环节只能概述，大约写到 1200 字就写完了。

**改写版：**

```
本章推进：弟弟被逐出王府（不可逆）；读者第一次看到兄长另有隐情（为后文埋下真相）。

场景1 情绪峰值 预计700字
  目的：把兄弟的矛盾当众挑明
  冲突：宗族长辈施压，要求给"私通外藩"的流言一个交代
  节拍：①长辈把截获的书信摔在案上 ②弟弟辩解，兄长始终不看他 ③兄长开口，只说了一句"府里容不下你"
  结果：弟弟以为兄长信了流言

场景2 对话为主 预计800字
  目的：兄弟最后一次私下对话，两人都没说真话
  冲突：弟弟要一个解释，兄长不能给
  节拍：①弟弟深夜闯进书房 ②提起少年时在海棠树下学字的往事，兄长转身去研墨 ③弟弟说"你从来只顾自己的爵位"，兄长没有反驳 ④兄长把一封封好的信压在镇纸下，没有交给他
  结果：误会加深；信留在了书房里（伏笔）

场景3 过渡 预计500字
  目的：弟弟离府
  节拍：①清晨的侧门，只有老仆来送 ②老仆往他行李里多塞了一件冬衣，说是"府里的规矩"
  结果：弟弟上路；冬衣其实是兄长吩咐的（读者能察觉，弟弟不知道）

场景4 情绪峰值 预计600字
  目的：在兄长身上留下真相的裂缝
  节拍：①兄长回到书房，把镇纸下的信投进火里，又在烧着之前抽了回来 ②信里夹着一张少年时写坏的字帖
  结果：章末问题——兄长到底在防谁？
```

节拍一共 11 个，按每个 250～400 字算，大约 2750～4400 字。这样字数是情节撑起来的；如果算下来超出区间上限，就删掉最弱的那个节拍。

## 自检清单（审核环节使用）

- [ ] 本章是否有一个和上一章不同的、不可逆的推进？
- [ ] 每个场景是否都写齐了目的、冲突、转折、结果？
- [ ] 每个场景是否有 2～4 个可以直接演出来的节拍？
- [ ] 节拍数量和预计字数是否大致对得上（约 250～400 字一个节拍）？
- [ ] 是否至少有一个场景存在外部阻力或其他人物的行动？
- [ ] 章末问题是否具体，并且来自本章实际发生的变化？

## 注入要点·规划

> 选择器在规划环节注入本段，不超过 1200 字。

规划本章时，按以下要求执行：

1. 先写出本章推进：本章发生了什么不可逆的变化。这个变化不能和上一章的目标、结尾重复。
2. 本章是一个完整情节，按起承转合安排。拆成 3～5 个场景。
3. 每个场景写清四项：目的、冲突（阻力来自谁或什么）、转折、结果。不满足的场景要合并或删除。
4. 每个场景列出 2～4 个节拍。节拍是可以直接演出来的"动作／对话／发现＋反应"，不能是概述。
5. 每个场景的预计字数按节拍数量估算，大约 250～400 字一个节拍。节拍不够时补情节（新的阻力、信息或人物选择），不要把预计字数写大去凑区间。
6. 给每个场景标注类型：情绪峰值、动作冲突、信息揭示、对话为主、过渡、日常。给本章标注角色：普通、重要、高潮、过渡。普通章落在字数区间的中下段，重要章和高潮章落在上段。
7. 章末留一个具体的问题，要从本章发生的变化里自然产生，不要用"一切才刚刚开始"这类套话。
8. 无关的时间（吃饭、赶路）不单独成场景，用一句时间跳转带过。
