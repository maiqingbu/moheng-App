# 节奏与密度

## 用途

决定每一章、每一段落快还是慢，以及事件和冲突的密度，让读者既不疲劳，也不觉得拖沓。节奏指的是变化的频率和张弛的交替，不是单纯把句子写短，也不是一直打斗。

## 何时使用 / 不适用

- **使用：**
  - 规划阶段确定本章角色和密度；
  - 高潮章及其前后两章；
  - 审核发现拖沓、过赶、一直高潮、连续几章同一模式时。
- **不适用：** 单个句子的修辞（由修改润色负责）；某个情绪场景内部的递进（由情绪场景负责）。

## 方法

1. **先判断所处阶段，阶段决定整体基调。**（来源：节奏控制，不同阶段的节奏控制）
   - 开篇阶段：快。尽早让读者看到主角的特殊之处和第一个小回报，每章都有可感知的推进。
   - 中期：稳。快慢结合，留出篇幅加深人物和世界，支线展开，设置中期高潮。
   - 后期：收。加快主线，回收伏笔，收束支线，推向最终高潮。
2. **按张弛交替安排章节。** 紧张的几章后面接一到两章放松（日常、休整、感情、后果的消化），再进入更紧张的一段。高潮之后一定要有过渡章。（来源：节奏控制，张弛变化；长篇架构设计，"紧张后必有放松，高潮后必有过渡"）
3. **控制情节密度。**
   - 高密度章：一章之内完成"遇敌、冲突、过程、结果、收获"。
   - 低密度章：日常、人物互动、心理和环境描写。

   两种交替使用，不要连续多章都是同一种密度。
4. **快和慢有各自的手段。**（来源：长篇架构设计，节奏调控方法）
   - 加快：缩短章节；提高对话和动作的比例；更快地切换场景。
   - 放慢：增加细节、环境、内心独白和日常；把关键时刻展开写。
5. **防止重复。** 和最近 3～5 章比较场景模式、冲突来源、情绪温度、结尾方式。连续两章是同一种模式，就要换。
6. **回报的间隔要可预期。** 读者等待的东西，比如突破、真相、打脸、表白，不要长期空窗，也不要全部扎堆。

## 参考区间（来自原文，仅供参考）

| 项目 | 开篇阶段 | 中期 | 后期 |
|---|---|---|---|
| 小回报（爽点）频率 | 大约每章 1 个 | 大约 2～3 章 1 个 | 跟随情节，以大回报为主 |
| 张弛交替 | 偏快 | 约紧张 5 章 → 放松 2 章 | 高潮段 10 章左右，之后放松 3 章 |
| 关键节点 | 3 章内亮出主角的特殊之处，10 章内有第一次明显的反击 | 设置中期高潮 | 留篇幅处理伏笔和支线，再进入终局 |

来源：节奏控制，开篇和中期的具体要求、爽点分布、交替模式。这些是网文常见的经验数字，要按题材调整。原文对比了玄幻、都市、历史、科幻的不同节奏：历史题材前慢后快，都市题材日常较多。悲剧和文艺向作品的回报不是"爽点"，而是情感兑现，频率可以更低。

## 失败写法与改法

| 症状 | 原因 | 改法 |
|---|---|---|
| 一章挤进好几个大事件，读者没有喘息 | 怕读者流失，一味加码 | 拆成两章，中间加一个后果或人物反应的场景 |
| 连续几章没有推进，大段铺垫 | 铺垫过度，缺少冲突 | 删掉无关内容，把下一个冲突提前 |
| 一直在高潮，越写越没力气 | 不敢降节奏 | 高潮之后安排过渡章，用对比恢复下一次高潮的冲击力 |
| 每章都是"遭遇—入侵—得手—新危机" | 没有比较最近几章的模式 | 换冲突来源（人际、内心、环境），或者换一章日常推进关系 |

## 示例（自写，演示手法）

一段 8 章的章节角色安排（都市悬疑）：

```
第11章 普通·高密度  追查线索，与对手第一次正面交锋（小回报：拿到关键证据）
第12章 普通·中密度  证据引出新疑点，主角与搭档产生分歧
第13章 重要·高密度  潜入对手据点，计划出错，搭档被困
第14章 高潮·高密度  营救＋对峙，真相揭开一角（大回报）
第15章 过渡·低密度  后果：搭档受伤，两人在医院第一次说真话（关系推进）
第16章 普通·中密度  新的委托出现，表面无关，实际与真相相连
第17章 普通·低密度  主角回到日常，失去的记忆痕迹再次出现（为下一段埋线）
第18章 重要·高密度  第二轮追查开始
```

要点：

- 第 14 章是高潮，后面紧跟一个低密度的过渡章（第 15 章）。
- 第 15 章虽然慢，但关系有实质推进，并不是"空着"。
- 第 12、16 章冲突来源换成了人际和委托，避免连续几章都是"潜入—得手"的模式。

## 自检清单

- [ ] 本章角色（普通、重要、高潮、过渡）和实际写出来的密度是否相符？
- [ ] 和最近 3～5 章相比，场景模式、冲突来源、结尾方式是否重复？
- [ ] 高潮章后面有没有安排过渡或消化后果的段落？
- [ ] 读者在等待的回报是否空窗太久，或者全部扎堆？
- [ ] 有没有一章挤进多个大事件、读者喘不过气的情况？

## 注入要点·规划

> 选择器在规划环节注入，不超过 900 字。

安排本章节奏时：

1. 根据所处阶段定基调：开篇阶段快，每章都要有可感知的推进和一个小回报；中期快慢结合，留篇幅加深人物和关系；后期加快主线，回收伏笔。
2. 确定本章角色（普通、重要、高潮、过渡）和密度（高密度：一章之内完成冲突到结果；低密度：日常、互动、消化后果）。
3. 高潮之后必须安排过渡。连续两章不能是同一种场景模式和冲突来源，要参照最近几章的目标和结尾来换。
4. 加快的手段：对话和动作比例更高，场景切换更快。放慢的手段：展开关键时刻的细节、环境和内心。慢章也必须有实质推进，比如关系、信息或后果。

## 注入要点·审核

> 选择器在审核环节注入，不超过 700 字。

从节奏的角度检查本章：

- 实际密度是否符合本章角色？
- 是否和最近 3～5 章的模式重复（场景模式、冲突来源、结尾方式）？
- 是否一章挤进了多个大事件？是否整章没有推进？
- 读者在等待的回报是否空窗太久？

发现问题时，给出具体的段落位置和调整建议（拆分、提前、增加后果场景、更换冲突来源），不要只给评分。
