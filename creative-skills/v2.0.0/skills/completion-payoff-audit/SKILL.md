# 完结回报审计

## 用途

在进入终局前和全书完结后，逐项核对这本书欠读者的东西有没有还上：读者承诺、核心冲突、伏笔、谜团、人物弧线、重要关系、支线。

## 何时使用 / 不适用

- **使用：** 进入终卷前（预审，用于安排终局）；全书完结后（终审）。
- **不适用：** 终局的结构设计（由终局设计负责）。

## 评估维度与判断标准

| 维度 | 合格 | 不合格的信号 |
|---|---|---|
| 读者承诺 | 承诺清单逐条兑现 | 主体验在结局缺席，或被另一种体验取代 |
| 核心冲突 | 有明确的解决，并且由主角的选择解决 | 外力解决，或含糊带过 |
| 伏笔 | 全部回收或有意保留 | 有遗忘的伏笔 |
| 谜团 | 答案揭开且公平 | 关键谜团未解，或答案没有前文依据 |
| 人物弧线 | 主角和重要配角到达终点 | 弧线中断，人物停在半路 |
| 重要关系 | 有落点 | 关系线无疾而终 |
| 支线 | 汇聚或有交代 | 支线人物和事件消失 |
| 余韵 | 有余韵，交代了后续 | 决战后立刻结束 |

来源：长篇连载管理，完本准备；长篇架构，第三幕；修改润色，结构检查；高潮设计，收尾检查。

## 修改建议的写法

- **预审（终卷前）：** 输出"待兑现清单"。每一项写明来源（承诺清单条目、伏笔编号、弧线、支线），以及建议在终局的哪一段兑现。（来源：长篇连载管理，提前梳理）
- **终审（完结后）：** 每个未兑现项写明"缺口、影响、补救方式"。补救方式包括：补一段回收、在余韵章交代、或者明确标为有意保留。

【补写】有意保留（开放式结尾、留给续作）必须是在规划中明确写过的，不能用来掩盖遗忘。

## 示例（自写，预审清单片段）

| 来源 | 内容 | 状态 | 安排 |
|---|---|---|---|
| 承诺 2 | 物件（旧烫伤／授权卡）意义反复变化 | 待兑现 | 终极对决中最后一次改变意义（第 232 章） |
| F02 | 姐姐的申请回执 | 待回收 | 第 225 章揭示 |
| 苏晴弧线 | "规则需要有人去修" | 待完成 | 第 216–225 章 |
| 支线 C | 黑市中介老周 | 无交代 | 余韵章一句交代去向 |
| 谜团 | 姐姐看到的证据是什么 | 有意保留？ | 规划中未写明保留 → 必须揭开 |

## 注入要点·评估

> 进入终卷前或完结后注入，不超过 800 字。

逐项核对：读者承诺清单是否兑现；核心冲突是否由主角的选择解决；伏笔是否全部回收或在规划中写明保留；谜团是否揭开且有前文依据；主角和重要配角的弧线是否到达终点；重要关系是否有落点；支线是否汇聚或交代；结局后是否有余韵。预审时输出待兑现清单并安排到终局各段；终审时对每个缺口写出影响和补救方式。未在规划中写明的保留，一律视为未兑现。
