# 人物登场

## 用途

让一个重要人物第一次出现时，就通过行动和选择让读者记住他是谁、想要什么、和主角是什么关系。不要用一段简历式的介绍来代替登场。

## 何时使用 / 不适用

- **使用：** 主角在开篇登场；重要配角或反派第一次出场；审核发现人物是用标签介绍出来的（"他是个冷酷的人"）、登场平淡、读者记不住时。
- **不适用：** 人物长期的变化（由人物弧负责）；关系的长期演变（由关系动态负责）。

## 方法

1. **让人物在行动中登场。** 第一次出现时，他正在做一件能体现性格的事，最好是一个需要选择的处境。（来源：开头技巧，"主角特点通过事件、对话、冲突展现"）
2. **【补写】一个登场只突出一个最主要的特质。** 第一印象只放一个最鲜明的特质，其余特质留到后面慢慢展现。特质太多，读者一个也记不住。
3. **用一个细节交代身份和地位。** 别人对他的反应、他身上的一件物品、他一个习惯性动作，比直接写头衔更有效。（来源：世界观深化，小见大）
4. **让读者对主角产生倾向。** 可以从这几种方式里选：处境让人同情、目标让人认同、性格有魅力，或者经历让人共鸣。要有弱点，但行为动机合理。（来源：开头技巧，建立代入感；开头常见问题三）
5. **反派登场要让读者有理由反感或警惕。** 让他做一件具体的事：欺压弱者、背叛、践踏别人珍视的东西。不要只靠形容词说他坏。（来源：读者粘性，让读者讨厌反派）
6. **【补写】登场时就和主角形成张力。** 重要人物第一次出现时，最好和主角的欲望发生关系：成为帮助、阻碍或诱惑，让读者知道他为什么重要。
7. **外貌描写要短，并且和性格相关。** 只写一两个能透露性格或处境的外貌细节，不要从头到脚列一遍。【补写】

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| "苏晴是个外冷内热的女孩，长发及腰，眼眸如星……" | 让她做一件体现"外冷内热"的事，外貌只留一个细节 |
| 反派出场就是"他阴险狡诈，无恶不作" | 写他做的一件具体的恶事 |
| 主角登场时只是在发呆、回忆往事 | 给他一个处境和一次选择 |
| 一次登场塞进五个特质 | 只突出一个，其余的留到后文 |

## 示例（自写，演示手法）

都市悬疑，搭档苏晴第一次出现。

**弱版：**

> 苏晴是档案局最年轻的高级调查员，性格冷淡，做事雷厉风行，但其实内心很温柔。她长发及腰，五官精致。

**改写版：**

> 苏晴进来的时候没有敲门。她把一叠档案摔在林默桌上，最上面那份的封皮被咖啡泡皱了。
>
> "你的。三个委托人投诉你修复后记忆还有残缺。"她顿了一下，又从口袋里摸出一包没拆的胃药，放在档案上面，"今天之前改完。"
>
> 她走的时候，顺手把林默桌角那盆快死的绿萝挪到了有阳光的窗台上。

手法：
- 在行动中登场：摔档案、下命令。
- 突出一个特质：冷硬。
- 用细节透露另一面：胃药、挪绿萝，读者自己读出"外冷内热"，不需要作者说。
- 地位：她可以不敲门就进来、给林默派活。

## 自检清单（审核环节使用）

- [ ] 人物是不是在行动或选择中登场的，而不是靠一段介绍？
- [ ] 第一印象是否只突出一个主要特质？
- [ ] 身份和地位是不是用细节和别人的反应交代的？
- [ ] 读者对主角是否产生了倾向（同情、认同或喜欢）？
- [ ] 重要人物登场时，和主角的欲望有没有发生关系？

## 注入要点·规划

> 本章有重要人物首次登场时注入，不超过 400 字。

写明登场人物的：一个主要特质、登场时正在做的事（最好面临一个选择），以及他和主角欲望的关系（帮助、阻碍或诱惑）。

## 注入要点·写作

> 写人物首次登场的场景时注入，不超过 750 字。

- 让人物在做事中登场。不写简历式介绍，不写"他是个××的人"。
- 第一印象只突出一个最主要的特质。其他侧面用一两个细节暗示，让读者自己读出来。
- 身份和地位用细节交代：别人的反应、一件物品、一个习惯动作。
- 外貌只写一两处和性格或处境相关的细节。
- 反派要做一件具体的事，让读者反感或警惕，不靠形容词定性。
