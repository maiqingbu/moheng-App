# 卷架构

## 用途

把一卷设计成一个完整的阶段：有自己的目标、完整的起承转合、卷末的阶段性高潮，以及通向下一卷的变化。

## 何时使用 / 不适用

- **使用：** 卷规划时（常驻）；审核发现某卷没有目标、没有高潮或者过长时。
- **不适用：** 卷内几十章的小段落（由段落架构负责）。

## 方法

1. **每卷写出四项**（来源：大纲方法，卷纲）：
   - 卷概述：这一卷讲的是什么阶段；
   - 卷目标：主角这一卷要做成什么；
   - 关键情节：三到六个节点；
   - 卷高潮：在卷末，是什么样的对决或揭示。
2. **每卷一个大阶段，并且自成一体。** 有独立的主线任务和起承转合；卷末用阶段性高潮收住。（来源：长篇架构，分卷原则）
3. **卷的篇幅：** 第一卷不宜太长，要尽快给读者第一个大回报；中间卷承载主要剧情；最后一卷不要拖。（来源：长篇架构，分卷字数）
4. **安排关键节点：** 高潮位置、伏笔埋设与回收、换地图的时机、能力突破。（来源：大纲方法，关键节点）
5. **卷高潮要有足够铺垫。** 卷级高潮通常需要十几章的铺垫：多次提及、逐步升级、制造期待。（来源：高潮设计，铺垫时长）
6. **卷与卷之间的过渡。** 换卷或换地图要有契机（事件、突破、被迫离开），新地图和旧地图保持联系，旧人物和旧事件继续产生影响。（来源：长篇架构，世界观扩展）
7. **【补写】卷末留下下一卷的钩子。** 卷高潮解决本卷问题的同时，揭开一个更大的问题。

## 参考区间（来源经验，按作品调整）

以两百万字长篇为例：第一卷约 30～50 万字，中间卷约 50～80 万字，最后一卷约 20～40 万字。篇幅不同时按比例缩放。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 一卷写完，主角和处境没有任何变化 | 写明卷目标和卷末的变化 |
| 卷末平平收场 | 在卷末安排一次阶段性高潮 |
| 第一卷拖了一百多章才有大回报 | 压缩，前移第一个大回报 |
| 换地图后旧人物全部消失 | 让旧人物或旧事件在新地图继续产生影响 |

## 示例（自写）

```
第2卷：地下（第 61–130 章）
卷概述：失去执照的林默在地下市场接活，第一次站到规则的另一边
卷目标：查出是谁举报了他，并拿回一份被封存的姐姐档案
关键情节：结识地下中介（65）→ 第一次越级修复，代价加重（80）→ 搭档苏晴奉命调查他（95）→ 档案库潜入失败（110）→ 发现举报人是档案局副局长（120）
卷高潮（121–130）：在副局长主持的公开听证会上，用一段修复出的记忆当众反击
卷末钩子：被修复的记忆里，出现了姐姐的脸，她穿着档案局的制服
过渡：黑市中介在第3卷成为情报来源，保持联系
```

## 自检清单

- [ ] 卷概述、卷目标、关键情节、卷高潮四项是否齐全？
- [ ] 卷高潮之前是否有足够的铺垫？
- [ ] 卷末是否有变化和下一卷的钩子？
- [ ] 换地图是否有契机，并与旧地图保持联系？

## 注入要点·规划

> 卷规划时注入，不超过 900 字。

每卷写明卷概述、卷目标、3～6 个关键情节、卷末高潮。每卷是一个自成一体的阶段，有起承转合，卷末用阶段性高潮收住，同时揭开下一卷的更大问题。卷高潮前要用十几章铺垫：多次提及、逐步升级、制造期待。标出伏笔埋设与回收、换地图、能力突破的位置。换卷要有契机，旧人物和旧事件要在新地图继续产生影响。第一卷不宜过长，最后一卷不要拖。
