# 章节叙事评估

## 用途

对一章已写成的正文做叙事质量评估：是否完成了章纲的任务，逻辑、节奏、人物、语言是否过关，并给出可以执行的修改建议。

## 何时使用 / 不适用

- **使用：** 每章正文生成之后的审核（常驻）。
- **不适用：** 开篇三章的整体评估（由开篇评估负责，可同时使用）；规划阶段（由大纲与章纲评估负责）。

## 评估维度与判断标准

| 维度 | 合格 | 不合格的信号 |
|---|---|---|
| 章纲完成度 | 规划的场景和节拍都写到，并且写够 | 节拍被一句话带过，或擅自偏离规划 |
| 逻辑 | 设定、能力、时间线一致；因果合理 | 前后矛盾，人物做出不合理的选择 |
| 节奏 | 有起伏，不拖沓，章末有钩子 | 大段无推进的内容，或一直高压无缓冲 |
| 人物 | 人设一致，对话符合性格，配角有作用 | 性格走样，所有人说话一个腔调 |
| 呈现 | 关键处用动作和细节展示 | 大量"他很生气"式的告知 |
| 语言 | 精炼准确，无病句，无模型腔 | 重复修饰、空泛抒情、段尾升华 |
| 篇幅质量 | 篇幅落在区间内，并且来自情节展开 | 达标但靠重复和堆砌描写，即注水 |

来源：修改润色，检查清单与常见问题。

## 修改建议的写法

每条问题写成"位置、问题、改法"，并标明严重程度：

- 必须改：逻辑矛盾、人设崩坏、章纲任务未完成、注水；
- 建议改：节奏、呈现方式、对话；
- 可选：个别用词。

先看深层问题（逻辑、结构、人物），再看表面问题（用词、标点）。（来源：修改润色，误区3）

判断某段是否冗余时，问：删掉它会影响理解或剧情吗？不会就删。（来源：修改润色，删减法）

## 示例（自写，评估意见）

> **位置：** 第 7 章第 2 场景，"档案库潜入"节拍 3
> **严重程度：** 必须改
> **问题：** 章纲中"苏晴故意留下授权卡"是本章的转折，正文只用一句"桌上有一张卡"带过，读者无法意识到这是苏晴有意为之。
> **改法：** 展开这个节拍：苏晴离开前停顿、回头看了一眼档案架的方向，再把卡放在台灯下最显眼的位置（约 300 字）。

## 注入要点·评估

> 每章正文审核时注入，不超过 1000 字。

逐项评估：

- 章纲规划的场景和节拍是否都写到、写够；
- 设定、能力、时间线是否一致，因果是否合理；
- 节奏是否有起伏，有无拖沓段，章末有无钩子；
- 人设和对话是否符合性格；
- 关键处是否用动作和细节展示；
- 语言是否精炼，有无重复修饰、空泛抒情和段尾升华；
- 篇幅是否来自情节展开，而不是重复和堆砌。

每个问题按"位置、严重程度（必须改／建议改／可选）、问题、改法"写出。先报告逻辑、结构、人物等深层问题，再报告表面问题。
