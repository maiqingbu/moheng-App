# 主动性与阅读欲望评估

## 用途

检查两件决定读者是否继续读下去的事：主角是不是在主动推动故事；读者在这一章结束时，是不是还有"想知道""想看到"的东西。

## 何时使用 / 不适用

- **使用：** 章节规划和审核时，当出现"主角被动"或"阅读欲望不足"的问题信号时；定期的留存检查。
- **不适用：** 开篇三章（由开篇评估负责，已包含相关维度）。

## 评估维度与判断标准

| 维度 | 合格 | 不合格的信号 |
|---|---|---|
| 主角的目标 | 本章有明确的、他自己想要的东西 | 只是在应付别人安排的事 |
| 主角的选择 | 至少一个关键转折由他的选择引发 | 所有转折都来自外部事件或别人 |
| 选择的代价 | 选择有代价或风险 | 选择毫无成本 |
| 读者站在他这边 | 有同情、认同或喜欢的理由 | 行为让人反感，或动机不清 |
| 阅读期待 | 能说出读者此刻具体想知道或想看到什么 | 说不出，或者期待太空泛 |
| 期待的更新 | 旧期待被部分满足的同时产生新期待 | 同一个期待原样重复了多章 |

来源：冲突升级，冲突公式；读者粘性，角色塑造与期待感；开头技巧，阅读期待与主角不讨喜。

## 修改建议的写法

每条问题写成"位置、问题、改法"。常用改法：

- 主角被动：把一个外部事件改成由主角的选择引发，或者让他在被动处境中做出一个有代价的决定；
- 不讨喜：补一个正面特质或合理动机（来源：开头技巧，主角不讨喜的解决）；
- 期待不足：在结尾前抛出一个具体的问题、危机或承诺。

## 示例（自写）

> **位置：** 第 15 章整体
> **问题：** 本章三个转折（委托上门、苏晴来访、证人失踪）都来自外部，林默只是在回应；章末读者没有明确的期待。
> **改法：** 让"证人失踪"变成林默选择的后果——他为了保护证人而把证人藏起来，却没有告诉苏晴。章末改为：苏晴打来电话，说稽查科正在找一个"被人藏起来的证人"。

## 注入要点·评估

> 出现主角被动或阅读欲望不足信号时注入，不超过 700 字。

检查：本章主角是否有自己想要的东西；至少一个关键转折是否由他的选择引发，并且有代价；读者是否有站在他这边的理由；章末是否能说出读者具体想知道或想看到什么；这个期待是否比上一章有所更新。每个问题按"位置、问题、改法"写出：主角被动就把外部事件改成他的选择后果；期待不足就在结尾前抛出具体的问题、危机或承诺。
