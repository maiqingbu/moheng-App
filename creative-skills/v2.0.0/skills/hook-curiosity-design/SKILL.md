# 钩子与好奇心

## 用途

在读者心里种下一个具体的问题，让他想知道答案。钩子不是吓人的一句话，而是"有个东西没说完，而且和人物的命运有关"。

## 何时使用 / 不适用

- **使用：** 开篇前三章（尤其是第一段）；需要埋下或接续一个悬念的章节；审核发现开头平淡、整章没有提出任何问题、悬念过快或过久揭开时。
- **不适用：** 章末那一刻的落点（由章末钩子负责）；长线谜题的整体结构（由悬疑设计负责）。

## 方法

1. **第一段必须让人留下来。** 读者扫一眼就决定去留，所以第一段要同时做到：有抓手（冲突、异常或有趣）、信息清楚（知道谁在什么处境）、能进入情境、读着顺。（来源：读者粘性，3 秒原则和第一段的作用）
2. **从"正在发生"的事开始，不从介绍开始。** 先给一个动作、冲突或异常，名字、年龄、背景放到后面顺带交代。（来源：开头技巧，快速进入主题；粘性篇的好坏开局对比）
3. **钩子要具体。** "他发现了一个秘密"太空泛；"信封里是他自己的死亡证明，日期是明天"才是具体的问题。具体到读者能复述"我想知道什么"。
4. **选一种期待类型，并和作品卖点挂钩**（来源：开头技巧，制造阅读期待）：
   - 悬念期待：一个谜团；
   - 冲突期待：一个必须解决的矛盾；
   - 成长期待：读者想看他怎样一步步强起来；
   - 复仇期待：读者想看这笔账最终怎么算清。
5. **第一句可以用这几种方式**（来源：开头技巧，常见第一句类型）：
   - 悬念式（未说完的威胁或承诺）；
   - 冲突式（一句顶回去的话）；
   - 震惊式（世界出现异常）；
   - 平淡式：只在后半句立刻翻出异常时才可用，否则就是流水账。
6. **问题要有节奏地回答。** 一个悬念大约 3～5 章内给出部分答案，同时抛出下一个新问题，形成"解开 A、抛出 B"的接力。不要一直拖着不答，也不要刚提出就立刻揭开。（来源：读者粘性，留悬念不拖沓）
7. **钩子必须兑现在故事里。** 提出的问题要和主线或人物的欲望相连，不能是写完就不管的噱头。

## 参考区间（来自原文，仅供参考）

- 第一段大约 100 字以内，必须出现抓手。
- 一个悬念大约 3～5 章内部分揭开，并接上新的问题。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| "我叫林默，今年二十二岁，是个普通的程序员。" | 改成正在发生的异常，身份信息后补 |
| 用大段环境描写开篇 | 先写人物在处境中的动作，环境作为背景穿插 |
| "他发现了一个惊天秘密……"（不说是什么） | 给出秘密的一角，让读者知道问题具体是什么 |
| 悬念提了十章还没有任何进展 | 先给部分答案，再抛出更深一层的问题 |
| 钩子和后文无关，只为吸引眼球 | 让钩子指向主角的欲望或主线冲突 |

## 示例（自写，演示手法）

都市悬疑，开篇第一段。

**弱版：**

> 林默是城市记忆档案局的一名调查员，他的工作是修复被篡改的市民记忆。今天天气阴沉，他像往常一样来到档案局上班。

**改写版：**

> 第三份委托书递到林默桌上时，他认出了委托人的签名——是他自己的笔迹。日期写的是下周二。

手法：从正在发生的异常开始，钩子具体（自己写给自己的、来自未来的委托），身份信息"档案局调查员"可以放到第二段顺带交代。

## 自检清单（审核环节使用）

- [ ] 第一段有没有抓手（冲突、异常或有趣），信息是否清楚？
- [ ] 读者读完能不能说出"我想知道什么"？
- [ ] 钩子是否和主线或主角的欲望相连？
- [ ] 正在进行的悬念，有没有在 3～5 章内给出部分答案，并接上新的问题？

## 注入要点·规划

> 规划开篇章节或悬念章节时注入，不超过 600 字。

- 写明本章要让读者产生的具体问题（读者能复述的那一句），以及它连接的主线或人物欲望。
- 选定期待类型：悬念、冲突、成长或复仇。
- 如果有正在进行的悬念，写明本章给出哪一部分答案、又抛出什么新问题。

## 注入要点·写作

> 写开篇章节的开头或悬念场景时注入，不超过 700 字。

- 第一段从正在发生的动作、冲突或异常写起，大约 100 字内出现抓手；名字和背景后补。
- 问题要具体，至少露出一角，让读者知道自己在等什么，不要只写"他发现了秘密"。
- 第一句可以用悬念式、冲突式或震惊式。平淡式只在后半句立刻翻出异常时使用。
