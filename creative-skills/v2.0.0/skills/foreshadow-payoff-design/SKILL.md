# 伏笔与回收

## 用途

管理全书的伏笔：埋在哪里、什么时候回收、现在是什么状态。保证每个伏笔都有回收，每个重要回收都有伏笔。

## 何时使用 / 不适用

- **使用：** 卷规划时（常驻）；伏笔到期时；章节规划和写作涉及埋设或回收时；审核发现伏笔无人回收、伏笔过多、回收缺少铺垫时。
- **不适用：** 谜团的线索链设计（由悬念与谜团负责）；本技能负责登记和到期管理。

## 方法

1. **按回收距离分级**（来源：长篇架构，伏笔的层次）：
   - 短期：几章到一个剧情单元内回收，制造近期的悬念；
   - 中期：一卷左右回收，维持长期吸引力；
   - 长期：跨多卷回收，营造史诗感；
   - 终极：接近结局才回收，揭示世界或故事的根本真相。
2. **登记到伏笔表。** 每个伏笔记下：编号、埋设章节、内容、级别、预计回收位置、实际回收章节、状态。埋一个，记一个。（来源：长篇架构，伏笔管理表）
3. **大伏笔分节点揭开。** 长期和终极伏笔不要一次揭开，按"暗示 → 线索 → 部分真相 → 完全揭开"分布在全书中。（来源：大纲方法，伏笔设置）
4. **定期检查。** 每卷规划时检查所有未回收的伏笔：哪些到期了，哪些需要再提一次提醒读者，哪些已经无法回收需要处理。（来源：长篇连载管理，伏笔管理）
5. **控制数量。** 不要埋太多收不住；同时在场的中长期伏笔数量要有上限。（来源：长篇架构，管理原则）
6. **【补写】埋设要自然。** 伏笔要以正常情节的一部分出现，读者第一次看到时不觉得突兀，回收时能回头认出。
7. **【补写】回收要有分量。** 回收时说明它改变了什么：人物的认识、局势、读者对前文的理解。只交代"原来如此"而没有影响，回收就浪费了。
8. **完结前清点。** 进入结局段之前，梳理全部伏笔，确保都回收或有意保留。（来源：长篇连载管理，完本前准备）

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 第 5 章提到神秘玉佩，后来再没出现 | 登记，并安排回收或在中途再提一次 |
| 结局靠一件之前从未提过的宝物取胜 | 在前文补埋伏笔 |
| 同时有二十个未回收的谜，读者记不住 | 先回收一批短期伏笔，暂停埋新的 |
| 伏笔埋得太显眼，读者一眼看穿 | 把它藏进正常情节，降低强调 |

## 示例（自写）

| 编号 | 埋设 | 内容 | 级别 | 预计回收 | 状态 |
|---|---|---|---|---|---|
| F01 | 第3章 | 主角左手腕的旧烫伤，他不记得来历 | 长期 | 第3卷 | 进行中 |
| F02 | 第12章 | 姐姐书桌上的申请回执 | 终极 | 结局段 | 进行中 |
| F03 | 第40章 | 搭档总在周四请假 | 短期 | 第50章前 | 已回收（第47章：她在探望被抹去记忆的父亲） |

F01 的分节点揭开：第 3 章暗示 → 第 70 章修复时闪过火光 → 第 160 章得知是救姐姐时留下 → 第 3 卷末完全揭开。

## 自检清单

- [ ] 本章埋设或回收的伏笔是否已登记？
- [ ] 是否有到期未回收的伏笔？
- [ ] 本章的重要回收，前文是否有伏笔？
- [ ] 同时在场的中长期伏笔是否过多？
- [ ] 回收时是否说明了它改变了什么？

## 注入要点·规划

> 卷规划时注入，不超过 600 字。

检查伏笔表：列出到期的伏笔并安排回收章节；需要提醒读者的伏笔安排再次提及；本卷新埋的伏笔写明级别（短期、中期、长期、终极）和预计回收位置。长期和终极伏笔分"暗示、线索、部分真相、完全揭开"多个节点。控制同时在场的中长期伏笔数量。

## 注入要点·章节

> 本章计划埋设或回收伏笔时注入，不超过 400 字。

写明本章埋设或回收的伏笔编号。埋设时让它作为正常情节的一部分出现；回收时说明它改变了人物认识、局势或读者对前文的理解。

## 注入要点·写作

> 写作本章且有伏笔任务时注入，不超过 300 字。

伏笔融入正常情节，不额外强调。回收时写出它带来的具体影响，不只写"原来如此"。
