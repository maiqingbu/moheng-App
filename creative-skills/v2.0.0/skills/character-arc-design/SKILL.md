# 人物弧线

## 用途

规划主角和重要配角在全书中的内在变化：从什么样的人变成什么样的人，每一步由什么事件推动。成长不能只是实力上涨，还要有心智、认知和选择的变化。

## 何时使用 / 不适用

- **使用：** 全书和卷规划时；到达弧线节点时；审核发现人物没有变化、变化来得太容易，或者成长只有实力时。
- **不适用：** 人物的静态设定（由主角设计、配角设计负责）。

## 方法

1. **【补写】写出起点和终点。** 起点是主角的缺陷或错误信念；终点是他克服了它，或者（悲剧向）被它毁掉。起点和终点要能对应到主角设计里的"欲望与需要"。
2. **成长分多个维度。** 实力之外，还有心智成熟、认知提升、格局变大、责任变重、人脉扩展。每卷至少有一个非实力维度的变化。（来源：读者粘性，角色成长；长篇连载管理，主角成长线）
3. **【补写】每个节点都要"付出代价才换来"。** 节点格式：触发事件 → 旧信念让他做错选择 → 承担后果 → 认识改变。直接宣布"他成长了"不算。
4. **成长的速度要合适。** 太快没有过程感，太慢读者没耐心。把弧线节点分散到各卷，大约每卷一次明显的内在变化。（来源：长篇连载管理，成长要合理）
5. **【补写】允许倒退。** 在压力最大的时候，人物可以短暂退回旧信念，这会让最终的改变更可信。
6. **配角也有弧线。** 重要配角至少有一次变化，不能只是陪衬。（来源：读者粘性，配角也要成长）
7. **记录成长轨迹。** 记下每个节点发生在哪一章，后续章节中人物的言行要符合当前所处的阶段。（来源：修改润色，人物检查）

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 主角从第一章到最后一章性格完全一样 | 定起点缺陷和终点，在各卷安排节点 |
| 旁白一句"他终于明白了" | 用一次做错选择、承担后果的事件推动 |
| 成长只有境界上涨 | 每卷加一个心智、认知或责任的变化 |
| 前一章刚领悟，后一章又像没领悟过 | 对照成长记录，或写成有意的倒退并给出压力 |

## 示例（自写）

```
主角林默
起点：错误信念"只要我一个人扛，就不会连累别人"
节点1（第1卷末）：独自潜入导致委托人被抓 → 第一次意识到隐瞒也会伤人
节点2（第2卷中）：向搭档坦白代价，但仍保留关键信息 → 半步改变
倒退（第3卷）：姐姐线索出现，他再次独自行动，失去搭档的信任
节点3（终卷）：把选择权交给姐姐本人，而不是替她决定 → 终点：信任他人、承认无法独自承担
配角苏晴：从"规则一定能保护人"到"规则需要有人去修"
```

## 自检清单

- [ ] 起点缺陷和终点是否明确，并和主角设计一致？
- [ ] 每个节点是否由事件、错误选择和后果推动？
- [ ] 每卷是否有一项非实力的变化？
- [ ] 本章人物的言行是否符合他当前所处的阶段？

## 注入要点·规划

> 全书或卷规划时注入，不超过 700 字。

写明主角和重要配角弧线的起点（缺陷或错误信念）和终点。成长分实力、心智、认知、格局、责任多个维度，每卷至少一项非实力变化。每个节点按"触发事件 → 旧信念导致错误选择 → 承担后果 → 认识改变"安排，不能直接宣布成长。节点分散到各卷，压力最大时可以短暂倒退。记录每个节点所在章节。

## 注入要点·章节

> 本章含弧线节点或重要人物选择时注入，不超过 300 字。

本章人物的言行要符合他当前所处的弧线阶段。如果本章是弧线节点，用一次具体的选择和后果表现变化，不用旁白宣布。
