# 核心机制与力量体系

## 用途

设计作品的核心机制：修炼境界、能力、系统或任何让主角变强、让冲突升级的规则。它决定了长篇的升级节奏，也决定了冲突能不能一直有张力。

## 何时使用 / 不适用

- **使用：** 确定故事设定、卷规划时；主角升级或获得新能力时；审核发现战力膨胀、能力没有代价、能力表现前后不一致时。
- **不适用：** 一般的社会规则（由世界规则负责）；不以变强为主线的作品可以只用第 3、5 条。

## 方法

1. **定境界或阶段的数量。** 长篇通常设计十个左右的大阶段（原文建议 10～15 个），每个阶段占据足够的篇幅，并且阶段之间有清晰的区分标志。（来源：长篇架构，境界体系）
2. **分配升级节奏。** 前期升得快，让读者尽早看到成长；中后期放慢，每次升级都更难、更珍贵。和卷结构对应：一卷大约跨一两个大阶段。
3. **能力要有代价和边界。** 每种能力写明：消耗什么、限制在哪里、会被什么克制。没有代价的能力会让冲突失效。（来源：套路与爽点，升级要有代价）
4. **升级要有展示。** 升级之后安排一场让读者看到变化的冲突，证明这次变强是真的。
5. **对手同步升级。** 主角变强，敌人和格局也要变大；否则会出现"后期还在打小怪"的问题。（来源：冲突升级，力量升级、常见错误2）
6. **记录能力表。** 记下主角和主要人物当前的阶段、能力和限制。新章节写能力时对照检查，避免同一能力前后强弱不一。（来源：世界观深化，设定矛盾）

## 参考区间（来源经验，按作品调整）

- 大阶段数量：约 10～15 个；
- 前期升级较快，约每卷 1～2 个大阶段；
- 中后期放慢，单个大阶段可以跨越多卷。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 主角每章都升一级，五十章就到顶 | 按卷分配阶段，中后期放慢 |
| 新能力用起来毫无消耗 | 写明消耗和限制，并在关键战中让限制起作用 |
| 主角升级了，对手还是原来那批人 | 同步扩大格局，引入更强的势力 |
| 同一招前面能劈山，后面连门都打不开 | 对照能力表，补上合理的解释或修正 |

## 示例（自写）

```
机制：记忆修复
阶段：表层修复 → 片段重建 → 长时段重建 → 他人记忆潜入 → 集体记忆干预 …（共 10 段）
代价：每次修复失去一段自己的真实记忆，阶段越高失去越多
边界：无法修复已被"彻底删除"的记忆（这是深层谜题）
克制：记忆封锁剂会让修复者陷入他人记忆无法退出
第1卷：表层 → 片段（快）；第4卷起：每卷不超过一个阶段（慢）
对手同步：黑市贩子 → 档案局稽查科 → 篡改组织
```

## 自检清单

- [ ] 阶段数量和每个阶段的篇幅能否撑起全书？
- [ ] 每种能力是否有代价、边界和克制？
- [ ] 本次升级之后是否安排了展示？
- [ ] 对手和格局是否同步升级？
- [ ] 本章的能力表现是否与能力表一致？

## 注入要点·设定

> 确定设定、卷规划或主角升级时注入，不超过 700 字。

写明力量阶段的数量（长篇约 10～15 个）和区分标志，前期升级快、中后期放慢，并和卷结构对应。每种能力写明消耗、边界和克制方式。升级之后安排一场能展示变化的冲突。主角变强时，对手和格局同步扩大。维护能力表，新的能力表现不能和已有记录矛盾。
