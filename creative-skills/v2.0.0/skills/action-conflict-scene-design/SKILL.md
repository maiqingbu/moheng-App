# 动作与对抗场景

## 用途

写好战斗、追逐、智斗、对峙、能力突破等对抗场景：读者清楚局势，感受到危险，在你来我往中被拉到最高点，结束后看到明确的结果和影响。

## 何时使用 / 不适用

- **使用：** 本章包含战斗、追逐、智斗、对峙或突破场景时；审核发现打斗单调、没有风险、赢得太容易或者局势混乱时。
- **不适用：** 以情感为核心的对峙（由情感场景负责，可以同时使用）。

## 方法

1. **按结构推进**（来源：高潮设计）：
   - 战斗：准备 → 试探交锋 → 陷入困境 → 反击 → 决胜 → 收场；
   - 智斗：布局 → 交锋 → 破局 → 揭露 → （可选）再反转；
   - 突破：瓶颈 → 契机 → 过程 → 成功 → 展现。
2. **势均力敌。** 一边倒的战斗没有看点。双方各有优势，主角要陷入困境，最后险胜或付出代价。（来源：冲突升级，冲突要有张力）
3. **困境要有转机的种子。** 主角陷入困境时不要彻底绝望；反击的依据（之前的伏笔、对手的破绽、同伴、意志）要提前埋下，反击才合理。（来源：高潮设计，陷入困境的注意）
4. **【补写】让局势清楚。** 读者要随时知道：谁在哪里、谁占上风、主角还剩什么手段。每个回合结束时，局势要有可感知的变化。
5. **快慢结合。** 交锋用短句、快节奏；关键一击放慢，拆细动作并加入感官和念头。（来源：高潮描写技巧）
6. **多角度。** 适当穿插对手的反应和旁观者的反应，烘托局势。环境可以随战局变化。（来源：高潮描写技巧）
7. **多战场交替。** 有多个战场时交替描写，接近高潮时切换加快。（来源：场景转换，战斗场景转换）
8. **收场要交代结果。** 战斗的结果、各方的反应、后续影响、主角的收获或损失。对抗要推动剧情，不能打完什么都没变。（来源：高潮设计，尘埃落定；冲突升级，推动剧情）

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 招式名一个接一个，没有局势变化 | 每个回合写出局势怎样变化 |
| 主角从头压制到尾 | 插入困境，让对手有真实的威胁 |
| 反击靠突然出现的新能力 | 让反击依据提前出现 |
| 多人混战，读者不知道谁在哪里 | 每次切换先交代位置和局势 |
| 打完直接进入下一件事 | 补上结果、反应和后续影响 |

## 示例（自写，智斗型对峙）

```
场景：听证会（布局 → 交锋 → 破局 → 揭露）
布局：副局长先出示录像，林默的违规被坐实（局势：林默处下风）
交锋：林默要求修复证人的记忆，副局长以"程序不合规"驳回；林默指出驳回需要两名委员签字——其中一名今天缺席
破局：委员会被迫同意；修复过程中证人开始抽搐，副局长示意中止，林默放慢节奏，继续深入（关键时刻放慢）
揭露：证人说出下令者的名字，旁听席转向副局长（旁观者反应）
收场：林默恢复执照；副局长被暂停职务；林默在离场时发现自己忘了来时乘的是哪路车（代价）
```

## 自检清单

- [ ] 是否按对应的结构推进，并有困境和反击？
- [ ] 双方是否势均力敌？
- [ ] 反击的依据是否提前出现？
- [ ] 读者是否随时清楚局势？
- [ ] 收场是否交代了结果、反应和后续影响？

## 注入要点·章节

> 本章含对抗场景时的规划注入，不超过 500 字。

写明对抗的结构（战斗、智斗或突破）和各阶段的节拍，至少包含一次主角陷入困境。写明反击的依据来自哪里，必须是前文已出现的东西。写明对抗结束后的结果和对剧情的推动。

## 注入要点·写作

> 写作对抗场景时注入，不超过 700 字。

双方势均力敌，主角要陷入困境，最后险胜或付出代价。每个回合写清楚谁占上风、局势怎样变化，读者随时知道各方的位置和剩余手段。交锋用短句快节奏，关键一击放慢展开。适当写对手和旁观者的反应。多战场时交替描写，接近高潮时切换加快。收场交代结果、各方反应、后续影响和主角的得失。
