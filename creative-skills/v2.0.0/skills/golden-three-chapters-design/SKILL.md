# 黄金三章

## 用途

把开篇三章当作一个整体来设计：第一章抓住读者，第二章展开设定和冲突，第三章确立方向并给出第一个明显的回报。读者大多在前三章决定去留，三章之内必须让他知道"这本书好看在哪里"。

## 何时使用 / 不适用

- **使用：** 开篇第 1～3 章的规划；审核开篇三章时。
- **不适用：** 单章内部的钩子写法（由钩子与好奇心、章末钩子负责）；第四章以后的章节。

## 方法

1. **先定开局模式，再分配三章的任务。** 常见模式（来源：开头技巧，经典开头模式）：
   - 困境开局：主角处于困境，困难具体展开，转机出现，开始改变；
   - 巅峰开局：先展示巅峰，再写陨落或重来，主角决心回到巅峰；
   - 日常突变：平常的生活被突发事件打破，主角被卷进去；
   - 身份隐藏：主角被轻视，被迫展露实力，身份开始曝光；
   - 系统或机缘降临：得到特殊能力，接受第一个任务。

   模式可以混合使用，但要能说清"读者为什么想看下去"。
2. **第一章：抓住读者**（来源：开头技巧、读者粘性对前三章的要求）。
   - 开头就进入冲突或异常。
   - 主角登场，性格通过一次具体的选择或行动展现。
   - 主角的特殊之处（能力、机缘、秘密）出现，或者至少露出端倪。
   - 给出一个小回报或小转机。
   - 留下悬念。
3. **第二章：展开设定和冲突。**
   - 悬念加深。
   - 引入重要配角和第一个冲突。
   - 设定通过剧情展开，不用大段说明。
   - 主角的特殊之处第一次被实际使用。
4. **第三章：确立方向。**
   - 一个小高潮：主角第一次明显的反击，或者得到认可。
   - 确立短期目标，暗示长期目标。
   - 让读者感到"有意思，接下来想看"。
5. **三章的推进不能重复。** 每章都要有新的东西，不要三章都是"被欺负，然后忍"。
6. **让读者站在主角这边。** 处境让人同情，目标让人认同，或者性格有魅力。主角不讨喜、行为不合理，读者不会跟下去。（来源：开头常见问题三）
7. **不同题材有不同侧重**（来源：开头技巧，不同类型的开头）：
   - 玄幻：快速展现力量体系，第一章就出现机缘；
   - 都市：贴近生活，特殊能力一开始不要太夸张，回报要接地气；
   - 历史：交代时代背景和主角身份，展示主角掌握的知识优势；
   - 科幻：尽快展现世界的独特之处。

   悲剧、文艺向作品可以不追求"爽点"，但第三章之前必须让读者看到人物的核心欲望和命运即将受到的威胁。

## 参考区间（来自原文，仅供参考）

- 第一章大约 3000 字内，让主角的特殊之处出现或露出端倪，并给出至少一个小回报。
- 原文数据：前三章大约会流失一半读者，因此三章内必须完成"吸引、展开、确立方向"。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 第一章大段介绍世界观和人物背景 | 把设定拆散，只交代当下需要的；重要设定在后文反复提及 |
| 三章都在铺垫，主角的特殊之处到第三章还没出现 | 第一章就露出端倪，第二章让主角第一次使用 |
| 主角只是被动挨打 | 让主角在每章都做一次主动的选择 |
| 第二章重复第一章的冲突 | 第二章引入新的人物或冲突，加深悬念 |
| 第三章没有任何回报 | 安排一次反击、一次被认可，或者一个明确的目标 |

## 示例（自写，演示三章任务分配）

题材：都市悬疑，记忆修复调查员；开局模式是日常突变加上代价机制。

```
第1章 抓住读者：第一次修复委托（冲突），成功（小回报），
      代价揭开——主角丢失一段自己的记忆（悬念）。
      主角在"是否接下第二份委托"上做出选择（性格）。
第2章 展开设定和冲突：档案局的规则通过一次争执带出；
      引入搭档（配角）；第二份委托和姐姐的旧案相连（悬念加深）；
      主角第一次主动利用修复能力取证（首次使用）。
第3章 确立方向：主角找到"篡改并非事故"的证据（小高潮），
      立下短期目标——查出是谁在篡改，暗示长期目标——找回姐姐。
```

三章各有新的推进，回报逐步升级，方向在第三章确立。

## 自检清单

- [ ] 第一章是否进入了冲突或异常，主角的特殊之处是否出现或露出端倪？
- [ ] 三章是否各有新的推进，没有重复？
- [ ] 主角是否每章都有一次主动的选择，并且让人愿意站在他这边？
- [ ] 设定是通过剧情展开的，而不是大段说明？
- [ ] 第三章是否有一个明显的回报，并确立了短期目标？

## 注入要点·规划

> 规划第 1～3 章时注入，不超过 1000 字。

开篇三章是一个整体：

- 先确定开局模式：困境、巅峰、日常突变、身份隐藏、机缘降临，或者它们的组合。
- 第一章：从冲突或异常开始；主角通过一次选择展现性格；特殊之处出现或露出端倪；有一个小回报和一个悬念。
- 第二章：加深悬念；引入重要配角和第一个冲突；设定通过剧情展开；主角第一次使用特殊之处。
- 第三章：一个小高潮（反击或被认可）；确立短期目标，暗示长期目标。
- 三章的推进不能重复，主角每章都要主动选择。
- 题材侧重：玄幻尽早出现机缘；都市的回报要接地气；历史交代时代和主角优势；悲剧向在第三章前让读者看到人物的欲望和即将到来的威胁。
