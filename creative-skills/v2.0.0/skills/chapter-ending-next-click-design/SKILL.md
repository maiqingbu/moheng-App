# 章末钩子

## 用途

让读者在一章结束时想点开下一章。好的章末问题，是从本章实际发生的变化里长出来的，而不是在最后硬加一句"然而他不知道，危险正在逼近"。

## 何时使用 / 不适用

- **使用：** 每章规划时确定章末问题；写最后一个场景时；审核发现结尾是套话、连续几章结尾方式雷同、或者故意吊胃口但下一章不兑现时。
- **不适用：** 开篇第一段的钩子（由钩子与好奇心负责）。

## 方法

1. **从本章的变化里找问题。** 先问：本章结束时，什么改变了、什么还没解决？章末问题就是"这个变化接下来会带来什么"。
2. **选一种落点方式**（来源：读者粘性，章末钩子的四种方法）：
   - 突发事件：新的变数在最后一刻闯入；
   - 悬念：看到了某个东西，但不全说；
   - 危机：危险迫近，停在动作发生之前；
   - 反转：一句话改变了对局面的理解。

   另外还有一种安静的落点：一个没有回答的问题，或者一个反常的画面。适合文艺、悲剧向的作品。
3. **停在最有张力的那一刻**：动作发出之前、答案揭开之前。不要在钩子之后再补两段解释或总结。（来源：情感冲击，留白）
4. **钩子要兑现。** 下一章开头必须接住这个问题，不能用"原来是一场误会"轻轻带过，否则读者会觉得被骗。
5. **结尾方式要轮换。** 和最近几章比较，不要连续用同一种落点，尤其是"危机降临"。
6. **禁用套话结尾**："真正的战争才刚刚开始""他不知道，命运的齿轮已经开始转动"这类句子不具体、可以套在任何一章上，一律不用。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| "他知道，真正的考验才刚刚开始。" | 换成一个具体的事件或画面，比如门外的脚步声、桌上多出来的一封信 |
| 钩子之后又写了两段总结 | 删掉钩子之后的内容，停在张力最高的那一刻 |
| 每章都停在"杀气锁定了他" | 和其他方式轮换：反转、悬念，或者一个安静的未解问题 |
| 上一章吊起的问题，下一章一句话带过 | 下一章开头直接处理它，并带出后果 |

## 示例（自写，演示手法）

本章内容：主角第一次成功修复委托人的记忆，代价是自己丢了一段童年记忆。

**弱版：**

> 林默合上档案，长长地出了一口气。他隐隐觉得，这一切才刚刚开始。

**改写版：**

> 他想给母亲打个电话，告诉她自己今天做成了一件事。通讯录翻到底，"妈妈"那一栏是空的。
>
> 他盯着屏幕看了很久，想不起来那里原本存的是什么号码。

手法：钩子来自本章的变化（修复的代价）；悬念具体（母亲的号码消失了，而且他想不起来）；停在发现的那一刻，不做解释。

## 自检清单

- [ ] 章末问题是不是来自本章实际发生的变化？
- [ ] 问题是否具体，而不是套话？
- [ ] 钩子之后有没有多余的解释或总结？
- [ ] 结尾方式和最近几章是否重复？
- [ ] 上一章的章末问题，本章开头有没有接住？

## 注入要点·规划

> 每章规划时注入，不超过 450 字。

写明本章的章末问题：本章结束时什么改变了、什么还没解决。从突发事件、悬念、危机、反转、安静的未解问题中选一种落点方式，并且和最近几章的结尾方式不同。如果上一章留下了章末问题，本章开头要先接住它。

## 注入要点·写作

> 写本章最后一个场景时注入，不超过 650 字。

- 用一个具体的事件、画面或一句话收尾，停在动作发生或答案揭开之前，后面不再补解释和总结。
- 禁用"真正的……才刚刚开始""命运的齿轮……"这类可以套在任何一章上的结尾。
- 如果本章开头需要接住上一章的问题，正面处理它并带出后果。
