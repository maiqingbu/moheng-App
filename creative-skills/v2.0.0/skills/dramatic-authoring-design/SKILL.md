# 戏剧化呈现（展示而非告知）

## 用途

把"告诉读者发生了什么"变成"让读者看到正在发生什么"：用动作、对话、细节和身体反应呈现情绪与局面，让读者自己得出结论。

## 何时使用 / 不适用

- **使用：** 写作时（常驻）；重写时；审核发现大量告知式叙述、该写成场景的地方被一句概述带过、描写平淡时。
- **不适用：** 有意的快速概述和时间跳跃（由概述与转场负责）。

## 方法

1. **把结论换成证据。** "他很生气"是结论；握紧的拳头、推翻的椅子、突然压低的声音是证据。写证据，让读者得出结论。（来源：修改润色，增强表现力、描写平淡）
2. **具体化。** 用具体的物、具体的动作、具体的声音代替笼统的形容词。一处准确的细节胜过三个形容词。（来源：修改润色，具体化）
3. **以小见大。** 用一个小细节展示更大的东西：一个人对另一个人的称呼，透露出权力关系；桌上的一张账单，透露出处境。（来源：世界观深化，以小见大）
4. **关键时刻放慢。** 决定性的瞬间用慢镜头展开：动作拆细，加入感官和念头。平常的过程则可以快速带过。（来源：时间线处理，时间放慢）
5. **通过行动和对话传递信息。** 人物在做事、在争执的过程中透露信息，而不是停下来解释。（来源：世界观深化，通过行动对话、通过冲突展现）
6. **【补写】给读者留一步。** 不要在展示之后再补一句解释（"他这么做是因为愤怒"）。信任读者。
7. **【补写】不是所有东西都要展示。** 与场景目标无关的过程可以一笔带过；展示的力气要花在推动局面和情绪的地方。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| "她很难过，觉得自己被背叛了" | 写她做了什么：把对方送的东西放回原处，摆得整整齐齐 |
| "两人大吵一架，最后不欢而散" | 至少写出吵架中的两三个回合 |
| 展示之后又加一句解释 | 删掉解释 |
| 无关的吃饭、走路也逐步展示 | 一笔带过，把篇幅留给关键节拍 |

## 示例（自写）

**告知版：**

> 林默很紧张，他担心苏晴已经知道了一切。

**展示版：**

> 苏晴把咖啡推过来，林默伸手去接，杯沿磕在桌角，洒了一小片。他抽纸去擦，擦了两遍，桌上早就干了。
> "你最近，"苏晴开口。
> 他把纸团攥进掌心。
> "……是不是没睡好？"

紧张通过多余的动作和被打断的呼吸呈现；读者和林默一样，在那半句话里屏住气。

## 自检清单

- [ ] 情绪和局面是否通过动作、对话、细节呈现？
- [ ] 是否有展示之后再补的解释句？
- [ ] 关键瞬间是否放慢展开？
- [ ] 无关过程是否一笔带过？

## 注入要点·写作

> 写作或重写时注入，不超过 600 字。

用动作、对话、具体细节和身体反应呈现情绪与局面，不直接写"他很生气""她很难过"这样的结论。用一个准确的细节代替几个笼统的形容词。关键瞬间放慢，拆出动作、感官和念头；与场景目标无关的过程一笔带过。人物在行动和争执中透露信息，不停下来解释。展示之后不要再补解释句。
