# 配角与反派设计

## 用途

让每个重要配角都有自己的欲望和功能，而不只是推动剧情的工具；让反派有合理的动机和足够的智力，成为主角真正的对手。

## 何时使用 / 不适用

- **使用：** 确定故事设定、卷规划时；新的重要人物出现时；审核发现配角是工具人、反派扁平或降智、多个配角功能重复时。
- **不适用：** 人物之间关系的变化（由关系动态负责）；首次登场的写法（由人物登场负责）。

## 方法

1. **【补写】每个配角都有一个功能。** 镜子：照出主角的缺陷。对照：做出主角不会做的选择。帮手、阻碍、诱惑：直接作用于主角的欲望。两个配角的功能不要重复。
2. **【补写】每个配角都有自己想要的东西。** 他的欲望和主角的欲望可以一致、冲突或交叉，这样他才会在主角不在场时也有行动的理由。
3. **配角不能是工具人。** 该出场时出场，该退场时退场。出场就要有作用，退场也要有交代。（来源：修改润色，人物检查）
4. **按功能区分配角的性格类型**（来源：套路与爽点，收小弟套路中的类型）：
   - 忠诚可靠的；
   - 机灵办事的；
   - 能打能扛的；
   - 出谋划策的。

   一个团队里的性格要有互补。
5. **反派要分阶段配置**：初期反派、中期反派、最终反派，强度和影响范围逐级上升。（来源：大纲方法，主要反派）
6. **反派要像个人**（来源：修改润色，人物检查；读者粘性，讨厌反派）：
   - 动机合理：他也认为自己是对的，或者有不得不做的理由。
   - 不脸谱化：有自己的原则或在乎的东西。
   - 智商在线：他会预判主角的行动，主角赢要靠付出代价或出奇制胜，不能靠反派犯傻。
   - 让读者有恨的理由：他做过具体的恶事。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 配角只在主角需要时出现，没有自己的生活 | 给他一个欲望，让他在主角不在场时也有行动 |
| 反派只因为"嫉妒"就步步紧逼 | 给他一个更深的理由，比如保护自己的家族、坚信自己的秩序是对的 |
| 反派在关键时刻突然犯低级错误 | 让主角的胜利来自代价或意料之外的手段 |
| 三个配角都是"忠诚的跟班" | 区分功能：镜子、对照、诱惑 |

## 示例（自写）

```
搭档 苏晴    功能：对照（她相信制度，林默要越过制度）
            欲望：升任档案局主管，证明规则能保护普通人
            与主角的关系：合作，但理念冲突，终将对立
初期反派 黑市修复贩子    动机：靠私下修复记忆牟利   作用：让主角看见规则之外的需求
中期反派 档案局副局长    动机：相信"有些记忆被抹去对社会更好"（自认为正确）
                       智力：提前销毁证据，并把主角的修复记录作为把柄
最终反派 篡改记忆的组织核心    与姐姐的消失直接相关
```

## 自检清单

- [ ] 每个重要配角是否有自己的欲望和明确的功能，且功能不重复？
- [ ] 配角的出场和退场是否都有作用？
- [ ] 反派的动机是否合理，是否有自己的原则？
- [ ] 主角的胜利是否来自代价或出奇制胜，而不是反派犯傻？

## 注入要点·设定

> 设计人物群或新的重要人物出现时注入，不超过 700 字。

每个重要配角写明：功能（镜子、对照、帮手、阻碍或诱惑，不要重复）、他自己的欲望、和主角欲望的关系。团队成员的性格要互补。反派按初期、中期、最终分阶段配置，强度逐级上升。每个反派写明：合理的动机（他认为自己是对的，或者有不得不做的理由）、他在乎的东西、他会如何预判主角，以及让读者有恨的理由的一件具体恶事。
