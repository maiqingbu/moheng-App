# 大纲与章纲评估

## 用途

在写正文之前检查规划：全书大纲、卷纲或章纲是否结构完整、主线清楚、每一章都有推进、篇幅安排能撑起目标字数。规划阶段发现的问题，比写完再改便宜得多。

## 何时使用 / 不适用

- **使用：** 全书、卷或章节规划生成之后、进入写作之前；章节规划时常驻。
- **不适用：** 已写成的正文（由章节叙事评估负责）。

## 评估维度与判断标准

| 维度 | 合格 | 不合格的信号 |
|---|---|---|
| 主线 | 能一句话说清，每段都在推进 | 说不清，或支线喧宾夺主 |
| 结构 | 开局吸引、中段有多次高潮、结尾回收 | 中段空白，结尾仓促 |
| 推进 | 每章都有新的东西（信息、局面、关系） | 相邻章节目标重复，原地打转 |
| 因果 | 情节之间用"因此""但是"连接 | 只是"然后"的事件罗列 |
| 铺垫 | 能力、情感、实力的变化都有前因 | 突然出现的能力或转变 |
| 人物 | 行为符合人设，配角有作用，反派有动机 | 人物只为推动情节而行动 |
| 篇幅承载 | 场景和节拍的数量能自然撑起目标篇幅 | 内容太少要硬撑，或内容太多要压缩成概述 |
| 设定一致 | 与已有设定、已提交正文不冲突 | 前后矛盾 |

来源：修改润色，结构和情节修改；长篇架构，常见问题。

## 修改建议的写法

每条问题写成"位置、问题、改法"。改法从以下几类中选（来源：修改润色，第二层情节修改）：

- 删除：不推动剧情、不塑造人物、不营造氛围的情节；
- 补充：缺少铺垫的能力、情感或实力变化；
- 调整顺序：高潮分布、回报密度、悬念解开的时机；
- 合并或拆分：内容太少的章合并，内容太多的章拆分；
- 增加节拍：篇幅承载不足时，增加真正的受挫、发现或选择，而不是增加描写。

## 示例（自写，章纲评估意见）

> **位置：** 第 2 章章纲
> **问题：** 本章目标"林默决定调查委托人"与第 1 章结尾已经做出的决定相同，本章没有新推进；规划中只有 1 个场景、2 个节拍，估计不足 900 字，远低于本章 2000～3000 字的区间。
> **改法：** 把目标改为"调查中发现委托人的记忆被二次覆盖"（新信息）；增加场景"档案查询受阻"（3 个节拍）和"深夜回访委托人"（3 个节拍），让篇幅自然落在区间内。

## 注入要点·评估

> 规划生成后注入，不超过 800 字。

逐项检查：

- 主线能否一句话说清并持续推进；
- 结构是否完整，中段有没有多次高潮；
- 每章是否都有新推进，相邻章目标是否重复；
- 情节之间是否有因果；
- 能力、情感、实力变化是否都有铺垫；
- 人物行为是否符合人设，反派是否有动机；
- 场景和节拍的数量能否自然撑起目标篇幅；
- 是否与已有设定和已提交正文冲突。

每个问题按"位置、问题、改法"写出，改法从删除、补充、调整顺序、合并拆分、增加节拍中选择。篇幅不足时增加真正的情节节拍，不增加描写。
