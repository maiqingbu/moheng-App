# 长篇滚动规划

## 用途

长篇不可能一开始就把每一章定死。本技能把规划分成"远粗近细"：全书和卷保持框架，章纲只滚动生成接下来的一小段；每写完一段，对照实际正文更新后续规划。

## 何时使用 / 不适用

- **使用：** 进入新卷时；开始生成一批新章纲时；发现实际写作偏离大纲时。
- **不适用：** 第一次做全书架构（由全书架构总成负责）。

## 方法

1. **远粗近细。** 总纲只到关键事件；卷纲到关键情节；章纲只细化到接下来的 10～20 章。（来源：大纲方法，Q1）
2. **每段结束后回顾。** 对照已写正文检查：主线推进了多少、哪些伏笔到期、节奏是否连续偏快或偏慢、人物是否走到了预定阶段。（来源：长篇架构，连载中必做）
3. **判断偏离的方向**（来源：长篇连载管理，偏离大纲）：
   - 偏离后更好：比如人物自然产生了更好的选择，就更新后续大纲；
   - 偏离后更差：就把后续章节拉回原计划。
4. **主线不变，细节可调。** 调整时核心冲突和结局方向不动；具体情节、顺序、配角安排可以改。（来源：大纲方法，调整原则）
5. **评估连锁影响。** 每次调整都列出受影响的伏笔、人物弧节点、卷高潮，一并更新。记录修改原因。（来源：大纲方法，调整方法）
6. **【补写】把已写内容作为事实。** 新章纲不能和已提交正文中的事实冲突；需要改变已写事实时，走修订流程而不是在新章里假装没发生过。
7. **【补写】新章纲接续上文。** 生成新一批章纲时，传入最近几章的目标和结尾，避免重复上一章的目标，确保每章都有新推进。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 开书时就写好了 300 章的章纲，写到第 40 章已经全对不上 | 只细化近 10～20 章，其余保持卷级粒度 |
| 偏离后不更新大纲，后面的规划全部作废 | 每段结束回顾并更新 |
| 为了新灵感改掉核心冲突 | 主线不动，只调细节 |
| 新章目标和上一章几乎相同 | 生成前传入最近几章的目标和结尾 |

## 示例（自写）

```
回顾点：第 80 章写完
实际情况：搭档苏晴在第 76 章主动替主角隐瞒了一次违规（原计划没有）
判断：偏离后更好——让她的转变更早有了伏线
调整：第 95 章"她奉命调查他"保留，但动机加上内疚；第 3 卷反目的触发事件改为"她发现自己的隐瞒害了别人"
连锁影响：苏晴的弧线节点前移一个；伏笔表新增 F07（第 76 章的隐瞒）
下一批章纲：细化第 81–95 章
```

## 自检清单

- [ ] 章纲是否只细化到近 10～20 章？
- [ ] 回顾是否覆盖主线、伏笔、节奏和人物阶段？
- [ ] 调整是否保持主线不变，并列出连锁影响？
- [ ] 新章纲是否与已提交正文一致，且不重复上一章目标？

## 注入要点·规划

> 进入新卷或发现偏离时注入，不超过 700 字。

对照已写正文回顾：主线推进、到期伏笔、节奏、人物阶段。偏离后更好就更新后续大纲，更差就拉回原计划。核心冲突和结局方向不变，具体情节、顺序、配角可以调整。每次调整列出受影响的伏笔、人物弧节点、卷高潮并一并更新，记录原因。章纲只细化到接下来的 10～20 章。

## 注入要点·章节

> 生成新一批章纲时注入，不超过 400 字。

新章纲必须接续最近几章的目标和结尾，每章都有新的推进，不重复上一章的目标。不能与已提交正文的事实冲突。
