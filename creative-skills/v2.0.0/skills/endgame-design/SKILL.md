# 终局设计

## 用途

规划全书的最后一段：收拢支线，回收伏笔，把核心冲突推向终极对决，最后给出与读者承诺一致的结局和余韵。既不能草草收尾，也不能无限拖延。

## 何时使用 / 不适用

- **使用：** 全书规划时预先确定结局方向；进入终卷或终局段时；审核发现结局仓促、拖沓、线索未收或终极高潮铺垫不足时。
- **不适用：** 完结后的整体回报审计（由完结回报审计负责）。

## 方法

1. **结局方向在全书规划时就定下。** 终局要回答核心冲突的问题，兑现读者承诺，并落在主角弧线的终点上。
2. **按顺序收束**（来源：节奏控制，后期节奏；长篇架构，第三幕）：
   - 加快主线；
   - 处理支线和伏笔；
   - 准备终极高潮；
   - 终极对决；
   - 收尾余韵。
3. **提前清点。** 进入终局段之前，梳理全部未回收的伏笔、未完成的人物弧、未汇聚的支线，逐项安排到终局各段中。（来源：长篇连载管理，完本前准备）
4. **终极高潮要有足够的铺垫。** 全书级高潮需要很长的积累：终极对手被多次提及、实力和威胁逐步显现。（来源：高潮设计，大高潮）
5. **【补写】终极对决同时解决外部和内部冲突。** 主角战胜外部对手的关键，最好正是他克服了内在缺陷之后做出的选择。
6. **高潮不能太短，收尾不能草率。** 期待已久的决战要充分展开；之后留出余韵，交代主要人物的去向和世界的变化。（来源：高潮设计，常见问题）
7. **不要太早，也不要太晚。** 故事讲完就收，不为凑篇幅拖延；最后一卷篇幅不宜过长。（来源：长篇连载管理，什么时候完本；长篇架构，分卷字数）
8. **【补写】结局与基调一致。** 悲剧向不要被强行扭转成团圆；爽文要给出足够痛快的最终回报。

## 参考区间（来源经验，按作品调整）

终局段约占全书的 10%～15%。其中最后几章依次承担：终极高潮、伏笔回收、结局交代、余韵。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 终极大战两章打完，紧接"全书完" | 展开决战，并留出余韵章 |
| 结局后还有三十章日常，没有新冲突 | 压缩到一两章余韵 |
| 结局时还有重要伏笔没有交代 | 终局前清点，逐项安排 |
| 主角靠突然获得的新能力赢下终局 | 让胜利来自弧线终点上的选择 |
| 悲剧向作品在最后一章强行团圆 | 回到读者承诺 |

## 示例（自写）

```
终局段：第 201–240 章
清点：未回收伏笔 F01、F02、F05；苏晴弧线待完成；记忆流失支线待汇聚
201–215 加快主线：组织核心现身，七天期限（F05 回收）
216–225 收支线：苏晴在档案局内部打开通道（她的弧线终点）
226–234 终极对决：公开所有被篡改的记忆；代价是主角关于姐姐的全部记忆（支线汇聚；外部与内部冲突同时解决：他第一次把选择交给姐姐本人）
235–238 回收与交代：F01、F02 回收；城市记忆体系的重建
239–240 余韵：姐姐坐在病床边，给已经不认识她的弟弟讲他们小时候的事
```

## 自检清单

- [ ] 结局是否回答了核心冲突、兑现了读者承诺、落在弧线终点？
- [ ] 是否列出并安排了所有未回收的伏笔和未完成的弧线？
- [ ] 终极高潮的铺垫和篇幅是否足够？
- [ ] 是否有余韵，并且没有拖延？
- [ ] 结局是否与作品基调一致？

## 注入要点·规划

> 全书规划或进入终卷时注入，不超过 800 字。

结局要回答核心冲突、兑现读者承诺、落在主角弧线终点，并与基调一致。进入终局前清点所有未回收的伏笔、未完成的弧线、未汇聚的支线，逐项安排。终局按"加快主线 → 处理支线和伏笔 → 准备终极高潮 → 终极对决 → 收尾余韵"推进，约占全书 10%～15%。终极对决同时解决外部和内部冲突。决战要充分展开，之后留出余韵，不草率也不拖延。

## 注入要点·章节

> 终局段的章节规划时注入，不超过 400 字。

写明本章在终局中的位置，以及本章回收哪些伏笔、完成哪条弧线或汇聚哪条支线。决战章充分展开；余韵章交代主要人物的去向和世界的变化。
