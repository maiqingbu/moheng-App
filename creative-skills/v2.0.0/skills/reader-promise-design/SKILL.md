# 读者承诺

## 用途

写清楚这本书承诺给读者的核心体验：读者为什么点进来，又为什么愿意一直追下去。所有章节的回报都要兑现这个承诺，不能写着写着变成另一本书。

## 何时使用 / 不适用

- **使用：** 确定故事设定和全书规划时；审核发现作品偏离了最初的卖点，或者回报方式和读者期待不一致时。
- **不适用：** 具体某一章的回报安排（由回报设计负责）。

## 方法

1. **定核心体验的类型。** 读者主要来获得什么？
   - 爽感：逆袭、打脸、变强；
   - 悬念：解谜；
   - 情感：感动、心痛；
   - 其他：温馨、恐惧、智斗……

   可以有主有次，但主体验只能有一个。（来源：情感冲击的类型；开头技巧，期待类型）
2. **写成可以检验的承诺。** 不写"好看"，要写"读者会反复体验到什么"。比如："主角每一次变强都要付出真实的代价，读者在痛快和心疼之间来回"。
3. **按核心体验确定回报的密度**（来源：读者粘性，爽点密度）：
   - 爽文：每章都要有一个回报；
   - 正常节奏的作品：两三章一个；
   - 严肃或悲剧向的作品：回报更少，但不能没有。它的回报是情感的兑现：真相、和解、遗憾落地。
4. **回报要逐级递进。** 小回报、中回报、大回报的分量要逐步上升。一开始就给到最大，后面就没有空间了。（来源：读者粘性，爽点层次）
5. **列出承诺清单，作为后续检查的依据。** 写出 3～5 条"这本书一定会给读者的东西"。卷规划和完结审计时，逐条核对有没有兑现。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| "这本书很好看，节奏快" | 写出读者会反复体验到的具体东西 |
| 前期卖逆袭爽感，中期变成慢热的感情戏，没有任何过渡 | 感情线可以加，但主体验要一直在场 |
| 悲剧向作品为了追求"爽点"而硬塞打脸情节 | 用情感兑现代替爽点 |
| 第一卷就把最大的回报用完 | 按小、中、大的层次分配 |

## 示例（自写）

题材：王府兄弟，悲剧。

```
核心体验（主）：情感——"他们都在为对方好，却亲手把对方推向结局"带来的心痛。
核心体验（次）：悬念——兄长到底在保护谁、防着谁。
回报方式：误会被读者看穿而人物不知道的张力；真相一点点落地；遗憾成为定局。
承诺清单：
1. 兄弟每一次伤害对方，背后都有读者可以理解的善意。
2. 一件承载两人关系的物件，会在关键时刻反复出现，意义不断改变。
3. 真相会揭开，但来得太晚。
4. 结局不会被强行扭转成团圆。
```

## 自检清单

- [ ] 主体验是否只有一个，并且具体？
- [ ] 回报的密度是否和主体验相符？
- [ ] 回报的分量是否逐级递进？
- [ ] 本卷或本章的回报，有没有偏离承诺清单？

## 注入要点·设定

> 确定设定或做全书、卷规划时注入，不超过 600 字。

写明本书的主体验（只能有一个）和次要体验。写出 3～5 条可以检验的承诺：读者会反复体验到什么。按主体验确定回报的密度：爽文每章一个；正常节奏两三章一个；严肃或悲剧向更少，用情感兑现作为回报。回报的分量按小、中、大逐级递进，后续的规划和完结都要对照这份承诺清单检查。
