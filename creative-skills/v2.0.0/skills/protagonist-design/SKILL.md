# 主角设计

## 用途

设计一个能撑起长篇的主角：他有强烈的欲望、真实的缺陷、在压力下会做选择，并且读者愿意站在他这边。

## 何时使用 / 不适用

- **使用：** 确定故事设定时；审核发现主角被动、不讨喜、没有缺陷，或者人设前后不一致时。
- **不适用：** 主角长期的变化路线（由人物弧负责）；首次登场的写法（由人物登场负责）。

## 方法

1. **分三层写目标：** 短期（这一卷要做到的）、中期、长期（全书的终点）。三层目标要能连成一条线。（来源：大纲方法，人物设定）
2. **【补写】欲望和需要分开。** 欲望是主角以为自己要的东西，需要是他真正缺少的东西。两者之间的落差就是人物弧的空间。比如他想要的是复仇，他真正缺的是放下。
3. **【补写】缺陷要能制造麻烦。** 选一个会在关键时刻让他做错选择的缺陷，比如骄傲、多疑、过度保护。不要选"太善良""太努力"这种无害的缺点。
4. **让读者站在他这边**（来源：读者粘性，角色塑造；开头技巧，代入感）：
   - 有魅力：有原则，对朋友好；
   - 有人性：有弱点，有烦恼；
   - 有情感：有在乎的人；
   - 处境让人同情，或者目标让人认同。

   这几项至少满足两项。
5. **主角要主动。** 每个阶段都由主角的选择推动剧情，不能总是被事件推着走。
6. **人设要前后一致。** 列出他的底线（绝不会做的事）和习惯（压力下的反应方式）。之后任何违背底线的行为，都必须有足够的压力和铺垫。（来源：修改润色，人物检查）
7. **【补写】能力和限制同时设计。** 主角的特殊之处一定要有边界或代价，否则冲突会失效。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 主角完美无缺，所有人都喜欢他 | 加一个会让他犯错的缺陷，并安排人反对他 |
| 主角一直在被事件推着走 | 每个阶段的转折都由主角的选择引发 |
| 主角前面重情义，后面毫无铺垫地出卖朋友 | 补上压力和过程，或者改掉这个行为 |
| 目标只有"变强" | 写出他为什么要变强，以及变强之后要做什么 |

## 示例（自写）

```
主角：林默，记忆修复调查员
短期目标：查清第一个委托背后的篡改是谁做的
中期目标：找到抹去姐姐存在的组织
长期目标：找回姐姐（欲望）
真正的需要：接受"有些失去无法挽回"，学会为当下活着
缺陷：对亲近的人过度负责，所以总在独自承担、隐瞒同伴，关键时刻害得同伴陷入险境
让读者站在他这边：处境让人同情（家人被抹去）＋有原则（拒绝收黑钱修复）
底线：不篡改他人记忆
压力下的习惯：先自己扛，最后才开口
能力的代价：每修复一次，失去一段自己的真实记忆
```

## 自检清单

- [ ] 三层目标是否能连成一条线？
- [ ] 欲望和需要是否有落差？
- [ ] 缺陷是否会让他在关键时刻做错选择？
- [ ] 读者站在他这边的理由，是否至少有两项？
- [ ] 本章主角的行为是否符合他的底线和习惯？

## 注入要点·设定

> 确定故事设定时注入，不超过 800 字。

设计主角时，写明：

- 短期、中期、长期三层目标；
- 欲望（他以为要的）和需要（他真正缺的）；
- 一个会让他在关键时刻做错选择的缺陷；
- 让读者站在他这边的至少两项理由（处境、目标、性格魅力、人性弱点）；
- 底线和压力下的习惯；
- 能力的边界或代价。

主角必须主动，每个阶段的转折都由他的选择推动。
