# 主线与支线设计

## 用途

确定全书有几条故事线、哪条是主线、各占多少篇幅、在哪些卷里交织和汇聚。目标是主线始终清楚，支线让故事更厚，但不喧宾夺主。

## 何时使用 / 不适用

- **使用：** 全书规划时（常驻）；卷规划分配篇幅时；审核发现主线失焦、支线膨胀、某条线太久没动时。
- **不适用：** 视角切换的写法（由视角与心理距离负责）。

## 方法

1. **选一种多线结构**（来源：多线叙事，多线类型）：
   - 主辅：一条主线为核心，支线为它服务。大多数网文长篇适用。
   - 平行：几条线各自发展，最后汇聚。适合多主角。
   - 交织：多条线频繁互相推动。最难，适合悬疑或多势力博弈。
2. **定 2～4 条线，分清主次。** 常见的线：成长或实力线、感情线、势力线、目标或复仇线、身世或谜团线。（来源：长篇架构，主线类型）
3. **分配篇幅。** 主线占大头，重要支线次之，次要支线很少。每卷的比例可以变化，比如某条谜团线在前期只埋伏笔，到后期占比上升。（来源：长篇架构、多线叙事，篇幅比例）
4. **每条支线都要回到主线。** 写明这条支线在哪里影响主线、在哪里汇聚。和主线无关的支线要砍掉。（来源：长篇架构，主线失焦）
5. **主线定期推进。** 不能连续很多章只写支线；重要的线不能太久不动，否则读者会忘。（来源：长篇连载管理，避免拖沓；多线叙事，篇幅平衡）
6. **高潮错开。** 主线高潮时，支线放在过渡；主线平缓时，用支线的小高潮调剂。两条线同时高潮会太累，同时平淡会太闷。（来源：多线叙事，节奏平衡）

## 参考区间（来源经验，按作品调整）

- 主线：约 60%～80%；
- 重要支线：约 10%～20%；
- 其他支线：各 5%～10% 或更少；
- 主线推进间隔：约每 10～20 章至少明显推进一次。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 感情线连写二十章，主线停滞 | 压缩感情线，或让它直接推动主线 |
| 一条支线开了就再没回来 | 写明它的汇聚点，或删除 |
| 主线和支线在同一章同时爆发 | 错开，一条高潮、一条过渡 |
| 跟风加了热门元素，和主线毫无关系 | 砍掉，回到核心冲突 |

## 示例（自写）

```
结构：主辅
主线（约 65%）：寻找姐姐 / 对抗篡改组织
支线A 搭档关系（约 15%）：合作 → 理念冲突 → 对立 → 终局和解；在第 130 章与主线交汇（她查到的档案指向组织）
支线B 记忆流失（约 12%）：主角自身的代价，前期点缀，后期占比上升；终局与主线汇聚（为找回姐姐需要放弃的正是自己的记忆）
支线C 黑市委托（约 8%）：单元案件，用于小高潮调剂，每个案件都交出一条主线线索
交织：第 1 卷主线为主，B 线埋伏笔；第 3 卷 A、B 线同时把压力推向主线；终卷三线汇聚
```

## 自检清单

- [ ] 主线能否用一句话说清？
- [ ] 每条支线是否写明了和主线的交汇点？
- [ ] 篇幅比例是否主次分明？
- [ ] 本卷或近 20 章内主线是否有明显推进？
- [ ] 主线和支线的高潮是否错开？

## 注入要点·规划

> 全书或卷规划时注入，不超过 800 字。

选择多线结构：主辅（大多数长篇）、平行（多主角，最后汇聚）或交织（悬疑、多势力）。定 2～4 条线并分清主次：主线约 60%～80%，重要支线约 10%～20%，其他各 5%～10%。每条支线写明在哪里影响主线、在哪里汇聚，无关支线要砍掉。主线约每 10～20 章至少明显推进一次，重要的线不能长期不动。主线高潮和支线高潮错开安排。
