# 核心冲突与赌注

## 用途

设计贯穿全书的核心冲突，并规划它如何一层层升级：对手越来越强，格局越来越大，失败的代价越来越重。冲突要合理、有张力、推动剧情。

## 何时使用 / 不适用

- **使用：** 全书和卷规划时（常驻）；章节规划时检查本章冲突；审核发现冲突单一、不升级、解决太容易或者为冲突而冲突时。
- **不适用：** 具体战斗或对峙场景的写法（由场景写作类技能负责）。

## 方法

1. **冲突公式：** 人物想要某样东西，加上有人或有事阻止他。说不出这两部分，就没有冲突。（来源：冲突升级，冲突公式）
2. **至少两种冲突类型并存。** 人与人、人与环境、人与社会、人与自己。主线冲突加支线冲突，外部冲突加内部冲突。（来源：冲突升级，类型和常见错误1）
3. **用五种方式升级**（来源：冲突升级，升级方式）：
   - 规模：个人 → 组织 → 国家 → 世界；
   - 力量：对手越来越强；
   - 复杂度：卷入的势力和线索越来越多；
   - 赌注：失败的后果越来越重，从丢脸到丢命再到失去所爱；
   - 时间压力：给出期限。
4. **选一种推进方式**（来源：冲突升级，推进技巧）：
   - 先抑后扬：受挫 → 隐忍 → 爆发；
   - 螺旋上升：困难 → 突破 → 更大的困难；
   - 多线交织：处理一条线时牵动另一条；
   - 危机连环：一波未平一波又起，但中间要有缓和期。
5. **冲突要合理、有张力、有作用**（来源：冲突升级，设计要点）：
   - 合理：对手有说得通的动机；
   - 张力：势均力敌最好看，太强太弱都没意思；
   - 作用：每次冲突之后，要带来新信息、新线索、格局变化或主线推进；
   - 变化：交替使用不同类型，不要每次都是同一种套路。
6. **重要冲突要有过程。** 多次交锋、调整策略、提升实力，然后才解决。看起来严重的危机不能一章就轻松化解。（来源：冲突升级，常见错误3）

## 参考区间（来源经验，按作品调整）

| 冲突级别 | 频率 | 作用 |
|---|---|---|
| 小冲突 | 每 1～3 章一个 | 保持基础紧张感 |
| 中冲突 | 每 10～20 章一个 | 阶段性高潮 |
| 大冲突 | 每 50～100 章一个 | 卷级大高潮 |
| 终极冲突 | 全书 1～2 次 | 全书最大爆发点 |

悲剧或严肃向作品频率可以更低，但每个级别都要存在。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 从头到尾只有主角和一个反派对抗 | 增加内部冲突、人与社会的冲突等支线 |
| 前期打小怪，后期还在打小怪 | 按五种方式升级规模、对手和赌注 |
| 生死危机一章就轻松化解 | 补上多次交锋和策略调整 |
| 路人挑衅、打一顿、剧情没有任何推进 | 换成重要人物，并让冲突带出新线索或格局变化 |
| 反派"因为是反派所以坏" | 给出说得通的动机，比如利益、旧仇、挡了他的路 |

## 示例（自写）

```
核心冲突：林默想找回姐姐 ＋ 篡改组织要掩盖真相、能力代价在吞噬他自己
类型：人与人（组织）＋人与社会（档案制度）＋人与自己（记忆流失）
升级路线：
  第1卷 个人：黑市贩子，赌注＝执照
  第2卷 组织：档案局稽查科，赌注＝自由，并且搭档被牵连
  第3卷 城市：篡改组织浮出水面，赌注＝姐姐的最后线索，期限七天
  终卷 制度：公开真相会让整座城市的记忆体系崩溃，赌注＝他关于姐姐的全部记忆
推进方式：螺旋上升为主，第2卷末用先抑后扬（被吊销执照 → 隐忍 → 反击）
```

## 自检清单

- [ ] 能否用"想要＋阻止"说出核心冲突？
- [ ] 是否同时有外部冲突和内部冲突？
- [ ] 每一卷的对手、规模、赌注是否比上一卷更大？
- [ ] 本章冲突是否带来了新信息、线索或格局变化？
- [ ] 重要冲突是否有多次交锋的过程？

## 注入要点·规划

> 全书和卷规划时注入，不超过 800 字。

用"人物想要什么＋什么在阻止"写出核心冲突，同时安排外部冲突和内部冲突。规划升级路线：规模、对手、复杂度、赌注、时间压力，每卷至少有一项明显升级。选择推进方式：先抑后扬、螺旋上升、多线交织或危机连环（危机连环要有缓和期）。参考频率：小冲突每 1～3 章，中冲突每 10～20 章，大冲突每 50～100 章，终极冲突全书 1～2 次；严肃向可以降低频率。重要冲突要有多次交锋，不能一章轻松解决。

## 注入要点·章节

> 章节规划时注入，不超过 400 字。

本章冲突要写明：谁想要什么、谁或什么在阻止、对手的动机。冲突结束后必须带来新信息、新线索、格局变化或主线推进之一。双方力量要接近，主角的胜利来自代价或策略。不要重复上一章的冲突套路。
