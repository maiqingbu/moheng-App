# 幽默与喜剧

## 用途

在合适的位置让读者会心一笑：缓解紧张、塑造人物、制造记忆点。幽默要从人物性格和情境中自然产生，不破坏作品基调和关键情绪。

## 何时使用 / 不适用

- **使用：** 确定故事设定时决定幽默比重；本章包含日常、喘息或轻松场景时；审核发现笑点生硬、破坏氛围、人物因搞笑而性格走样，或者全书过于压抑时。
- **不适用：** 悲剧或黑暗向作品的关键情绪段落。

## 方法

1. **先定比重。** 轻松向作品幽默可以占很大比重；正常向以严肃为主，幽默作为调剂；严肃、黑暗、悲剧向只偶尔点缀。（来源：幽默喜剧，适合的类型与比例）
2. **选择幽默类型**（来源：幽默喜剧，幽默的类型）：
   - 反差：身份、力量、场面与期待不符；
   - 自嘲：人物拿自己开玩笑；
   - 吐槽：人物对周围的人和事说破（适度，避免刻薄）；
   - 语言：双关、误听、文字游戏；
   - 情境：刚说完狠话就出糗，背后议论时当事人出现；
   - 夸张：要符合世界观；
   - 专属梗：反复出现的口头禅或标志性反应，形成记忆点。
3. **从人物性格出发。** 活宝、毒舌、天然呆、反差萌各有各的笑法；严肃的人物只用符合他性格的冷幽默或小反差，不能为了搞笑让人物性格走样。（来源：幽默喜剧，角色塑造中的幽默、禁区1）
4. **放在对的位置。** 紧张之后、战斗之后、沉重章节之后用幽默放松；感人、高潮、煽情的时刻不要插科打诨。（来源：幽默喜剧，禁区4）
5. **不过度、不低俗。** 不要每句话都抖机灵；不写歧视、恶意嘲讽和低俗笑话。（来源：幽默喜剧，禁区2、3）
6. **【补写】笑点要有节奏。** 先铺垫期待，再用一个短句打破；笑点之后立刻收住，不解释笑点。
7. **【补写】幽默也可以推进剧情。** 最好的笑点同时透露信息、加深关系或者为后文埋伏笔。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 冷酷的反派突然讲冷笑话 | 改成符合性格的冷幽默，或删除 |
| 主角在同伴牺牲的场景里开玩笑 | 删除，把幽默移到之后的喘息段 |
| 笑点之后再解释"这是一个双关" | 删掉解释 |
| 每段对话都在互相调侃 | 只保留最好的一两处 |
| 玄幻世界里出现现实网络流行语 | 换成世界观内部的表达 |

## 示例（自写）

```
场景：听证会前一晚，林默和地下中介老周在面馆（喘息段）

老周把一张写满字的纸拍在桌上："明天的要点，我都给你列好了。"
林默看了一眼："第一条，'别忘了明天要开听证会'？"
"以你现在的记性，"老周把醋推过去，"这条最重要。"
林默没笑。他低头吃面，过了一会儿，把那张纸叠好，放进了胸前的口袋。
```

笑点来自人物性格（老周的嘴硬）和处境（主角的失忆代价），同时加深了关系，并在最后一个动作里收回到作品的基调。

## 自检清单

- [ ] 幽默的比重是否符合作品类型和基调？
- [ ] 笑点是否来自人物性格和情境？
- [ ] 是否放在了喘息的位置，没有破坏关键情绪？
- [ ] 是否过度、低俗或脱离世界观？
- [ ] 笑点之后是否没有多余解释？

## 注入要点·设定

> 确定故事设定时注入，不超过 400 字。

按作品类型确定幽默比重：轻松向可以较多，正常向作为调剂，严肃或悲剧向只偶尔点缀。写明哪些人物承担幽默，以及各自的笑法（活宝、毒舌、天然呆、反差萌、冷幽默）。

## 注入要点·写作

> 本章含日常、喘息或轻松场景时注入，不超过 600 字。

幽默从人物性格和情境中产生：反差、自嘲、适度吐槽、语言游戏、情境巧合、符合世界观的夸张、专属梗。不要让人物为了搞笑而性格走样。放在紧张之后的喘息处，感人、高潮和煽情时刻不要插科打诨。先铺垫再用短句打破，笑点后不解释。不过度，不低俗。最好的笑点同时推进关系或埋下伏笔。
