# 全书架构总成

## 用途

把前面确定的核心设定、读者承诺、人物、世界、冲突汇总成一份全书架构：全书分几幕、几卷，每一段承担什么任务，主线和伏笔如何分布。它是之后所有卷规划和章规划的上层依据。

## 何时使用 / 不适用

- **使用：** 全书规划时（常驻）；审核发现缺少整体架构、结构头重脚轻时。
- **不适用：** 单卷内部的安排（由卷架构负责）；具体章节（由章节规划负责）。

## 方法

1. **按顺序汇总，不跳步。** 核心设定 → 世界与机制 → 人物 → 冲突与主线 → 卷与节点 → 伏笔与回报分布。前一步没定清楚，后一步会反复返工。（来源：大纲方法，制作流程）
2. **三幕划分，按篇幅比例分配**（来源：长篇架构，三幕式升级版）：
   - 起步：约四分之一，吸引读者、展开世界、完成第一次成长和第一个阶段高潮；
   - 发展：约六成，主角持续成长，矛盾升级，多条线展开，高潮多次出现；
   - 冲刺：约一成半，终极对决、回收伏笔、情感落点、结局。
3. **三层大纲：** 总纲定全书框架和关键事件；卷纲定每卷的目标和高潮；章纲只滚动生成近期几章（见滚动规划）。（来源：大纲方法、长篇连载管理，大纲层次）
4. **每一段都写明任务。** 每幕、每卷都要写出：这一段结束时，主角、关系、世界、冲突各自变成了什么样。说不出变化的段落，要么合并，要么删掉。
5. **建立设定档案。** 人物、力量、势力、地理、时间线、重要物品、伏笔各一张表，后续章节写作和审核时对照。（来源：长篇连载管理，设定文档）
6. **【补写】按用户目标篇幅缩放。** 原资料以两百万字为样本；用户的目标篇幅不同时，按同样比例缩放幕和卷，不要套用绝对字数。

## 参考区间（来源经验，按作品调整）

| 段落 | 篇幅比例 | 主要任务 |
|---|---|---|
| 起步 | 约 25% | 吸引、建立矛盾、第一次高潮 |
| 发展 | 约 60% | 升级、多线、多次高潮 |
| 冲刺 | 约 15% | 决战、回收、结局 |

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 只有开头和结局，中段一片空白 | 把发展段拆成至少两个阶段，各有一个高潮 |
| 冲刺段占了全书三成以上，结局拖沓 | 压缩到一成半左右，砍掉无关支线 |
| 某一卷说不出结束时有什么变化 | 合并到相邻卷，或补上一项明确变化 |
| 没有设定档案，写到中期前后矛盾 | 立项时就建表，每章对照 |

## 示例（自写）

```
目标篇幅：60 万字（约 240 章）
起步（1–60 章）：委托案引出代价机制；第 60 章执照被吊销 → 第一阶段高潮
发展A（61–130 章）：地下修复、结识搭档；第 130 章发现篡改组织 → 中期高潮
发展B（131–200 章）：与档案局对立，搭档反目；第 200 章姐姐线索出现 → 中期大高潮
冲刺（201–240 章）：公开真相的抉择，终局；回收所有一级伏笔
每段结束时的变化：例如发展B结束时，主角失去了"信任制度"，关系从合作变成对立，世界从"城市"扩到"整个档案体系"
```

## 自检清单

- [ ] 各段篇幅比例是否大致合理？
- [ ] 每幕、每卷是否写明了结束时的变化？
- [ ] 发展段是否至少有两次高潮？
- [ ] 设定档案是否齐全？

## 注入要点·规划

> 全书规划时注入，不超过 900 字。

按"核心设定 → 世界与机制 → 人物 → 冲突与主线 → 卷与节点 → 伏笔与回报"的顺序汇总全书架构。按用户的目标篇幅分三段：起步约 25%（吸引、建立矛盾、第一次高潮），发展约 60%（升级、多线、至少两次高潮），冲刺约 15%（决战、回收伏笔、结局）。每幕、每卷写明结束时主角、关系、世界、冲突各自的变化，说不出变化的段落要合并或删除。同时列出人物、力量、势力、地理、时间线、物品、伏笔的设定档案。
