# 升级与张力递进

## 用途

在卷内和章与章之间，让压力一步步加大：危险更近、代价更重、退路更少。核心冲突与赌注负责全书的升级路线，本技能负责落实到具体的卷和章节，并防止升级失控。

## 何时使用 / 不适用

- **使用：** 卷规划时；本章角色是"升级"或"高潮前"时；审核发现张力平淡、威胁变小、升级方式重复时。
- **不适用：** 全书层面的冲突设计（由核心冲突与赌注负责）。

## 方法

1. **每次升级至少动一个维度：** 对手更强、牵涉更多人、赌注更重、时间更紧、手段更复杂。连续几次只动同一个维度会让读者麻木。（来源：冲突升级，升级方式）
2. **螺旋上升，中间有喘息。** 困难 → 突破 → 更大的困难。危机连环时要留缓和期，一直高压读者会疲劳。（来源：冲突升级，推进技巧）
3. **【补写】关上退路。** 每一次升级都拿掉主角的一个选项：一个盟友、一种资源、一条出路。到高潮前，主角只剩下最难的那条路。
4. **重要冲突不能轻易解决。** 越重的升级，解决时需要越多交锋和代价。（来源：冲突升级，常见错误3）
5. **控制升级的幅度。** 对手的强度不能失控，越级取胜不能太频繁；否则后期无法收场。（来源：长篇架构，实力体系崩溃）
6. **前面的强敌不能后来变弱。** 旧对手再出现时，要么同样在变强，要么用合理的理由交代他的处境。（来源：长篇连载管理，战力崩坏）
7. **对手分级递进：** 小对手很快解决，中对手需要策略，大对手贯穿一卷甚至全书。（来源：长篇连载管理，反派管理）

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 每次升级都只是"来了个更强的人" | 换维度：时间压力、盟友背叛、赌注加重 |
| 高潮前主角还有好几条轻松的退路 | 逐次关上退路 |
| 主角连续五次越级取胜 | 减少越级，或让每次越级付出明显代价 |
| 前期的大反派后期被路人一招打败 | 交代合理理由，或保持他的威胁 |

## 示例（自写）

```
单元高潮前的三次升级（第 120–128 章）：
升级1 时间：听证会提前到三天后（时间更紧）
升级2 盟友：地下中介被抓，主角失去情报来源（关上一条退路）
升级3 赌注：副局长手里有主角越界修复的录像，如果反击失败，搭档也会被定罪（赌注从自身扩大到他人）
结果：高潮时主角只剩下一条路——在公开场合修复一段记忆，并承受当众失忆的风险
```

## 自检清单

- [ ] 本次升级动的是哪个维度，和上一次是否不同？
- [ ] 主角的退路是否在逐步减少？
- [ ] 高压段之间有没有缓和期？
- [ ] 对手强度和越级取胜是否可控？
- [ ] 旧对手的再次出现是否和之前的强度一致？

## 注入要点·规划

> 卷规划时注入，不超过 600 字。

规划本卷的升级步骤：每次至少动一个维度（对手强度、牵涉范围、赌注、时间、复杂度），并且相邻两次换维度。每次升级拿掉主角的一个选项，到高潮前只剩最难的路。高压段之间留缓和期。控制越级取胜的频率，旧对手的强度要前后一致。

## 注入要点·章节

> 本章角色为升级或高潮前时注入，不超过 400 字。

写明本章升级了哪个维度（和上一次不同）、拿掉了主角的哪一个选项、读者感受到的压力从什么变成了什么。不要让升级在本章内轻易化解。
