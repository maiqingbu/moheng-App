# 世界规则设计

## 用途

设计一个内部一致、能制造冲突、并且可以逐步展开的世界。重点不是设定有多复杂，而是规则会影响人物的选择。

## 何时使用 / 不适用

- **使用：** 确定故事设定时；本章需要交代设定或进入新地图时；审核发现设定矛盾、大段说明或世界单薄时。
- **不适用：** 力量体系和升级路线（由核心机制负责）。

## 方法

1. **分三层设计**（来源：世界观深化，层次）：
   - 表层：地理、种族、势力，读者最先看到的东西；
   - 中层：社会结构、经济、历史，解释表层为什么是这样；
   - 深层：世界的根本规则和隐藏的真相，往往是全书最后才揭开的秘密。
2. **用四种方法加深**（来源：世界观深化）：
   - 推演：从一条核心规则出发，问"那么会导致什么"，一路推到社会和人物。
   - 提问：对每个设定追问"谁受益、谁受害、有没有例外"。
   - 对比：让两个地区或两种势力形成对照。
   - 借鉴现实：参考真实历史或社会的运行方式，增加可信度。
3. **规则要有代价和漏洞。** 每条规则都写明它的限制，以及谁在利用它的漏洞。规则的漏洞往往就是冲突的来源。
4. **随剧情逐步展开。** 开始只展示主角所在的一小块，随着故事推进再扩大地图、揭开深层。（来源：长篇架构，世界观层层展开）
5. **通过剧情交代**（来源：世界观深化，展现技巧）：
   - 设定在人物需要它的时候出现；
   - 用对话、冲突、细节带出来；
   - 一次只讲当前情节需要的那部分。
6. **维护一张规则表。** 每条已公开的规则都记下来；新章节涉及规则时对照检查，避免前后矛盾。（来源：世界观深化，常见错误）

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 开篇用三段介绍大陆历史 | 只保留当前情节需要的一句，其余在后续剧情中带出 |
| 规则没有代价，谁都能用 | 写明限制和谁在利用漏洞 |
| 前面说"禁术无人能解"，后面主角轻松解开 | 提前铺垫例外条件，或改掉其中一处 |
| 设定很多，但不影响任何人的选择 | 删掉，或让它直接制造困境 |

## 示例（自写）

**说明式（弱）：**

> 在这座城市，所有人的记忆都存档在档案局，修改记忆需要三级审批，私自修改属于重罪。

**剧情式（改写）：**

> 委托人把一张皱巴巴的申请单推过来，审批栏里三个格子都空着。"上面不批，"她说，"所以我才来找你。"林默没有接，他知道这张纸一旦落到稽查科手里，判的是谁。

规则（需要审批、私改重罪）在人物做选择的时刻出现，同时制造了困境。

## 自检清单

- [ ] 表层、中层、深层是否都有设计，深层是否留到后面揭开？
- [ ] 每条规则是否有代价、限制和漏洞？
- [ ] 本章的设定交代是否通过剧情出现，并且只讲必要的部分？
- [ ] 是否和规则表中已公开的规则矛盾？

## 注入要点·设定

> 确定故事设定时注入，不超过 800 字。

按表层（地理、势力）、中层（社会、经济、历史）、深层（根本规则、隐藏真相）设计世界。从核心规则推演到社会和人物；对每个设定追问谁受益、谁受害、有没有例外。每条规则写明代价、限制和漏洞，漏洞就是冲突来源。世界随剧情逐步展开，深层真相留到后面。维护一张已公开规则表。

## 注入要点·写作

> 本章涉及设定交代或新地图时注入，不超过 400 字。

设定在人物需要它的时刻出现，用对话、冲突或细节带出，一次只讲当前情节需要的部分，不写大段说明。新出现的规则不能和已公开的规则矛盾。
