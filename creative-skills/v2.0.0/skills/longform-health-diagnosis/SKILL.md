# 长篇健康诊断

## 用途

在卷与卷之间或定期对整部作品做一次体检：主线、战力、设定、伏笔、节奏、多线平衡、重复度。在长篇"写崩"之前发现趋势并调整。

## 何时使用 / 不适用

- **使用：** 每卷结束或进入新卷时；按固定章节间隔做定期检查；出现主线偏离、战力膨胀、设定矛盾、重复套路的信号时。
- **不适用：** 单章评估（由章节叙事评估负责）。

## 评估维度与判断标准

| 维度 | 健康 | 风险信号 |
|---|---|---|
| 主线 | 近一段时间有明显推进 | 长期只写支线，主线停滞 |
| 战力 | 主角和对手的强度可控，越级取胜不频繁 | 前期强敌变弱，越级成为常态，数值膨胀 |
| 设定 | 与设定档案一致 | 前后说法不一致 |
| 伏笔 | 到期的已回收，未回收数量可控 | 大量到期未回收，或埋得太多 |
| 节奏 | 张弛交替 | 长期高压或长期平淡 |
| 多线平衡 | 各线比例符合规划，没有线长期不动 | 某条线消失太久，或支线反客为主 |
| 人物 | 配角定期出场，弧线按计划推进 | 重要配角长期消失，人物停滞 |
| 重复度 | 冲突和回报类型有变化 | 同一套路反复使用 |

来源：长篇连载管理，崩盘原因；长篇架构，常见问题和连载中必做；多线叙事，篇幅平衡。

## 修改建议的写法

输出一份诊断报告：每个维度给出"健康／注意／风险"，风险项写成"证据（哪些章节）、问题、下一卷的调整措施"。

常用措施（来源：长篇架构，常见问题的解决；长篇连载管理，预防崩盘）：

- 主线：重新梳理主线，制定下一阶段大纲，砍掉无关支线；
- 战力：重新审视战力设定，控制对手强度，减少越级；
- 设定：对照设定档案逐条修正，必要时给出合理解释；
- 伏笔：列出全部未回收伏笔，安排回收；
- 节奏：画出近期紧张度曲线，补缓冲或补冲突；
- 多线：安排长期不动的线重新出场；
- 重复：下一卷换冲突和回报类型。

## 示例（自写，诊断片段）

```
维度：多线平衡 —— 风险
证据：搭档线最后一次出现在第 98 章，现在是第 131 章（33 章未出现）；规划占比 15%，实际约 4%
问题：读者可能已经忘记苏晴的立场变化，第 3 卷的反目会显得突兀
措施：第 3 卷前 10 章内安排一个苏晴视角的场景，交代她在这段时间里做了什么

维度：伏笔 —— 注意
证据：F01、F04 已到预计回收位置；未回收中长期伏笔 9 个
措施：第 3 卷回收 F01、F04；本卷暂停埋设新的长期伏笔
```

## 注入要点·评估

> 进入新卷或定期检查时注入，不超过 900 字。

对作品做健康诊断，逐项给出健康、注意或风险：

- 主线近期是否推进；
- 战力是否可控（旧强敌是否变弱、越级是否频繁）；
- 是否与设定档案矛盾；
- 伏笔是否到期未收或过多；
- 节奏是否长期高压或长期平淡；
- 各条线比例是否符合规划，有没有线长期不动；
- 重要配角是否长期消失，弧线是否推进；
- 冲突和回报是否重复。

风险项写出证据章节、问题和下一卷的调整措施。
