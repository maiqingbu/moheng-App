# 信息揭示

## 用途

决定什么时候告诉读者什么，用什么方式告诉。设定、背景、秘密和真相都在需要的时候、通过剧情让读者知道。重大揭示要有铺垫，事后回看能找到线索。

## 何时使用 / 不适用

- **使用：** 场景需要交代设定或背景；有秘密或真相要揭开；审核发现大段说明、揭示得太突然、太早或拖得太久时。
- **不适用：** 长线谜题的整体布局（由悬疑设计负责）；伏笔的种下和回收窗口（由伏笔与回收负责）。

## 方法

1. **需要时再说。** 主角走到哪里、遇到谁，才交代那里和那个人的设定。开篇不要一次性介绍世界。（来源：世界观展现技巧二）
2. **让信息附带在动作和冲突里出现。**
   - 一次买卖可以带出货币，
   - 一句闲谈可以带出局势，
   - 一次被欺负可以带出阶层差距。

   读者在剧情中顺带理解了世界。（来源：润物细无声；通过冲突展现）
3. **以小见大。** 用一个细节展现一个大结构：比如所有人都向一个修为很低的公主行礼，说明皇权高于修为。（来源：小见大）
4. **只给必要的信息，重要的反复提。** 当下用不到的设定先不说；关键设定在不同场景里出现两三次，读者才记得住。（来源：开头常见问题二）
5. **重大揭示的四步**（来源：情感冲击，反转场景）：
   - 先让读者相信表面的样子；
   - 沿途埋下事后能回看出来的线索；
   - 选在最有冲击力的时机揭开（通常是人物最需要或最不愿意知道的时候）；
   - 揭开的方式要有力：一句话、一件物品，或者一个画面。
6. **揭示之后要有后果。** 新知道的信息必须改变人物的处境或决定，否则就只是信息，不是揭示。
7. **把握节奏。** 一个谜团大约 3～5 章内给出部分答案，同时露出新的疑问。（来源：读者粘性）
8. **视角限制。** 人物不能知道他不该知道的事。读者可以比人物知道得多（制造紧张），也可以比人物知道得少（制造悬念），但要是有意的选择。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 一整段介绍"这个世界分为五大陆，修炼有十个境界……" | 拆进几次买卖、争执、闲谈里，用到什么说什么 |
| 真相突然揭开，前文没有任何线索 | 回到前面的章节补两三处可以回看的细节 |
| 揭开真相后，人物的行动没有任何变化 | 揭示必须带来一个新的决定或处境变化 |
| 人物知道了只有读者知道的事 | 检查信息来源，补一个他获知的途径 |

## 示例（自写，演示手法：通过冲突交代设定）

设定要点：在这个城市，记忆可以被修复，但修复需要档案局的许可；没有许可的私下修复是重罪。

**弱版：**

> 在这座城市里，记忆修复必须获得档案局许可，私自修复属于重罪，最高可判十年。

**改写版：**

> 老妇人把皱巴巴的钞票推过来："求你了，就修一点点。我女儿的名字……我只想记起她的名字。"
>
> 林默没有接钱。走廊尽头的监控灯一闪一闪。"没有许可单，我动一下就是十年。"
>
> "许可单要排三年。"老妇人笑了笑，"我等不了三年了。"

手法：规则（需要许可、私修重罪）、制度的代价（排队三年）、主角的两难，全部在一次请求和拒绝里带出，而且直接推动了"他会不会冒险"的选择。

## 自检清单（审核环节使用）

- [ ] 有没有超过一段的纯设定说明？
- [ ] 本章交代的设定是不是当下用得到的？
- [ ] 重大揭示之前，有没有可以回看的线索？
- [ ] 揭示之后，人物的处境或决定有没有改变？
- [ ] 人物是否知道了他不该知道的事？

## 注入要点·规划

> 本章有信息揭示场景时注入，不超过 600 字。

写明：本章要让读者知道的信息、通过哪个动作或冲突带出来、揭示之后人物的处境或决定如何改变。重大揭示要标注前文的哪些线索可以回看；没有的话，要补到之前的章节规划里，或者推迟揭示。

## 注入要点·写作

> 写信息揭示场景时注入，不超过 800 字。

- 不写大段设定说明。信息附带在买卖、争执、闲谈、冲突里出现，只交代当下用得到的部分。
- 用一个细节体现大结构（以小见大）。
- 重大揭示：先让人物和读者相信表面的样子，在最需要或最不愿意知道的时刻揭开。用一句话、一件物品或一个画面揭示，不要附加长篇解释。
- 揭示之后，人物要立刻有反应和新的决定。
- 人物只能知道他有途径知道的事。
