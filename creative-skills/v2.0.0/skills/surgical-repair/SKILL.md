# 局部修复

## 用途

根据审核意见对正文做最小必要的修改：只改有问题的段落或场景，保护没有问题的内容和已经写好的部分，不借修复之机重写全章。

## 何时使用 / 不适用

- **使用：** 审核发现可以局部修复的问题时；重写阶段（常驻）。
- **不适用：** 结构性问题（规划本身有问题、主线偏离），应走重新规划（由重规划与升级负责）。

## 方法

1. **先定层次。** 判断问题属于结构、情节、语言还是细节。结构问题不在局部修复中解决，转交重新规划。（来源：修改润色，修改的层次）
2. **划定修改范围。** 写明要改的具体段落或节拍；其余内容列为保护范围，原样保留。
3. **一次针对一类问题。** 逻辑问题、篇幅问题、语言问题分别处理，避免一次改动太多造成新问题。（来源：修改润色，分遍修改）
4. **按问题类型选择手段**（来源：修改润色）：
   - 缺铺垫：在前文补一处自然的铺垫；
   - 冗余：删除不影响理解和剧情的段落；
   - 平淡：把告知改成展示；
   - 用词：换成准确、不重复的词。
5. **篇幅不足时，展开具体的节拍。** 审核会指出哪些节拍展开不足、差多少字。只展开这些节拍：补动作、对话、感受和细节，或者补出规划中有但正文漏掉的步骤。不能重复已有内容，也不能加入与场景目标无关的描写。
6. **【补写】不复用失败的短稿。** 如果整章篇幅严重不足，问题往往在规划。重新按场景卡生成，不要在过短的初稿上反复加料。
7. **保持风格。** 修改后的段落要和前后文的文风、人物语气一致，不能改得面目全非。（来源：修改润色，误区4）
8. **改完复查。** 写明修改后要复查的维度（逻辑、篇幅、语言），确认没有引入新的矛盾。
9. **控制次数。** 同一个问题反复修不好，说明需要换方法或升级处理，而不是继续修。（来源：修改润色，过度修改）

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| 为修一处对话，重写了整章 | 只改那段对话，其余保护 |
| 篇幅不足时在结尾加一段景物描写 | 展开审核指出的不足节拍 |
| 修复后人物语气和前文不同 | 对照前后文统一语气 |
| 同一个逻辑问题修了三次还在 | 转交重新规划 |

## 示例（自写，修复计划）

```
问题：本章 1620 字，低于区间下限 2000；审核指出节拍 2-3（授权卡）和节拍 3-2（回访委托人）展开不足
修改范围：只改这两个节拍
保护范围：开头场景、结尾钩子、所有对话中已有的台词
手段：
  节拍 2-3：补苏晴离开前的停顿、目光、放卡的位置，以及林默看见卡时的反应（约 +250 字）
  节拍 3-2：补委托人开门前的犹豫、屋内被收拾过的痕迹、林默注意到相框少了一张（约 +200 字）
复查：总字数是否进入区间；新加内容是否与第 5 章设定一致；语气是否保持克制
```

## 注入要点·修复

> 重写阶段注入，不超过 800 字。

只修改审核指出的段落或节拍，其余内容原样保留。先判断问题层次，结构问题不在此处修。一次针对一类问题。缺铺垫就在前文补一处自然的铺垫；冗余就删；平淡就把告知改成展示。篇幅不足时，只展开审核指出的不足节拍：补动作、对话、感受、细节或规划中漏掉的步骤，不重复已有内容，不加与场景目标无关的描写。修改后的文风和人物语气要与前后文一致。改完复查逻辑、篇幅和语言。
