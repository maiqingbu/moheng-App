# 文字与语感

## 用途

确定并保持作品的文字风格：句子的长短、用词的质感、叙述的语气。让文字精炼、准确、有节奏，并且全书前后一致。

## 何时使用 / 不适用

- **使用：** 确定故事设定时定下文风；写作和重写时（常驻）；审核发现文字啰嗦、平淡、风格前后不一、用词重复时。
- **不适用：** 人物各自的说话方式（由对话设计负责）。

## 方法

1. **【补写】立项时定下文风。** 用三个词描述（例如"冷静、克制、偏短句"或"明快、俏皮、口语化"），并写一段约一百字的样例。之后的章节对照样例保持一致。
2. **精简。** 能用一个词的不用三个，同义的修饰只留一个。删掉不增加信息的副词和套话。（来源：修改润色，精简语言）
3. **用准确的词。** 笼统的动词换成具体的动作（"走"可以是踱、蹭、冲、挪）；同一个词不要在相邻几句里反复出现。（来源：修改润色，替换法）
4. **句子长短配合节奏。** 紧张处用短句、短段；舒缓处可以用长句和更多描写；对话多则快，描写多则慢。（来源：节奏控制，加快和放慢的方法）
5. **统一风格。** 严肃或轻松、庄重或幽默，全书基调要一致；转换基调要有意为之，而不是写着写着变了。（来源：修改润色，统一风格）
6. **用朗读检查。** 读起来拗口、喘不过气、反复出现同一个音节的地方要改。（来源：修改润色，朗读法）
7. **【补写】避免模型腔。** 少用空泛的抒情和总结句（"这一刻，他终于明白了……""命运的齿轮开始转动"）；少用成串的排比和比喻；不要在每段结尾升华。

## 失败写法与改法

| 失败写法 | 改法 |
|---|---|
| "他慢慢地、缓缓地、一步一步地走过去" | "他挪过去" |
| 一段里出现四次"看着" | 换成具体动作，或删掉不必要的 |
| 紧张的追逐写成长句和大段景物 | 改短句，删去不影响局势的描写 |
| 每段结尾都加一句感慨或升华 | 删除，让场景自己收住 |
| 前十章冷峻，第十一章突然满是网络流行语 | 回到既定文风 |

## 示例（自写）

**文风设定：** 冷静、克制、偏短句；细节具体；不抒情。

**样例：**

> 档案局的走廊有十二盏灯，第七盏坏了三年。林默每次经过都会慢半步。不是怕黑，是怕自己哪天忘了它坏过。

**模型腔版本（需要改）：**

> 漫长的走廊在灯光下延伸向远方，仿佛诉说着无尽的秘密。林默缓缓走过，心中百感交集，这一刻，他深深地意识到，记忆是多么珍贵的东西。

## 自检清单

- [ ] 本章文风是否与设定样例一致？
- [ ] 是否有可以删掉的重复修饰和套话？
- [ ] 相邻句子中是否有重复用词？
- [ ] 句子长短是否配合本段的节奏？
- [ ] 是否有空泛的抒情、总结或升华句？

## 注入要点·设定

> 确定故事设定时注入，不超过 400 字。

用三个词描述本书文风，并写一段约一百字的样例，作为后续所有章节的对照标准。

## 注入要点·写作

> 写作或重写时注入，不超过 500 字。

保持设定的文风。用准确的具体词，删除重复修饰和不增加信息的副词。相邻句子避免重复用词。紧张处用短句短段，舒缓处可以放长。不写空泛的抒情和总结句，不在段尾升华，不堆砌排比和比喻。
