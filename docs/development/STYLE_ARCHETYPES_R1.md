## 1. 市场基线 vs 我们的实验产出

| 指标（中位数） | 起点 | 晋江 | 纵横 | 七猫 | 实验第 5 轮 | 实验第 6 轮 |
|---|---|---|---|---|---|---|
| 单章字数 | 3333 | 3733 | 2597 | 2220 | 2890 | 2010 |
| 平均段长 | 31.8 | 29.9 | 26.7 | 26.2 | **42.0** | **41.9** |
| 短段占比 | 30% | 41% | 38% | 44% | 30% | 31% |
| 对白段占比 | 42% | 37% | 32% | 33% | 39% | 56% |
| 比喻/千字 | 1.0 | 0.8 | 0.9 | 0.6 | 0.5 | 0.5 |
| 因果词/千字 | 1.2 | 1.2 | 0.5 | 1.4 | 0.2 | 0.0 |
| 感叹号/千字 | 3.6 | 1.1 | 4.5 | 3.1 | **0** | **0** |
| 问号/千字 | 4.3 | 5.3 | 4.4 | 5.5 | 2.4 | 3.0 |
| 省略号/千字 | 3.5 | 2.3 | 2.9 | 7.2 | 0.9 | **0** |

**结论**

1. **比喻和因果解释已经压到市场水平以下，不必再压。** 市场作品每千字约 1 个比喻、1 个因果词，适度解释并不是问题。后续规则改为"上限对齐市场"，不再追求零。
2. **我们的产出"太平、太匀、太干净"。**
   - 段落偏长：42 字，而市场为 26–32 字。
   - 几乎没有感叹、省略，问号偏少。
   - 市场靠单行反应段、内心追问、语气停顿制造节奏和"有人在说话"的感觉，我们的产出缺这一层。这正是负责人说的"像按规划填词、没有人的思维"在数字上的表现。
3. **数字不是坏东西。**
   - 头部作品大量使用钱数、工资、价格、年龄作为处境与目标的刻度，例如攒学费、欠款、物价。
   - 要拦的是"伪精确测量"（3.7 厘米、17 秒），不是"有分量的数字"。现有规则需要区分这两类。
4. **视角并非越严越好。** 多部头部作品在第 1 章就切到反派或亲属的场景，让读者先知道主角不知道的阴谋（戏剧反讽），这是重要的追读钩子。严格单视角应作为原型参数，不是全局规则。
5. **信息靠冲突里的对话和旁人议论给出。** 开篇常见手法：问诊或审讯式问答、街坊闲谈、亲属密谋。直接的旁白设定说明很短，并且紧跟事件。
6. **第 1 章的固定动作**（男频几乎全部具备）：
   - 300 字内出现处境或冲突；
   - 主角带一个具体目标（钱、活命、复仇、离开）；
   - 章末前亮出能力或异常（系统、传承、预言、异物）；
   - 章末停在新的危险或反转上；
   - 章节名本身就是钩子。

## 2. 原型（8 个）

每个原型包含：适用题材、量化目标（风格卡直接采用）、句段规则、开篇结构、禁用写法，以及一组自写示例（只示意手法，不供照抄）。

### A1 吐槽轻喜（都市脑洞 / 轻松修仙 / 系统流）
- 参考：青山、1984 川菜馆、让仙门再次伟大、原来我是仙道天骄、请勿高考时渡劫。
- 量化：
  - 段长 28–34；短段 30–45%；对白 40–55%；
  - 问号 4–8/千字；感叹 3–6/千字；比喻 ≤1.5/千字。
- 规则：
  - 主角对荒诞或危险处境用平静、较真或答非所问的方式回应，笑点来自反差，而不是来自讲笑话；
  - 单行反应段（一个字、一个问号）用来卡节奏，每章 3–6 处；
  - 配角也要有怪癖，至少一人的言行和处境完全不合拍；
  - 系统或面板的说明文字可以带吐槽式备注；
  - 让读者知道主角不知道的事（亲属或对手密谋）。
- 开篇：问答或旁人议论开场 → 处境揭示 → 主角反差回应 → 异常出现 → 章末反转。
- 禁用：主角内心长篇吐槽解释笑点；网络流行语堆砌。
- 示例（自写）：
  - 前台小姐把表格推过来："死因那一栏，请自己填。"
  - 沈渡想了想："能写'暂无'吗？"

### A2 冷峻市井 / 江湖（高武、年代、历史、底层奋斗）
- 参考：武道！、明君、星辰大道、周迟（纵横）。
- 量化：
  - 段长 23–30；短段 35–50%；对白 35–65%；
  - 感叹 ≤3/千字；比喻 ≤1/千字；省略可高（停顿与犹疑）。
- 规则：
  - 用钱、价格、工钱、欠账标出处境和目标，数字具体并且算得清；
  - 地名、店名、行话构成质感，每场至少一个；
  - 主角话少、算得多，内心盘算用短句列出选项和代价；
  - 暴力来得突然、写得短，结果用一两句交代。
- 开篇：地点三连 → 一笔交易或对话 → 主角的账本或目标 → 世界的规矩 → 能力出现。
- 禁用：抒情式环境描写；主角心理独白超过 3 句。
- 示例（自写）：
  - 老周把三张票子压在秤盘下："这个月就这些，下月涨租。"
  - 林满数了两遍，数目没变。

### A3 悬疑惊悚（悬疑灵异 / 规则怪谈 / 民俗）
- 参考：罗彬一书（纵横）、青山的病房段落。
- 量化：
  - 段长 21–25；短段 50–60%；对白 18–30%；
  - 感叹 8–16/千字；问号 4–8/千字；省略 5–8/千字。
- 规则：
  - 开篇即危险，先给感官，再给信息；
  - 记忆或线索以碎片化短段闪回；
  - 内心用连续的短问句推断；
  - 每场有一个倒计时或逼近的威胁，例如天黑、脚步、敲门；
  - 规则与禁忌由角色说出，读者跟主角一起推理。
- 开篇：醒来或被困 → 听见他人对话得知自己处境 → 身体与环境异常 → 第一个"不对劲" → 外力逼近、被迫选择。
- 禁用：鬼怪外形长篇描写；"一股寒意从脊背升起"类固定说法。
- 示例（自写）：
  - 第三声敲门之后，门外的人报出了他的名字。
  - 可他从没告诉过谁，他今晚住这儿。

### A4 宏大史诗（东方玄幻 / 修真文明 / 洪荒）
- 参考：夜无疆、玄鉴仙族、剑烛大荒。
- 量化：
  - 段长 30–40；短段 20–35%；对白 25–35%；
  - 比喻 ≤2.5/千字（允许略高）；感叹 ≤2/千字。
- 规则：
  - 先给一个世界尺度的异变或设定（一句到一段），立刻落到一个小人物的具体处境；
  - 意象可以宏大，但每段只用一个；
  - 历史和传说借器物、地名、口述带出；
  - 节奏比其他原型慢，章末仍须有新的异象或抉择。
- 开篇：楔子式短句 → 世界状态 → 小人物的日常与困境 → 异象接触 → 命运转向。
- 禁用：连续三段以上纯设定；排比句堆砌。
- 示例（自写）：
  - 第九年，河水开始往山上流。
  - 村里人照旧在下游洗衣裳，只是要多走半里路。

### A5 直给爽文（下沉市场：战神、神医、赘婿、退婚）
- 参考：七猫大热榜多数作品、纵横的"齐天"。
- 量化：
  - 段长 20–27；短段 45–60%；对白 30–45%；
  - 感叹 5–15/千字；省略 5–15/千字；因果 ≤2.5/千字（允许直接交代）。
- 规则：
  - 第 1 章完成"受辱 → 身份或能力揭示 → 第一次打脸的铺垫"；
  - 反派的嫌弃和算计要说出口；
  - 背景可用短段直接交代，但每次不超过 5 段，交代后立刻回到冲突；
  - 每章至少一次"众人反应"段，用来放大爽点；
  - 章节名直接点出爽点。
- 开篇：出狱、归来、被退婚 → 亲属或对手嫌弃 → 主角隐忍或冷笑 → 背景速交代 → 冲突升级、主角出手。
- 禁用：主角长时间被动；对爽点的事后解释。
- 示例（自写）：
  - "一个开车的，也配坐主桌？"
  - 陈默没说话，把车钥匙放在了桌上，钥匙扣上刻着一个"军"字。

### A6 言情氛围（现代言情 / 校园 / 都市情感）
- 参考：难哄、坠落、偷偷藏不住、小鱼薄荷、陷入我们的热恋。
- 量化：
  - 段长 23–30（另一路长段对白型 43–47）；短段 40–58%；对白 25–55%；
  - 问号 5–10/千字；感叹 ≤2/千字；比喻 ≤2/千字。
- 规则：
  - 女主视角观察男主：先看外在和他人如何对待他，再加女主一句带态度的短评，单独成段；
  - 第 1 章安排一次过去的交集（不超过 6 段）；
  - 情绪落在具体小事和身体状态上，例如胃疼、熬夜、电话；
  - 女主有自己的生活困境（家人、钱、工作），不只是围着男主转；
  - 对白里留话外音。
- 开篇：女主的日常小困扰 → 远处看见男主 → 一句态度短评 → 往事一次交集 → 现实困境的电话或消息 → 两人再次交汇。
- 禁用：外貌形容词堆叠超过 3 个；直接写"心动""心跳漏了一拍"。
- 示例（自写）：
  - 他替那女生把伞往外偏了偏，自己半边肩膀湿透。
  - 挺会的。许棠低头继续剥橘子。

### A7 逆境求生 / 穿书女主（星际、废土、穿书、宅斗）
- 参考：砸锅卖铁去上学、黑月光拿稳 BE 剧本、穿进赛博游戏。
- 量化：
  - 段长 25–37；短段 25–45%；对白 6–45%（第 1 章常很少）；
  - 感叹 ≤3/千字；比喻 ≤1/千字。
- 规则：
  - 用生存逻辑展示世界规则：什么时候去、躲谁、吃什么、会怎么死，都写成主角的行动安排；
  - 主角的能力用动手解决小问题来展示（修东西、算路线、改造工具）；
  - 原主记忆简短交代；
  - 冷幽默一章 2–3 处；
  - 意外资源出现时，先评估风险再取用。
- 开篇：恶劣环境中醒来或已适应 → 一个小麻烦被利落解决 → 生存规则 → 意外机会 → 机会背后的危险或大人物。
- 禁用：自怨自艾超过两句；大段原主生平。
- 示例（自写）：
  - 水壶的盖子裂了，阿檀用胶布缠了三圈，又在外面套了个塑料袋。
  - 能装水就行，漏的是明天的事。

### A8 第一人称都市情感（官场、职场、乡土、成长）
- 参考：步步登阶。
- 量化：
  - 段长 25–30；短段 50–60%；对白 40–50%；
  - "我"约 30–40/千字；因果词可到 3–4/千字（口述气）。
- 规则：
  - 叙述者涉世未深，看得到、但看不全，读者比他先懂；
  - 口述感，允许"说是……其实……"这类自我纠正；
  - 社会关系和潜规则通过旁人言行暗示，不点破；
  - 每章一个让叙述者"开窍一点"的时刻。
- 开篇：不明就里的对话 → 叙述者自报处境 → 旁人的暗示 → 一个比他懂的人出现 → 新环境的第一条规矩。
- 禁用：叙述者事后全知式总结；说教。
- 示例（自写）：
  - 王哥让我把茶倒到七分满，我倒到八分，他也没说什么，只是把杯子往局长那边又推了推。

## 3. 风格卡生成方式（落地到 §4.1）

1. 用户选择题材后，系统推荐 1–2 个主原型和 1 个辅原型，组合出 3 版候选风格卡：
   - 主原型纯版；
   - 主原型 + 辅原型的节奏；
   - 主原型 + 辅原型的叙述距离。
2. 每张风格卡包含：
   - 量化目标（取原型区间）；
   - 6–10 条句段规则；
   - 开篇结构；
   - 禁用写法；
   - 2 组自写示例。
3. 写后规则检查读取风格卡的量化目标：
   - 段长、短段、感叹或问号密度超出区间时，给出"节奏"类发现；
   - 现有的比喻、因果上限改为跟随原型，不再全局固定。
4. 用户提供范文时，用同一套指标测量范文，生成"范文实测"那一版，其余两版取最接近的原型。

## 4. 对现有规则的修订建议（随第 3 步实施）

| 现规则 | 修订 |
|---|---|
| 伪精确数字超过 2 处即报 | 只计长度、时间、重量类测量；钱、价格、年龄、日期、人数不计 |
| 严格主角视角 | 改为原型参数：A1、A5 允许反派或亲属短切（每章 ≤1 场） |
| 比喻上限 max(3, 字数×3/1000) | 改为风格卡上限（原型区间上沿） |
| 无节奏检查 | 新增：平均段长超过原型上沿 +6，或短段占比低于下沿时报"节奏平"；感叹、问号、省略三项全为 0 时报"语气平" |
